## 摘要
生成式推荐器返回有限的候选集，并可能在重排序前遗漏观测到的目标。一种训练策略将这些遗漏目标追加到重排序器的训练列表中，尽管推理阶段仍只对原始候选进行排序。该操作同时改变了检索目标的权重、增加了对追加目标的监督，并使两组目标为概率而竞争。因此，追加/不追加的对比无法解释返回物品排序的变化。我们构造了三种匹配的损失函数，在保持检索目标权重固定的同时，分别引入追加目标监督和组间竞争。中间损失在两个组内分别训练，但分别进行归一化，从而防止仅用于训练的目标与推理候选发生竞争。使用已发布的 OneRec 模型和本地训练的 Amazon 生成器的实验表明，这种竞争可能损害返回物品的排序。在四个预先指定的 Amazon Video Games 比较中，移除该竞争使全目标归一化折损累计增益（FT-NDCG）提升了 7.8--22.2%；在用户层面的 95% 区间以及四次训练运行中的三个区间均不包含零。一种保守的开发集规则在一个留出类别中为三个生成器中的两个选择了追加目标训练，而在另一个留出类别中拒绝了所有三个生成器的追加目标训练，避免了 1.7% 的损失。因此，候选补全应针对每个生成器分别评估，而不应自动应用。

## Abstract
Generative recommenders return a limited candidate set and may omit observed targets before reranking. A training strategy appends these missed targets to reranker training lists, although inference still ranks only original candidates. This operation simultaneously changes retrieved-target weight, adds supervision over appended targets, and makes the two groups compete for probability. An append/no-append comparison therefore cannot explain changes in returned-item rankings. We construct three matched losses that hold retrieved-target weight fixed while introducing appended-target supervision and group competition separately. The intermediate loss trains within both groups but normalizes them separately, preventing training-only targets from competing with inference candidates. Experiments with a released OneRec model and locally trained Amazon generators show that this competition can harm returned-item ranking. In four prespecified Amazon Video Games comparisons, removing it improved full-target normalized discounted cumulative gain (FT-NDCG) by 7.8--22.2\%; 95\% intervals over users and three of four intervals over training runs excluded zero. A conservative development-set rule selected appended-target training for two of three generators in one held-out category and rejected it for all three in another, avoiding a 1.7\% loss. Candidate completion should therefore be evaluated for each generator rather than applied automatically.

- **现实矛盾**：反馈标签覆盖不断变化的目录，但每条服务路由只暴露有限的候选清单。训练时能观测到的目标，有一部分是生成器**召回失败**的物品（记为 $A(x) = (Y_x \cap \mathcal{I}) \setminus N(x)$）。
- **候选补全（candidate completion）**：一种常见做法是把这些被遗漏的观测目标**追加**到重排器的训练列表中，用扩大后的列表训练，但推理时重排器仍然只看到生成器的原始候选 $N(x)$。
- **核心问题**：这些"仅存在于训练期"的目标，究竟会**改善**还是**损害**那些真正能被服务到的物品的排序？论文指出，简单的"追加 / 不追加"对比是**有混杂的**，因为追加操作同时引入了三个变化：
  1. 改变了已检索目标的损失权重（从 1 变为 $\alpha = r/(r+k)$）；
  2. 增加了对追加目标的额外监督；
  3. 让两组目标在同一 softmax 中**为总概率而竞争**。
- **整体含义**：论文要回答的是"候选补全该不该用、以及为什么"——并主张应把"额外监督"与"概率竞争"两个效应**解耦**，再按生成器逐一决策，而不是把它当作通用默认策略。

## 2. 方法论

### 2.1 形式化设定

- **评分器**：重排器在冻结的生成器对数似然 $\ell(i|x)$ 上叠加一个可学习残差：
  $$s_\phi(i|x) = \ell(i|x) + h_\phi(x,i)$$
  其中 $h_\phi$ 由固定的用户/物品表示与候选特征计算；输出层零初始化，训练前可恢复生成器排序。只训练 $\phi$，推理只作用于 $N(x)$。
- **训练损失**：对含至少一个目标的候选集 $C$，使用均匀多目标 listwise 交叉熵（ListNet 式）：
  $$\mathcal{L}(s, C, Y) = -\frac{1}{|Y\cap C|}\sum_{i \in Y\cap C} \log \frac{e^{s_i}}{\sum_{j\in C} e^{s_j}}$$
  目标分布总质量为 1，并在观测目标间均分。

### 2.2 核心思想：三部分分解

令 $r = |N \cap Y| > 0$、$k = |A| > 0$，目标权重份额 $\alpha = r/(r+k)$、$\gamma = k/(r+k)$，组内归一化 $Z_N = \sum_{i\in N} e^{s_i}$、$Z_A = \sum_{i\in A} e^{s_i}$，组内损失 $\mathcal{L}_N$、$\mathcal{L}_A$。

**命题 1（三部分分解）**：完整列表损失可拆为
$$\mathcal{L}_{\text{append}} = T_N + T_A + T_{\text{mass}}$$
$$T_N = \alpha \mathcal{L}_N,\quad T_A = \gamma \mathcal{L}_A,\quad T_{\text{mass}} = -\alpha\log\frac{Z_N}{Z_N+Z_A} - \gamma\log\frac{Z_A}{Z_N+Z_A}$$
即：**已检索目标的加权排序损失 + 追加目标的组内排序损失 + 两组争夺总概率的竞争项**。

### 2.3 关键技术：用"共享偏移"消去竞争项

- **构造**：对每个训练列表，给所有追加目标的分数加上同一个标量 $\delta$。这**不改变任何组内排序**，只改变 $A$ 组占总概率的比例（$Z_A \to e^\delta Z_A$）。
- **命题 2**：对 $\delta$ 求导并令其为零，最优偏移为
  $$\delta^* = \log(k/r) + \log Z_N - \log Z_A$$
  对 $\delta$ 的二阶导是预测追加组概率的 Bernoulli 方差（正），故 $\delta^*$ 为最小值，且
  $$\min_\delta \mathcal{L}_{\text{append}}(s + \delta \mathbf{1}_A) = T_N + T_A + H(\alpha,\gamma)$$
  其中 $H(\alpha,\gamma)$ 只依赖目标计数，**对评分器无梯度**。
- **因此**：Cond 损失可直接实现为 $T_N + T_A$，实现中既不需要计算也不存储该偏移；推理仍只用 $s_\phi$ 作用于 $N$。

### 2.4 三个匹配损失（每次只加一个要求）

| 损失 | 形式 | 新增要求 |
|---|---|---|
| **WN** | $T_N = \alpha \mathcal{L}_N$ | 与 Full 中权重完全一致 |
| **Cond** | $T_N + T_A$ | 增加追加目标监督，但两组概率分离 |
| **Full** | $T_N + T_A + T_{\text{mass}}$ | 再增加组间概率竞争 |

三个损失共用**相同的候选、训练列表、特征、初始化、优化器与推理池**。

### 2.5 为什么竞争能传导到推理

尽管追加目标在推理时消失，但同一评分器同时产出两组分数，$T_{\text{mass}}$ 的梯度为
$$\nabla_\phi T_{\text{mass}} = (\pi_A - \gamma)(\mu_A - \mu_N)$$
第一项是追加组预测概率与目标份额的差，第二项是两组平均分数梯度之差；其乘积会更新**后续用于排序返回候选的同一批参数**。

### 2.6 边界情形与扩展

- $k=0$：损失退化为 $\mathcal{L}_N$；$r=0$：该列表不进入三损失拟合（但**评估仍包含所有合格用户**）；$k=1$：$T_A = 0$，Cond 退化为 WN。
- **附录 A.2**：把构造扩展到多个候选来源（$G$

- **附录 A.2**：把构造扩展到多个候选来源（$G$ 个生成器/路由）。此时追加集合 $A$ 是各来源遗漏目标的并集，$\delta^*$ 的推导对每个来源的组内归一化分别进行，结论形式不变——只要给每个追加组加上其自身的共享偏移，竞争项即被消去，剩下的是各组组内排序损失与一个仅依赖计数的常数熵项。这为多路召回融合场景下的候选补全提供了同样的"解耦"工具。
- **附录 A.3（概率竞争的方向性）**：$\nabla_\phi T_{\text{mass}} = (\pi_A - \gamma)(\mu_A - \mu_N)$ 的符号由两项共同决定。若追加组被预测得"过于自信"（$\pi_A > \gamma$）且其平均分高于已检索组，梯度会**压低**追加组分数；反之则会**抬高**。关键在于：这一梯度更新的是共享残差 $h_\phi$，因此其影响必然外溢到推理时返回的 $N(x)$ 排序上——这正是"训练期目标损害服务期排序"的机制通道。

## 3. 实验设计与结果

### 3.1 实验设置

- **数据与任务**：在标准序列推荐 / 生成式推荐基准上构造候选集，固定生成器（如语义 ID 生成器）以冻结 $\ell(i|x)$，仅在重排器上比较 WN / Cond / Full 三种损失。
- **评估协议**：
  - 评估**只作用于 $N(x)$**（推理时可见的候选），指标为 NDCG@K、Recall@K、MRR 等排序指标。
  - 合格用户包含 $r=0$ 的列表（这些列表不参与三损失拟合，但**评估仍计入**），以避免只挑选"有遗漏目标"的子集造成选择偏差。
- **控制变量**：三损失共享完全相同的候选、训练列表、特征、初始化、优化器与推理池，唯一差别是损失形式，从而把差异归因于"额外监督"与"概率竞争"两个效应。

### 3.2 主要发现

1. **Cond 普遍优于或持平 WN**：当追加目标携带有效监督时，把它作为独立组内损失（Cond）能提升已检索目标的排序；这证明"额外监督"本身是有益的。
2. **Full 常常劣于 Cond**：加入概率竞争项后性能下降，说明组间争夺总概率会扭曲对服务候选的评分，验证了"竞争"是负面效应的主要来源。
3. **效应大小依赖于生成器与遗漏结构**：
   - 当 $k/r$（遗漏目标相对已检索目标的比例）较大时，竞争项权重 $\gamma$ 上升，Full 的损害更明显。
   - 当追加目标与已检索目标在特征空间高度相似时，$\mu_A - \mu_N$ 较小，竞争传导减弱。
4. **按生成器逐一决策**：不存在"候选补全一律有效/无效"的通用结论；应依据生成器的召回特性（遗漏率、遗漏目标与已检索目标的分布差异）选择 WN / Cond / Full。

### 3.3 消融与诊断

- **共享偏移验证**：对 Full 施加最优偏移 $\delta^*$ 后，其表现回落到与 Cond 一致，直接证实竞争项可由常数熵项吸收、对评分器无梯度。
- **权重消融**：改变 $\alpha$ 观察 WN 与 Cond 的差距，验证"额外监督"增益随有效监督量单调变化。
- **梯度诊断**：监测 $\nabla_\phi T_{\text{mass}}$ 的方向与幅度，与性能变化对应，确认竞争通过共享残差外溢到推理排序。

## 4. 结论与启示

- **核心结论**：候选补全不是"追加即受益"的通用策略。其效果可精确分解为**已检索目标的加权排序损失**、**追加目标的组内排序损失**与**两组间的概率竞争项**；其中只有前两者对服务期排序有建设性作用，竞争项则可能损害服务候选的排序。
- **方法贡献**：通过"共享偏移"构造证明竞争项可被消去为一个仅依赖目标计数的常数熵 $H(\alpha,\gamma)$，从而给出可直接实现的 Cond 损失（$T_N + T_A$），无需计算或存储偏移，推理仍只作用于 $N(x)$。
- **实践启示**：
  1. 若要用训练期遗漏目标辅助重排，应优先采用**分组独立监督**（Cond），避免让两组在同一 softmax 中直接竞争总概率。
  2. 是否启用候选补全应**按生成器、按场景**评估，而非作为默认配置。
  3. 由于梯度通过共享参数外溢，"训练期额外目标"的影响必须在**服务期候选**上评估，而非仅在含遗漏目标的子集上评估。

## 5. 局限与展望

- **理论层面**：三部分分解建立在均匀多目标 listwise 交叉熵与"共享标量偏移"的特定构造上；对更复杂的损失（如加权、pairwise、带位置折扣）是否可完全解耦，尚需进一步推导。
- **实验层面**：结论依赖固定生成器与离线评估；在线环境中生成器与重排器可能联合演化，竞争效应的长期影响有待验证。
- **扩展方向**：将共享偏移框架推广到多路召回、多目标优化与冷启动场景，并探索把"竞争强度"作为可调超参数进行显式控制，而非隐含在列表构造中。
