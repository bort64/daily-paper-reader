## Abstract 

Large language model (LLM)-enhanced recommender systems leverage rich item semantics to support personalized recommenda-tion. However, semantic representations alone do not determine which historical behaviors reflect persistent preferences and which mainly indicate recent interests, leaving an important aspect of user understanding unresolved. Recent advances in LLM inference show that newly available information can be used to refine the internal state during inference, thereby improving subsequent predictions. Inspired by this principle, we propose MATE (Memory Adaptation with Temporal Evidence), an adaptive user modeling framework for LLM-enhanced sequential recommendation. MATE first evaluates each newly observed interaction from two temporal perspectives: whether it is repeatedly supported by historical behaviors and whether it is consistent with recent interactions. The resulting temporal evidence controls the updates of two user-specific memories, where the long-term memory conservatively preserves persistent preferences while the short-term memory rapidly adapts to recent interests. For each recommendation, a recent-context representation dynamically determines how strongly the two memories contribute to the current user representation. During offline training, next-item prediction is jointly optimized with temporal supervision, while during online adaptation, the shared model remains fixed and only the two user memories are updated from newly observed interactions. Experiments on MovieLens-10M, Amazon Luxury Beauty, and KuaiRec show that MATE 

improves mean NDCG@10 over the strongest external baseline by 7.0–13.2%. Further analyses support its ability to adapt to recent interests while retaining useful information about recurring earlier preferences.

## 1 Introduction 

Large language models (LLMs) have recently emerged as a promis-ing paradigm for recommender systems, benefiting from their strong language understanding, semantic modeling, and generaliza-tion capabilities [3, 11, 13]. Unlike conventional recommendation methods that primarily rely on discrete item IDs and user–item interactions, language-model-enhanced recommenders can exploit rich textual information to construct more informative represen-tations of items and user behaviors. Recent studies have explored

different ways of incorporating such knowledge, including formu-lating recommendation as a language modeling task [3], learning semantic representations from item content [11], developing se-mantic item representations from different domains for LLM-based recommendation [9], integrating collaborative signals with LLM representations [13], and reasoning over historical evidence for preference understanding [5]. These advances provide a stronger semantic foundation for personalized recommendation; however, richer item representations alone do not necessarily lead to a better understanding of how user interests evolve over time. Accurately understanding users remains challenging because user preferences are inherently dynamic and may exhibit different temporal characteristics. Some preferences can persist over long periods, whereas others emerge from recent behaviors and may rapidly change. Sequential recommendation methods have been developed to capture behavioral dependencies over interaction his-tories [10, 12], while several studies further distinguish long- and short-term user interests [25, 28]. Although these approaches have demonstrated the importance of modeling multiple temporal sig-nals, they mainly focus on how historical behaviors are encoded or combined into user representations. A less explored question is how each newly observed interaction should change the user model itself. Treating all new behaviors with the same update mech-anism may respond too slowly to emerging interests, or conversely, allow a small number of recent interactions to excessively affect useful preferences that have been repeatedly observed over a longer period. Interestingly, recent advances in LLM inference provide a useful perspective for addressing this issue. Recent studies have shown

that LLM performance can be further improved after offline training by allocating additional computation during inference, for example by searching over candidate reasoning paths, revising intermediate predictions, or adaptively refining the model state [16, 19]. The key insight is that inference need not remain a single passive for-ward process: newly available information can be used to refine the internal state on which subsequent predictions are made. In-Place Test-Time Training (TTT) further demonstrates that such adaptation can be implemented by updating a subset of the model’s existing weights using the observed context [2]. This principle naturally aligns with sequential recommendation: as new user in-teractions become observable, they provide additional evidence for refining the current understanding of the user, which can in turn improve subsequent recommendations. This motivates us to rethink user modeling as a continuous adaptive process rather than solely as a fixed encoding of the observed interaction history. In this context, a natural question arising is: “How can we better understand evolving users by preserving their long-term preferences while adapting to recent interests?” To answer this question, we outline the following two design challenges: 

• C1. Identifying the temporal role of each interaction. 

A newly observed interaction does not explicitly indicate whether it reflects a persistent preference or a recent interest . Simply treating earlier interactions as long-term and recent ones as short-term may be unreliable, since the same behavior can reinforce an existing preference while also being part of an active recent interest. Therefore, the model should determine how much evidence each observed interaction provides to the two temporal aspects. 

• C2. Adapting the user state without losing useful his-torical information. Even after identifying the temporal role of an interaction, it remains unclear how this evidence should modify the user model. A uniform update may ei-ther respond too slowly to newly emerging interests or excessively overwrite useful preferences accumulated over a longer period. Moreover, the stored long-term and short-term information should not necessarily contribute equally to every recommendation. To address these aforementioned challenges, we propose MATE ,a Memory Adaptation with Temporal Evidence for better user understanding in LLM-enhanced sequential recommendation. an adaptive user modeling framework for LLM-enhanced sequential recommendation. Our key idea is to use temporal evidence to continuously update two ser-specific memories that capture long-term preferences and short-term interests, while dynamically de-termining how the two memories should contribute to the current recommendation. 

(Idea 1): Temporal evidence for understanding user behav-iors. Instead of assigning interactions to long-term or short-term interests solely according to their timestamps, we evaluate each newly observed behavior from two complementary perspectives. We regard behaviors that repeatedly appear across separated his-torical periods as stronger evidence of long-term preference ,while consistency with recent interactions provides evidence of 

short-term interest . Importantly, the two types of evidence are not mutually exclusive, allowing the same interaction to contribute to both user states with different strengths. In this way, the model captures the temporal meaning of each observed behavior before updating the user representation, thereby addressing C1 .

(Idea 2): Adaptive user memories for continuously refining user understanding. Inspired by recent adaptive LLM inference methods, we allow newly observed interactions to directly refine the user state instead of only serving as additional inputs to a fixed forward process. Specifically, we maintain a long-term memory 

and a short-term memory for each user, which follow different up-date and retention dynamics. The long-term memory changes more conservatively to preserve persistent behavioral patterns, whereas the short-term memory responds more rapidly to recent interests. Furthermore, the recent interaction context dynamically controls how much the two memories contribute to the current recommen-dation. This design separates what should be remembered from 

what should be emphasized now , thereby addressing C2 .Overall, our framework follows a simple adaptive process: newly observed interactions are first evaluated through temporal evidence, then used to update the long-term and short-term user memories, and finally the two memories are selectively utilized for next-item recommendation. The shared recommendation model is learned offline and remains fixed during inference, while the user-specific memories continue to evolve only after real user interactions be-come observable. Our main contributions are summarized as follows: 

• Adaptive user understanding: We connect temporal user modeling with recent advances in adaptive inference and investigate how newly observed interactions can continu-ously refine user understanding in LLM-enhanced sequen-tial recommendation. Different from methods that primarily encode or combine temporal representations, we focus on how behavioral evidence should modify the user state itself .

• Evidence-guided dual-memory modeling: We propose 

MATE , which uses temporal evidence to control the up-dates of long-term and short-term user memories with dif-ferent adaptation dynamics. A context-aware mechanism further determines how strongly the two memories con-tribute to each recommendation, enabling the model to preserve persistent preferences while adapting to recent changes. 

• Comprehensive evaluations: Experiments on three real-world datasets show that MATE (a) improves mean NDCG@10 over the strongest external baseline by 7.0– 13.2%, (b) improves prediction of both recent interests and returns to recurring earlier themes, and (c) uses 1 MiB of adaptive memory per user, with 1.25–1.32 ms additional processing per event. 

## 2 Related Work 2.1 LLM-Enhanced Sequential Recommendation 

Recent advances in language models have enabled recommender systems to exploit rich semantic information beyond conventional item IDs. Early language-based recommendation frameworks, such 

> 2Remembering What Lasts, Adapting to What Changes

as P5, formulate recommendation tasks in a unified text-to-text par-adigm [3]. Other studies leverage textual item information to learn transferable or semantically enriched representations for sequen-tial recommendation, including UniSRec [7] and Recformer [11]. More recent approaches further integrate collaborative signals with language models [13], employ LLMs for candidate ranking [26], or represent items using semantic identifiers for generative retrieval and scalable item tokenization [9, 15]. LLMs have also been used to reason over historical evidence for more explicit and verifiable preference modeling [5]. These studies demonstrate that language models provide rich semantic representations for modeling items and user–item inter-actions. In this work, we use frozen language-model embeddings to represent item semantics and instead focus on how such se-mantic evidence can support a more adaptive understanding of users. Specifically, we study how persistent preferences and recently emerging interests can be accumulated and selectively utilized as the user’s interaction history evolves. 

## 2.2 Temporal User Modeling in Sequential Recommendation 

Sequential recommendation has extensively studied how user pref-erences evolve over interaction histories. Representative models employ recurrent networks [4], self-attention [10], bidirectional Transformers [18], and explicit temporal intervals [12] to capture sequential dependencies. Beyond modeling a single evolving rep-resentation, several studies explicitly distinguish preferences at different temporal scales. SLi-Rec models long- and short-term user preferences and adaptively aggregates them for recommenda-tion [25]. Particularly related to our work, CLSR disentangles long- and short-term interests using separate encoders and constructs history-derived proxies to supervise the two representations [28]. This demonstrates that temporal interests benefit from explicit model-ing rather than being implicitly compressed into a single user state. However, CLSR primarily separates and aggregates representations .Our work investigates a different question: whether temporal evi-dence should also determine how user states are updated . Instead of assigning interactions exclusively to one temporal representation, an observed interaction may update both persistent and recent memories with different strengths according to cross-period recur-rence and recent behavioral consistency. 

## 2.3 Adaptive Inference for User Modeling 

Recent inference-time learning methods provide a complementary perspective in which observed context is not only encoded as in-put, but also used to update an internal model state. Test-Time Training (TTT) introduces self-supervised adaptation during infer-ence [20], while TTT layers formulate the hidden state itself as a learnable model that is continuously updated as new tokens are observed [19]. In-Place TTT further implements this idea within standard Transformer MLP blocks by treating existing projection matrices as fast weights and updating them with prediction-aligned local learning objectives [2]. Earlier fast-weight models similarly demonstrate that matrix-valued associative memories can store and retrieve recent contextual information [1]. The idea of adaptive inference has also been explored in recom-mendation. Related efforts have investigated advanced generative modeling and post-training optimization, including diffusion-based collaborative filtering [8] and reinforcement-learning-based fine-tuning of diffusion recommenders [6]. More directly, TTT4Rec introduces TTT-style state updates into sequential recommenda-tion, allowing newly observed interactions to modify the internal sequence state during inference [24]. Related work further studies adaptation under distribution shift [23], temporal alignment for changing user interests [27], and retrieval-based adaptation without parameter updates [21]. Existing temporal recommenders model user interests at differ-ent time scales, while adaptive inference methods update user states from newly observed interactions. However, how temporal evidence should guide such adaptation remains underexplored. We therefore maintain two user-specific fast-weight memories for persistent and recent interests, using cross-period recurrence and recent-window consistency to control memory updates, while the current context determines their contributions to the next recommendation.

## 3.2 Overview 

Recent studies on LLM inference have shown that model perfor-mance can be further improved after pretraining by making better use of computation and information available at inference time. For example, inference-time scaling improves reasoning by allocating additional computation to explore, evaluate, or refine candidate solutions [17], while test-time learning further allows the model state itself to adapt to the observed context [19]. These approaches improve prediction not by simply enlarging the pretrained model, but by extracting more useful information from the current input and using it to guide subsequent inference. Motivated by this idea, we propose a three-stage adaptive user modeling framework, illustrated in Fig. 2. First, Temporal Evi-dence examines whether a newly observed behavior is repeat-edly supported by the user’s earlier history or is mainly consistent with recent interactions, providing evidence for long-term prefer-ence and short-term interest, respectively. Second, Adaptive User Memory uses these signals to update two user-specific memories: a long-term memory that preserves relatively stable preferences and a short-term memory that quickly adapts to recent interests. The shared recommendation model remains fixed during infer-ence, while the two user memories evolve as new interactions are observed. Third, Context-Aware Recommendation determines how strongly the two memories should contribute under the current context and produces the user representation for next-item ranking. Frozen language-model embeddings provide semantic item repre-sentations throughout the framework. During offline training, the shared recommender and memory-control mechanisms are jointly learned, while during inference the shared parameters remain fixed and only the user-specific memories evolve after real interactions are observed.

## 4 Experiments 

We evaluate MATE from the perspectives of recommendation ac-curacy, component effectiveness, user adaptation, computational cost, and individual recommendation behavior. The experiments address the following research questions ( RQs ): 

• RQ1: Overall Effectiveness . How does MATE perform compared with representative sequential recommendation competitors? 

• RQ2: Component Effectiveness . How do temporal evidence, dual user memories, temporal supervision, and context-aware reading affect performance? 

• RQ3: User Adaptation. Does MATE retain useful long-term information while adapting to recent interests? 

• RQ4: Efficiency Analysis. What computational and stor-age costs accompany user-memory adaptation? 

• RQ5: Qualitative User Understanding. How do memory updates and reading affect recommendations for individual users? 

## 4.1 Experimental Setup 

Datasets and preprocessing. We use MovieLens-10M 4, Amazon Luxury Beauty 2018 5, and KuaiRec 2.0 6. Positive interactions are ratings of at least four for MovieLens and Luxury Beauty, and a watch ratio greater than two for KuaiRec. We retain the first posi-tive event for each user–item pair and remove events without item metadata. Item text contains movie titles and genres; product titles, categories, features, and descriptions; or video captions, categories, cover text, and topic tags. Review text, MovieLens user tags, ag-gregate ratings, and feedback counts are excluded. Timestamps represent rating, review, or video-interaction times; Luxury Beauty records are not interpreted as purchases. After filtering, we split each dataset globally by time into approx-imately 80% training, 10% validation, and 10% test, keeping equal timestamps in the same partition. We then select at most 1,000 users using only training-period activity, requiring at least 10, 8, and 10 positive training interactions on the three datasets, respectively. The user cohorts are fixed across training seeds. Consequently, their partition counts need not follow the global 80/10/10 ratio. Table 1 reports the resulting statistics. The recent-context representation is derived from observed history; no explicit user query is supplied. 

Candidate and evaluation protocol. All methods rank the same fixed metadata catalog exactly, without sampled evaluation nega-tives. Previously interacted items are masked, and evaluation tar-gets are never added to the catalog. Validation begins by replaying training history; test evaluation independently replays training and validation history. Shared parameters remain frozen. Each target is predicted and scored before it is revealed and used to update memory. States are isolated by user, events are not written twice, and generated recommendations are never treated as feedback. 

Baselines. We compare MATE with GRU4Rec [4], SASRec [10], TiSASRec [12], CLSR [28], and TTT4Rec [24]. We also include Ora-cle4Rec [22] and PCTM [14]. CLSR uses long–short fusion without the original contrastive objective. PCTM uses training-only transi-tion statistics and no item embeddings. Base uses MATE ’s backbone without adaptive memories, while Single uses one user-memory matrix. All methods share the data split, candidate catalog, and evaluation protocol. 

Evaluation metrics. We report event-averaged Recall@ 𝐾 and NDCG@ 𝐾 for 𝐾 ∈ { 5, 10 }. Each event has one relevant next item, so Recall equals Hit Rate. Overall metrics include uncovered targets with zero credit; covered-only metrics use targets in the catalog. Coverage is 100% here, so these two results coincide. Stochastic methods use 3 seeds with means and sample standard deviations reported. PCTM is deterministic and uses one validation-selected fit. Paired uncertainty estimates resample users with their event sequences intact.

## 4.2 Overall Effectiveness 

To answer RQ1 , we compare MATE with sequential baselines under the same chronological split, fixed candidate catalog, observed-history mask, and exact full-ranking protocol. Hyperparameters and checkpoints are selected by validation NDCG@10, with the test split reserved for final evaluation. Base, Single, and MATE use a two-epoch warm-start selection budget followed by five continuation epochs per method. External neural adapters train for seven epochs; however, different objectives and batch settings mean that equal epoch counts do not imply equal computation. Table 2 summarizes the overall results. 

MATE achieves the best mean performance across all reported metrics on all three datasets. Relative to the strongest external base-line on NDCG@10, its improvements are approximately 8.6% on MovieLens-10M, 13.2% on Luxury Beauty, and 7.0% on KuaiRec. Its lead at both cutoffs indicates that the benefit is not restricted to one recommendation-list length. The strongest alternatives differ across datasets: TTT4Rec leads the external baselines on MovieLens-10M, whereas PCTM leads on Luxury Beauty. On KuaiRec, TTT4Rec is the strongest external method on three metrics, while Oracle4Rec has the highest external NDCG@5. Thus, MATE ’s advantage holds against different competitive approaches rather than a single con-sistently weak comparator. Within the shared-backbone family, MATE improves NDCG@10 over Base by approximately 93.8%, 46.6%, and 28.1% on MovieLens-10M, Luxury Beauty, and KuaiRec, respectively. Single also outper-forms Base on all reported metrics, suggesting that user-memory adaptation adds useful predictive information beyond the shared backbone and frozen item semantics. MATE further improves on Single across all three datasets. This pattern is consistent with the motivation for maintaining persistent and recent information sepa-rately, rather than writing every interaction into one undifferenti-ated memory. Nevertheless, Single has half the adaptive-memory capacity, so this comparison cannot isolate temporal decomposi-tion from additional storage. The equal-capacity ablations provide the more direct component comparisons; the overall results estab-lish the performance ordering without attributing the gains to any single mechanism.

## 4.4 User Adaptation 

For RQ3 , we test whether MATE can adapt to a recent interest while retaining useful earlier information. Predicting recent behav-ior alone could reward excessive recency bias; predicting actual returns to an earlier theme additionally tests retention. We iden-tify observed histories with a recurring earlier theme A followed by a distinct recent theme B. A recurs in at least two older calen-dar months spanning 30 days. B forms a consecutive suffix within seven days and accounts for at most 20% of older labeled interac-tions. Themes are fixed metadata groups or training-fitted semantic groups used only for analysis, never additional model inputs. After 1, 2, 3, or 5 observed B interactions, Continue B evaluates a real next item belonging to B, testing adaptation. Return to A evaluates a real next item belonging to A, testing prediction of a return rather than merely assigning high scores to A items. Eligibility uses only the observed prefix; the target theme labels the evaluation outcome. Predictions precede target revelation and memory updating. Table 4 pools the preset B-count positions. MATE exceeds Base and Single in mean NDCG@10 for both outcomes on all three datasets. Better Continue B performance supports adaptation to recent behavior, while better Return to A performance suggests that this responsiveness does not sacrifice prediction of recurring earlier interests in these cohorts. Together, these outcomes support the intended adaptation–retention balance, without isolating the long-term matrix’s causal contribution. Small cohorts and pooled B counts limit conclusions about individual users or adaptation at each streak length. Frozen matches MATE at the reported precision, so these results do not establish an additional benefit from test-period memory writes. Table 5 adds diagnostics over all test events. Long writes trigger in 62–65% of MovieLens/Luxury events but only 6.1% of KuaiRec events; mean short-memory read contributions exceed long-memory contributions on every dataset. These statistics show dataset-dependent memory usage, but activity alone does not es-tablish useful retention. The comparisons are descriptive, without a statistical-significance claim.

## 5 Conclusion and Broad Impact 

In this work, we studied evolving user interests in LLM-enhanced sequential recommendation with frozen item embeddings. We pro-posed MATE , a memory adaptation framework that uses temporal evidence to update two user-specific memories with different adap-tation dynamics. Long-term evidence captures recurring behavior across periods, while short-term evidence reflects recent consis-tency. Context-dependent reading determines their contributions to the current recommendation. The shared model is trained offline, and user memories are updated only after real interactions become observable. Experiments on MovieLens-10M, Amazon Luxury Beauty, and KuaiRec show that MATE achieves the best mean performance across the reported recommendation metrics. Equal-capacity abla-tions support the roles of temporal evidence, temporal supervision, and dynamic reading. Real-sequence analyses further show im-proved prediction of both continued recent interests and actual returns to earlier recurring themes. However, Frozen Online Mem-ory matches MATE ’s reported Top-𝐾 metrics, so these experiments do not establish an additional benefit from continued test-time writing. Efficiency measurements show that adaptation introduces additional computation and user-state storage. Together, the results support temporal evidence as a useful control signal for memory adaptation, while leaving its incremental online benefit open to further evaluation. 

> 12

Remembering What Lasts, Adapting to What Changes 

Broad Impact. MATE offers a framework for personalized recom-mendation that combines persistent information with adaptation to recent behavior. This design may also inform other interactive sys-tems with evolving user states. Its deployment nevertheless requires careful handling of behavioral histories and persistent memories. Privacy protection, memory management, and safeguards against reinforcing narrow or outdated interests remain important con-siderations. Predictive improvements should not be interpreted as direct understanding of users’ motivations, and practical evaluation should consider user benefit alongside recommendation accuracy and computational cost.
