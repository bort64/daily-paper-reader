## 摘要
生成式推荐已在工业界和学术界引起广泛关注，旨在构建更智能的系统以打造下一代推荐系统。在大语言模型蓬勃发展的浪潮下，我们团队研发了基于 Semantic ID 的 OneRec/OneRec-V2。这些模型已广泛应用于生产环境，并展示了自回归下一项预测范式在工业推荐系统中的扩展潜力。在 OneRec 成功的基础上，我们进一步探索了一系列模型，包括 OneRec-Think、OpenOneRec 和 OneReason，它们将物品 Semantic ID 与自然语言连接在统一的表示空间中，并试图释放自然语言思维链（CoT）推理在推荐中的潜力。然而，我们的初步工作发现，引入推理 CoT 并不总能提升推荐性能。为解决这一问题，OneReason 加强了物品与语言之间的语义对齐，引入了基于结构化模板的兴趣推理监督，并应用先进的强化学习技术，使推理更有益于推荐。作为构建推荐基础模型的前沿课题，我们相信该课题具有重要的研究价值，并希望鼓励更多研究者共同探索。为此，我们与 SIGIR 2026 社区共同组织了 KUAISHOU Explorer LLM-Rec Challenge 2026：推理式生成推荐。

## Abstract
Generative recommendation, has been attracted a surge of attentions in industrial and academic research community, towards to build more smart system to build next-generation recommender. Under the significant developing wave of large language model, our team have been developed Semantic ID based OneRec/OneRec-V2. These models have been widely deployed in production and demonstrate the scaling potential of the autoregressive next-item prediction paradigm for industrial recommender systems. Building on the success of OneRec, we further explored a series of models, including OneRec-Think, OpenOneRec, and OneReason, that connect item Semantic IDs with natural language in a unified representation space and seek to unlock the potential of natural-language chain-of-thought (CoT) reasoning for recommendation. However, our preliminary works found that introducing reasoning CoT does not always improve the recommendation performance. To address this issue, OneReason strengthens the semantic alignment between items and language, introduces structured template-based supervision for interest reasoning, and applies advanced reinforcement learning techniques to make reasoning more beneficial to recommendation. As a frontier topic to building recommendation foundation models, we believe this topic has significant research value and hope to encourage more researchers to explore it together. To this end, together with the SIGIR 2026 community, we organized the KUAISHOU Explorer LLM-Rec Challenge 2026: Reasoning Generative Recommendation.

## 一、核心问题与研究背景

- **范式转移**：生成式推荐将"预测用户下一次交互"重构为序列生成问题，为推荐系统在大模型时代提供了新的扩展路径。快手 OneRec 系列基于 **Semantic ID（SID）** 验证了自回归下一项预测在工业级推荐中的可扩展性，并已大规模上线。

## 二、方法论

### 2.1 物品表示与词表扩展

- **物品 Tokenizer**：多模态编码器将封面、视频帧、文本、音频压缩为稠密向量，并与语言解码器联合训练（以物品向量作 soft prompt 重建描述），保证语义保真。
- **RQ-KMeans 三级残差量化**：每级 8,192 个码字，物品 SID 形式为 `<|domain_begin|><s_a_x><s_b_y><s_c_z>`，`domain ∈ {video, prod, ad, living}`。
- 领域标记与量化码作为特殊 token 加入 LLM 词表，SID 与自然语言混合构成训练序列。

### 2.2 多粒度语义对齐预训练（四个层级）

| 层级 | 监督内容 |
|---|---|
| **Token 级** | 单个码或其组合与自然语言的对应、码前缀与描述的双向映射、由码解释组合出完整物品描述 |
| **物品级** | SID→描述生成、描述→SID 检索、内容属性问答；**控制描述粒度**，保留主题/品类/品牌等可区分信息，弱化码无法承载的细节 |
| **关系级** | 由协同行为信号（看后搜、物品跳转、跨域共现）构造物品关系并生成文本解释，序列中交织物品码与关系说明 |
| **用户级** | 跨域条件建模（以其他域行为预测目标域）+ 多域记录按时序交织并部分以描述替换码，兼顾内容与时序 |

- **三阶段训练**：① 冻结原参数，仅训新物品 token 的 embedding 与输出层（110B tokens）；② 全参数训练学习推荐语义与行为模式（449B tokens）；③ 扩展上下文长度支持长历史（19B tokens）。预训练混入通用文本、数学、代码与多模态数据。

### 2.3 四类任务定义

- **理解物品**：SID ↔ Caption 双向映射（初赛为描述→SID，复赛改为 SID→描述，由 LLM judge 评分）。
- **理解用户**：给定历史与兴趣主题，① **相关行为选择**（输出相关交互的 JSON 数组）；② **兴趣演化链生成**（每事件含 `date / action / logic`，链长≤5，涵盖场景内需求完成、因果推进、需求细化三类演化）。
- **理解推荐**：以多域历史预测指定目标域的下一次交互 SID。评测采用 **think + nothink 双路 Pass@32 合并去重**（候选集 ≤64），旨在让 think 模式产出 nothink 无法覆盖的多样化兴趣物品。
- **理解世界**：中文常识单选题，考察推荐任务训练后保留的通用知识。

### 2.4 评估指标（核心公式用文字说明）

- **物品理解**：将生成描述与参考描述拆解为信息点，参考点带 1–5 重要度权重，匹配质量用 bert-base-chinese 的 BERTScore F1 度量；据匹配/遗漏/冗余三类加权量计算 **双加权 F1**，兼顾核心信息准确、参考内容遗漏与无依据细节。
- **相关行为选择**：预测集与参考集的 **F1**（Precision 衡量选中项相关性，Recall 衡量参考项覆盖度）。
- **兴趣演化链**：先在保持顺序的**单调一对一匹配**中求交互集 F1 总和最大的对齐，得到 Action 侧 P/R/F1；再用 **Token F1 与 ROUGE-L F1 的等权平均**度量对齐事件的解释相似度，得 Logic 分数；最终 **S_chain = 0.5·F_act + 0.5·F_logic**。无法解析结构的回答计 0 分且保留在分母中。
- **推荐**：候选 SID 映射为 PID 并与真实目标 PID 集比对，**PIDPass**（任一命中即 1）按四个目标域分别计算。
- **常识**：抽取选项字母与参考答案比对，计算 Accuracy。
