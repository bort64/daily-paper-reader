## Abstract 

Recommender systems leveraging generative models often gen-erate item identifiers directly, rather than ranking catalog items by a recommendation score. Recent work extends beyond pure sequential interaction signals by incorporating item content and structured relationships among items, with two distinct directions emerging. Semantic IDs (SIDs) enrich item representations by replac-ing opaque, randomly initialized embeddings with hierarchically quantized discrete codes derived from item content. Knowledge-graph (KG) path reasoning instead generates entity-relation paths that ground recommendations in structured relationships between items, attributes, and external entities, thereby enriching the rela-tional context. These two lines have complementary limitations: SID-based models lack relational grounding, while KG-based gen-erative recommenders still represent items as arbitrary, opaque tokens tied to large embedding tables, limiting parameter sharing and generalization. We propose SPRIG , a generative recommender that integrates content-derived SIDs into KG path reasoning. SPRIG is trained on information-rich KG paths that terminate in items rep-resented as discrete, content-derived tokens, combining the advan-tages of both approaches. We evaluate SPRIG on movie and music recommendation datasets against baselines spanning sequential lan-guage models, KG-augmented methods, and SID-based approaches. Our results show that SPRIG achieves competitive performance over prior generative models while using fewer parameters and a lower compute cost. ## 1 Introduction and Related Work 

Recommender systems have recently shifted from score-based re-trieval towards generative formulations, where a causal Transformer model trained on chronologically ordered interaction sequences autoregressively predicts the next item directly from a user’s his-tory [6, 15, 23]. While these advances brought substantial gains, two limitations persist: the vocabulary size required for items grows linearly with catalog size, and the sequential (collaborative) signal alone is not rich enough. Complementary directions have emerged to inject richer contextual information into generative recommendation. The first approach enriches the item representa-tion by replacing the arbitrary, opaque, randomly-initialized item IDs with semantically rich discrete codes, known as Semantic IDs (SIDs) [8, 9, 15, 18]. Because each item is encoded with codes from a small shared codebook, SIDs also substantially reduce the vocab-ulary size. Semantic IDs for Generative Recommendation. SIDs were popular-ized by TIGER [15], which represents each item as a short sequence of content-derived codes from an RQ-VAE over pretrained embed-dings [11, 15]. Sharing code prefixes across semantically similar items enables parameter sharing and cold-start generalization [17], and later work adds collaborative signals [19, 25] or end-to-end tokenization [12]. SPRIG adopts the TIGER formulation with the refined quantization of Generative Recommendation with Semantic IDs (GRID) [9], but unlike these methods grounds recommendation in a structured relational context. 

Knowledge-Graph-Augmented Generative Recommendation. A par-allel line frames recommendation as explicit path reasoning over a KG, returning an item together with a human-interpretable multi-hop path. Early reinforcement-learning (RL)-based agents navigate from user to item [2, 3, 20]; the paradigm was later recast as autore-gressive language modeling over KG paths , with constrained decod-ing guaranteeing valid edges [1, 5]. KGGLM [4] is the state of the art in this line, pretraining a generative model on generic KG paths and fine-tuning for path-reasoning recommendation. However, all of these represent items as opaque, arbitrary IDs, preventing param-eter sharing and growing the vocabulary linearly with the catalog size. In this context, we propose SPRIG , a generative recommender framework that unifies content-derived SIDs with knowledge-graph path reasoning in a single autoregressive model. SPRIG ingests hierarchical SIDs pre-computed from item content features via a residual quantizer, replacing the opaque atomic item tokens of prior KG-based recommenders with semantically informed, parameter-sharing codes. Afterwards, it leverages the rich contextual structure of a KG to pretrain a causal Transformer decoder on generic entity-relation paths, before fine-tuning on user-to-item recommendation paths whose last tokens consist of SID sequences. The path genera-tor builds on KGGLM [4], which we also adopt as our primary KG baseline. This design simultaneously inherits the expressiveness of KG path reasoning [1, 4, 5, 20] and the parameter efficiency and cross-item generalization of SIDs [15, 19], while decoupling the out-put vocabulary from the catalog size. To the best of our knowledge, SPRIG is the first model to integrate SIDs with KG path reasoning for generative recommendation. Within this context, we investigate whether KG-based generative recommenders benefit from repre-senting item entities using semantically grounded identifiers ( RQ1 ), and whether the resulting shared code space reduces the output vocabulary without sacrificing recommendation quality ( RQ2 ). To answer these questions we make the following contributions: 

• We propose SPRIG, the first generative recommender that unifies SIDs and KG path reasoning in a single autoregressive frame-work. 

• We show in two recommendation domains (movies on ML-1M and music on Onion) that SPRIG achieves competitive perfor-mance against sequential language models, KG-augmented meth-ods, and SID-based baselines.

## 3 Experiments 

In this section, we describe the setup of our experiments, which aim to uncover the effects of supplementing KG path reasoning with SIDs on recommendation accuracy and model size. 

Datasets. Following KGGLM [4], we evaluate on two publicly available datasets spanning distinct domains: MovieLens-1M (ML-1M) [24] for movie recommendation and LFM-2B [16] for music track recommendation. We adopt the KG-enriched version of ML-1M available via RecBole [24]. We complement LFM-2B with the music content features from [13] and use artist, genre, album, and user-generated tags from the same dataset, to construct the KG. Given the scale of LFM-2B, we restrict to interactions in March– May 2018 and apply iterative 𝑘 -core filtering ( 𝑘 = 20) until the user and track sets stabilize, we call this combined dataset Onion. Implementation Details. All experiments use an NVIDIA A40 GPU. Each model is run under its own best configuration from the original publications [4, 10, 15, 21] and verified on our splits, with identical dataset preprocessing and chronological splits across models. The DistilGPT-2 backbone (6 layers, 12 heads, 𝑑 =768) is used off-the-shelf and shared by SPRIG and KGGLM, so it is not tuned in SPRIG’s favor; SPRIG only lowers the learning rate and shortens the path length, as the longer 𝐿 𝑠 -token SIDs require. We pretrain on 500 5-hop KG random walks per entity for 3 epochs, then fine-tune on collaborative 3-hop paths (200 per user). 

Task and Protocol. SPRIG performs top-k recommendation by path reasoning: conditioned on a user ( ⟨[ 𝐵𝑂𝑆 ], 𝑈 𝑖𝑑 , 𝑅 𝑈 𝐼 ⟩), it gen-erates user-to-item paths via diverse beam search and ranks the terminal items. We use a per-user chronological 60/20/20 split and evaluate under full ranking over the catalog against each user’s held-out interactions. We use diverse beam search with 60 beams in 5 groups, diversity penalty 0 .4, and length penalty 0, deterministi-cally generating 3-hop paths and returning up to 50 candidate paths per user. Terminal items are ranked by their path log-likelihood; when several beams reach the same item we keep its highest-scoring path. Because SPRIG and KGGLM share this decoding configura-tion, their comparison is controlled, whereas SASRec ranks the full catalog directly and therefore serves as a reference point rather than a head-to-head generative baseline. 

Evaluation Metrics. We evaluate ranking quality with three stan-dard metrics at 𝐾 = 10. We assess statistical significance with a two-sided paired bootstrap test over per-user metric scores, com-paring SPRIG (gen + spec) against KGGLM (gen + spec). 

Baselines. We compare SPRIG against baselines spanning sequen-tial, generative, and knowledge-aware recommendation paradigms. SASRec [10] is a strong sequential recommendation baseline based on self-attentive sequence modeling. Unlike the generative methods below, it directly ranks items from the full catalog rather than gen-erating recommendation paths or identifiers. OpenP5 [21] is a gen-erative recommender that represents items with atomic identifiers; we report both its sequential and collaborative indexing variants. TIGER [15] represents items with semantically grounded codes derived from item content, isolating the effect of SIDs in the identi-fier space. KGGLM [4] is the direct predecessor of SPRIG and our strongest knowledge-aware baseline: it incorporates KG structure but retains opaque item tokens, so the gap between KGGLM and SPRIG isolates the contribution of our SID scheme rather than the KG itself. For both KGGLM and SPRIG we report a generalization-only variant ( gen-only ), trained solely on the generative objective, and a specialized variant ( gen + spec ), further fine-tuned for recom-mendation.

## 4 Results 

Table 2 reports the performance of SPRIG and all baselines on ML-1M and Onion. SPRIG (gen + spec) performs best among directly comparable generative models. We analyze these results to answer the RQs from Section 1. We first address RQ1 : whether replacing the opaque item tokens used in KG-based generative recommenders with semantically-grounded IDs improves recommendation quality. On ML-1M the fully specialized SPRIG (gen + spec) improves nDCG@10 by roughly 44% over its directly comparable baseline KGGLM (gen + spec). The same trend holds on the larger and sparser Onion, where SPRIG raises nDCG@10 by 58%. Since KGGLM and SPRIG share the same backbone and knowledge-graph signal, this gain stems from the SID-based item representation and its associated decoding rather than from the knowledge graph, answering RQ1 affirmatively. These improvements over KGGLM (gen + spec) are statistically significant across all metrics on both datasets (Table 2). Across representation paradigms, the generative baselines OpenP5 and TIGER are substantially outperformed by the knowledge-aware models, confirming that relational grounding adds signal that SID-based sequential models alone miss. SASRec attains the highest nDCG@10 on both datasets and the highest HR@10 on Onion, but it ranks the full catalog directly while the generative models decode over beam-search candidates, so the comparison is indicative rather than exact; its margin on Onion further reflects the sequentiality of music listening that the sampled setup discards. Among directly comparable generative models, the gap between SPRIG and KG-GLM shows that relational grounding and SIDs are complementary and the combination of them is strongest. Even without collaborative fine-tuning, SPRIG (gen-only) sur-passes KGGLM (gen-only) on every metric on both datasets (e. g., nDCG@10 improves from 0 .0281 to 0 .0375 on ML-1M). We attribute this to the parameter sharing induced by SIDs, which lets rarely seen items inherit signal from their prefix-level neighbors; the ad-vantage widens further after specialization. We now turn to RQ2 : whether representing items in a smaller, shared latent code space allows a generative recommender to reduce its output vocabulary while preserving accuracy. KGGLM allocates one embedding per item, so its item-dependent vocabulary grows linearly with the catalog ( |I| = 2,984 for ML-1M and 18 ,415 for Onion). SPRIG instead represents every item with 𝐿 𝑠 = 3 codes SPRIG CIKM ’26, November 07–11, 2026, Rome, Italy 

drawn from 𝐾 = 256 shared entries, bounding the item-token vocabulary by the factor 𝐿 𝑠 · 𝐾 = 768 regardless of catalog size. On ML-1M this shrinks the item-token budget from |I| = 2,984 to 

𝐿 𝑠 · 𝐾 = 768 (a ∼ 4× reduction), and the saving widens to ∼ 24 × on the larger Onion catalog (18 ,415 to 768). This compression does not cost capacity. On ML-1M, SPRIG is comparable in size to KGGLM (56 .1M vs. 57 .8M parameters) yet uses 11% fewer FLOPs per step, while reaching the higher accuracy in Table 2. This gap grows with the catalog. On Onion, where KG-GLM’s per-item embeddings dominate its parameter count, SPRIG uses 19% fewer parameters and nearly half the FLOPs. Decoupling the vocabulary from the catalog thus improves both accuracy and efficiency, and does so most where the catalog is largest. 

Ablation: Robustness to Quantization and Item Representation. 

To test the robustness of SPRIG to the quantization approach, we evaluate three residual quantizers for semantic-ID construction: RVQ [22], RQ-VAE [11, 15], and residual K-means [9]. Consistent with GRID [9], residual K-means attains the best accuracy, but the gap over RVQ and RQ-VAE is small ( ∼1%), indicating that SPRIG is largely insensitive to the choice of quantizer. We then test robust-ness to the item representation by comparing two audio feature extractors on Onion. Here the behavior differs: musicnn embed-dings [14] consistently outperform the MFCC bag-of-words [7] representation across all quantizers, showing that SPRIG is instead sensitive to the quality of the underlying item features. 

## 5 Conclusions and Future Work 

We introduced SPRIG, the first generative recommender to unify content-derived SIDs with KG path reasoning in a single autore-gressive framework. By rewriting every item entity in the KG as a short sequence of hierarchical tokens and training a causal Trans-former decoder over the resulting paths, SPRIG combines the rela-tional reasoning of KG-based recommenders with the parameter ef-ficiency and cross-item generalization of SIDs. Across two domains — movies on ML-1M and music on Onion— SPRIG outperforms prior generative recommenders spanning atomic-ID (OpenP5), SID-based (TIGER), and KG-augmented (KGGLM) families, surpassing its direct predecessor KGGLM on every metric, while remaining competitive with a strong sequential baseline (SASRec) at a lower parameter count and decoupling the output vocabulary from the catalog size. Several directions remain open. First, the use of SIDs offers as natural and promising application the use of SPRIG for item cold-start recommendation: a new item can be reached through the SID prefix it inherits from content-similar seen items, rather than requiring a dedicated embedding [15, 17]. A faithful evaluation, however, requires cold-start–specific splits and a path-sampling strategy for items absent from the user–item training edges, which we leave to future work. Second, while KG path reasoning is inher-ently explanatory, SPRIG’s paths terminate in SID codes that are less human-readable than named item entities; recovering faithful, interpretable justifications(e. g., by aligning the hierarchical code levels with the attribute entities that generated them) is a promis-ing but non-trivial direction rather than an existing feature of the model. In addition, our finding that the optimal quantizer differs from that reported for purely sequential SID models [9] motivates a deeper study of how tokenizer choice interacts with relational path modeling. We leave these research directions for future work.
