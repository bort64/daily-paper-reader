## 摘要
在指令引导的生成式推荐中，基于 LLM 的推荐器需要平衡两个目标：回应用户当前请求，以及与其交互历史中的偏好保持一致。当二者冲突时，历史事件可能压过请求。我们表明，将单个历史事件的影响转化为监督面临两个障碍。第一，对推荐影响最大的事件未必是支持目标物品的事件。第二，移除一个误导性事件可能提高目标物品的分数，但竞争物品的分数提高得更多，因此仅凭目标物品分数更高并不能保证更好的排序。我们提出非对称干预引导的间隔监督（Asymmetric Intervention-Guided Margin Supervision, AIMS），它将移除单个历史事件的效果转化为排序监督。对于已经正确排序的训练请求，一个冻结的参考模型会识别出请求特定的删除操作，这些删除既能提高目标物品的分数，也能提高其相对于推荐截断点附近竞争者的间隔。这些间隔作为训练目标，同时完整历史仍被保留为输入。训练将交叉熵与一个非对称辅助损失相结合，该损失惩罚间隔不足，并且其梯度仅通过竞争者分数回传。推理过程不变，无需编辑历史或搜索删除。在一个工业数据集和两个公开基准上，跨越六个 LLM 主干，AIMS 在 Recall 和 NDCG 上优于强基线。消融实验支持请求特定的间隔和非对称监督，并且所选删除优先移除违反约束的历史。

## Abstract
In instruction-guided generative recommendation, LLM-based recommenders need to balance two goals: responding to the user's current request and aligning with the preferences in their interaction history. When the two conflict, history events can override the request. We show that turning the effect of individual history events into supervision faces two obstacles. First, the events that most influence a recommendation are not necessarily the ones that support the target item. Second, removing a misleading event can raise the target's score but a competing item's score even more, so a higher target score alone does not guarantee a better ranking. We propose Asymmetric Intervention-Guided Margin Supervision (AIMS), which converts the effect of removing individual history events into ranking supervision. For training requests already ranked correctly, a frozen reference model identifies request-specific deletions that improve both the target's score and its margin over a competitor near the recommendation cutoff. These margins serve as training targets, while the complete history is retained as input. Training combines cross-entropy with an asymmetric auxiliary loss that penalizes margin shortfalls and routes its gradient only through the competitor score. Inference is unchanged, requiring no history editing or deletion search. Across six LLM backbones on an industrial dataset and two public benchmarks, AIMS improves Recall and NDCG over strong baselines. Ablations support request-specific margins and asymmetric supervision, and the selected deletions preferentially remove constraint-violating history.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务设定**：指令引导的生成式推荐（instruction-guided generative recommendation）。LLM 以语义标识符（SID，三层离散码）自回归解码物品，输入包括两部分：
  - **自然语言请求 q**：约束"当下什么是可接受的"；
  - **交互历史 H = (h₁,…,hₙ)**：在可接受项中做个性化选择。
- **核心痛点**：当请求与历史冲突时，历史事件会"压过"请求。典型例子：用户看过红烧排骨烹饪视频后请求"30 分钟内完成的素食快手晚餐"，模型却把需 3 小时的炖牛肉排在前面，同时压低用户真正想要的 20 分钟鹰嘴豆意面。
- **作者诊断出的两个障碍**（这是论文的核心贡献之一）：
  1. **影响–效用错位（Influence–Utility Misalignment, IUM）**：对预测影响最大（JS 散度最大）的历史事件，未必是"支持目标"的事件。影响与效用**绝对值** |Uⱼ| 的相关性为 0.300（Llama）/0.167（Gemma），而与**带符号效用** Uⱼ 仅 0.045/0.002；最大影响选择相比随机选择，支持性事件率仅提升 0.24/0.42 个百分点（置信区间含 0），泛化请求下甚至转负（−3.94/−2.95）。
  2. **目标分数提升 ≠ 排序改善**：删除某事件可能同时抬高目标与竞争者分数，若竞争者涨得更多，目标–竞争者间隔（margin）反而下降。审计显示，即使目标分数上升，margin 下降的请求占 11.8%（Llama）/16.7%（Gemma），重解码后只有 1.08%/1.50% 变成 top-10 命中。
- **整体含义**：论文主张不应在推理时"编辑/筛选历史"（会丢失个性化信息），而应把**单事件删除的请求相关效应**转化为**离线可得的训练监督**，让模型在**完整历史**上学到更强的目标–竞争者间隔，推理过程完全不变。

## 2. 方法论：AIMS（Asymmetric Intervention-Guided Margin Supervision）

### 2.1 核心思想
- 删除动作**只定义监督目标，不改变训练/推理输入**；完整历史始终作为输入。
- 以冻结 SFT 检查点 θ₀ 为参考模型，对每条"初始已排正确"的训练请求寻找**请求特定的删除视图**，将其带来的最大 margin 增益作为"反事实间隔"（counterfactual margin）缓存下来，由学生模型从完整历史中去逼近。
- 辅助损失**非对称**：梯度只经过竞争者分数（目标分数被 detach），因为目标已由交叉熵直接监督。

### 2.2 关键技术细节（公式化流程）

- **评分与间隔定义**
  - SID 序列得分：`sθ(v|q,V) = Σ_{ℓ=1..L} log pθ(vℓ | q, V, v<ℓ)`，L=3。
  - 目标–竞争者间隔：`mθ(y,c|q,V) = sθ(y|q,V) − sθ(c|q,V)`。
  - 竞争者 c 的选取：初始完整历史解码列表中，若目标已在 top-R 内，取 rank R+1；否则取 rank R（论文默认 R=10）。c 的身份在跨历史视图与整个训练中固定。

- **保护集 P**
  - 仅包含初始（θ₀）完整历史下目标位于 top-10 的训练请求（工业数据上占训练请求 18.1%/30.6%）。目的是在继续训练中防止这些已命中样本被"挤出"。

- **Stage 1：指令条件化的干预审计（离线、一次性）**
  - 删除预算 K（默认 K=1），候选删除集合 `C(K)_i` 为所有 1≤|S|≤K 的下标子集；删除后得视图 `H^{−S}_i`。
  - 计算目标提升与 margin 增益：`Δ_{y,i}(S) = sθ₀(yᵢ|qᵢ,H^{−S}_i) − sθ₀(yᵢ|qᵢ,Hᵢ)`，`Δ_{m,i}(S) = mθ₀(i;H^{−S}_i) − m⁰_i`。
  - **接受条件**：`E(K)_i = { S : Δ_y > τ 且 Δ_m > τ }`，τ = 10⁻⁴ nats（同时要求目标自身上升与间隔扩大，二者缺一不可）。
  - 缓存最大增益：`gᵢ = max_{S∈E} Δ_{m,i}(S)`，否则 gᵢ = 0；`mcf_i = m⁰_i + gᵢ`。

- **Stage 2：在完整历史上学习反事实间隔**
  - 记 `sθ(v|i) = sθ(v|qᵢ,Hᵢ)`，`sg(·)` 为前向返回值、反向阻断梯度。
  - 辅助损失：`ℓ_ACS(i;θ) = [ mcf_i − ε − sg(sθ(yᵢ|i)) + sθ(cᵢ|i) ]₊`，ε = 0.01 nats 为容差。
  - 总损失：`L(θ;B) = L_CE(θ;B) + (λ/|B|) Σ_{i∈B∩P} ℓ_ACS(i;θ)`，L_CE 为 3 个 SID token 的平均负对数似然，λ = 1.0。
  - **梯度路由**：当 hinge 激活（学生 margin 低于 mcf−ε）时梯度为 `∇θ sθ(cᵢ|i)`，否则为 0；目标分支被 detach，只影响 hinge 是否激活。默认对完整竞争者分数求导（含与目标共享的 SID 前缀）。
  - 初始化时学生 = 参考模型，故 `ℓ_ACS(i;θ₀) = [gᵢ − ε]₊`，对绝大多数保护请求（gᵢ > ε 占比 87.8%/85.1%）在起点即激活。

- **推理**：使用原解码器（SID 约束 beam search，beam=100）与完整输入，无参考模型评估、无删除搜索。

## 3. 实验设计

- **数据集 / 场景（3 个）**
  - **工业数据集**：某大规模内容平台匿名生产日志采样；请求为自然语言查询，目标为用户点击项，历史为最近 30 次交互；训练 3 天日志、评估为相隔 1 天后的单日；**全目录检索**（SID 约束 beam search 100 条）。
  - **Qilin**（公开，search 子集）：6,192 测试请求，44,024 训练请求按用户不重叠哈希分为 39,931 训练 / 4,093 验证；一个请求可有多正例。
  - **KuaiSearch-Lite**（公开，KuaiSearch 电商搜索子集）：102,086 用户一个月记录，557,780 训练 / 28,781 验证 / 8,456 测试点击正例请求；**候选池排序**（教师强制 SID 对数概率排序），候选池 <40 时用训练集曝光（不含点击标签）确定性扩展，所有方法共用同一池。
  - SID 构造：三层、每层 2,048 码；工业用平台生产 SID，公开基准用 Qwen3-Embedding-0.6B 表征训练 RQ-VAE；6,144 个 SID token 加入词表。
- **评估指标**：Recall@1/5/10/20、NDCG@5/10/20（百分数，百分点差）；显著性用**配对用户簇 bootstrap（10,000 次重采样，双侧 95% 百分位区间不含 0 视为 p<0.05）**。
- **模型骨干（6 个，3 个家族）**：Llama-3.1-8B / 70B、Gemma-3-4B / 12B、Qwen3-8B / 14B；每个数据集/骨干的所有方法都从**同一 SFT 检查点 θ₀** 出发。
- **对比方法**：
  - **Continued CE**（匹配基线，同实例、同 batch、同步数）；
  - **CFT**（反事实 logit 对比）、**LETTER (RG)**（温度缩放排序引导生成损失）、**LTRGR**（生成 + margin 排序损失）、**S-DPO**（多负例 softmax 偏好损失，θ₀ 为冻结参考）。
- **消融与对照（约 20 余组，主要在工业数据集上，Llama-3.1-8B + Gemma-3-12B）**：
  - 增益构造：R-comp（去掉增益）、ConstantGate、Magnitude Shuffle、D-free / D-cal（按初始难度分配增益）、Generic-matched（用泛化请求重算增益）、Margin-only（去掉目标提升条件）。
  - 删除选择：Uplift-first（最大目标提升）、Influence-first（最大影响，无标签）。
  - 历史输入方式：Deletion CE、Deleted-branch、Deleted-input（并做初始 hinge 匹配控制）。
  - 梯度路由：Target-only、Symmetric、Prefix-safe。
  - 历史使用：Request-only CE、History dropout（p=0.5）、历史替换（他人匹配历史）。
  - 其他：Placebo（在每位插入随机物品而非删除）、K∈{1,2,3} 与竞争者数 M∈{1,3,5} 敏感性、3 个训练种子重复。
  - 冲突分析：按历史冲突严重度 κᵢ 分层，统计违规率（FAIL）与增益；对所选删除做约束标签分析。
