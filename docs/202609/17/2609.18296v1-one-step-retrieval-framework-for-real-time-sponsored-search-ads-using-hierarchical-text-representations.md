## 摘要
传统检索系统通常采用多阶段级联架构（MCA），其中每个模块独立优化，导致目标不一致并过早淘汰高潜力候选。最近的基于LLM的生成方法提供了端到端解决方案，但使用离散语义标识符（SID）来检索广告，这些标识符并非由基础LLM学习得到，并且在SFT期间需要记忆大量SID到广告的映射，因而对未见广告的泛化能力有限，且维护和更新成本高。SID与广告之间的一对一映射导致解码效率低下。此外，这些方法依赖小型奖励模型（例如pctr）进行相关性和排序，限制了LLM充分评估广告商业价值的能力。为应对这些挑战，我们提出了统一生成-判别-排序实时检索（ANGLE）框架。ANGLE使用LLM生成的分层文本表示，该表示由提供高层概览的商业意图和提供细粒度细节的广告摘要组成。此外，ANGLE将检索、相关性和排序直接集成在单个LLM中，通过充分利用LLM的能力实现对广告精确且高效的排序。我们将ANGLE应用于真实搜索场景，实现了消耗增长1.81%和商品交易总额（GMV）增长2.16%。我们还对ANGLE和七个基线进行了离线评估，在HR和ACR等关键指标上，ANGLE均优于所有基线。

## Abstract
Traditional retrieval systems typically use multi-stage cascading architectures (MCA), where each module is optimized independently, leading to inconsistent objectives and the premature elimination of high-potential candidates. Recent LLM-based generation methods offer end-to-end solutions but use discrete semantic identifiers (SIDs) to retrieve ads, which are not learned by the base LLM and require memorization of numerous SID-to-ad mappings during SFT, suffering from limited generalization to unseen ads, high maintenance and update costs. The one-to-one mapping between SIDs and advertisements leads to inefficient decoding. Moreover, these methods rely on a small reward model (e.g. pctr) for relevance and ranking, limiting the LLM's ability to fully assess ads' commercial value. To address these challenges, we propose A uNified Generation-discriminative-ranking reaL-time rEtrieval (ANGLE) framework. ANGLE uses LLM-generated hierarchical textual representations, which consist of commercial intent that provide high-level overviews and ad abstract that deliver fine-grained details. Additionally, ANGLE integrates retrieval, relevance, and ranking directly within a single LLM, enabling precise and efficient ranking of ads by leveraging the full capabilities of the LLM. We applied ANGLE to the real-world search scenarios, achieving a 1.81% increase in consumption and a 2.16% increase in gross merchandise volume (GMV). We also conducted offline evaluations of ANGLE and seven baselines, with ANGLE outperforming all across key metrics such as HR and ACR.

# 论文总结：ANGLE —— 基于分层文本表示的实时赞助搜索广告单步检索框架

## 1. 核心问题与研究背景

- **传统多阶段级联架构（MCA）的固有缺陷**：工业广告检索通常由「召回 → 相关性 → 粗排 → 精排」四级级联构成，各模块独立优化，导致三个问题：
  - 前序阶段的误差与遗漏会向后传播，限制最终结果质量；
  - 模块间缺乏联合优化，难以达到全局最优；
  - 每级处理大量候选，计算成本高、响应慢。
- **LLM 生成式检索的新问题**：现有方法（如 UniSearch、DSI 类工作）用 RQ-VAE 等生成的**离散语义标识符（SID）**表示广告，存在两大瓶颈：
  - SID 并非基座 LLM 原生学习的表示，SFT 阶段需强行记忆海量 SID–广告映射，对未见广告泛化差、维护与更新成本高；SID 与广告的一对一映射还导致解码效率低；
  - 相关性与排序依赖轻量级奖励模型（如 pCTR 预测器），限制了 LLM 对广告商业价值的完整评估能力。
- **本文整体含义**：提出 **ANGLE**（A uNified Generation-discriminative-ranking reaL-time rEtrieval）统一框架，用 LLM 生成的**分层语义文本**替代 SID，并把召回、相关性判别、商业排序**集成进单个 LLM**（GDR-LLM），使生成结果可直接送入精排，从而简化 MCA 流水线，实现端到端检索。

## 2. 方法论

### 2.1 核心思想
- 用 **意图–摘要对（intent–abstract, int-abs）** 作为广告的中间表示：
  - **Intent（商业意图，SText）**：压缩文本，提供高层商业类别概览，如「Role-playing Game」「Survival Challenge Game」；
  - **Abstract（广告摘要，STerm）**：从广告标题中抽取的 n-gram，保留具体事实与显著短语，如「Endless Winter」。
  - 二者组合既利用 LLM 的世界知识（对齐其生成机制），又保留细粒度事实；对新广告只需重新生成 int-abs 即可更新索引，无需重训模型，且可解释性强。
- **GDR-LLM**：单个 LLM 同时承担生成、判别、排序三种能力；用户 query 输入后先生成 intent，再生成与该 intent 对齐的 abstract，通过倒排索引取回广告，**跳过传统相关性与粗排模块**，直接进入精排展示。

### 2.2 训练目标（三个损失，加权求和）
- **生成损失 $L_{gen}$**：标准交叉熵，$L_{gen}=-\sum_{t=1}^{T}\log P(y_t|y_{<t},x)$，学习从 query 生成 intent-abstract 文本。
- **判别损失 $L_{dis}$**：在输入 prompt 末尾附加 `[CLS]`，取其表示 $h_{[CLS]}$ 经 MLP 得标量分数 $s=f(h_{[CLS]})$，经 sigmoid 得相关概率 $\hat p=\sigma(s)$，用二元交叉熵 $L_{dis}=-[y\log\hat p+(1-y)\log(1-\hat p)]$ 训练，标签来自线上点击/曝光日志。
- **排序损失 $L_{dpo}$**：采用 DPO，用偏好三元组 $(x,y_w,y_l)$（胜出/落败广告按线上实际消耗排序），$L_{dpo}=-[\log\sigma(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}-\beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)})]$，使模型对高商业价值广告赋予更高相对概率。
- **总损失**：$L_{model}=\alpha L_{gen}+\beta L_{dis}+\gamma L_{dpo}$。

### 2.3 训练数据构造
- 对 query $q$ 从线上日志取相关广告集 $A$（有点击）与不相关广告集 $B$。
- 用 $A$ 训练生成损失；$L_{dis}$ 与 $L_{dpo}$ 同时使用 $A$、$B$。
- 将 $A\cup B$ 按商业价值降序得候选列表 $C$；$c_i\in A$ 时生成损失 mask 置 1、相关性标签 1，$c_i\in B$ 时 mask 置 0、标签 0，最终生成损失为 mask 与 $L_{gen}$ 的逐元素乘积。

### 2.4 广告索引构建
- 用 LLM 为库内所有广告生成语义意图，按行业去重清洗后得到约 **70 万个**粗粒度商业意图类别；
- 在这些意图类别上对广告语料做**约束束搜索**，再由 LLM 为每条广告自由生成 abstract，构成 intent × abstract 分层表示并建立**倒排索引**；
- 新广告按「约束生成 intent + 自由生成 abstract」流程即时入库，索引每小时更新，过期广告及时移除。

### 2.5 检索：动态约束束搜索（DCBS）
- 对 int-abs 对构建前缀 Trie，从 `[BOS]` 开始先生成 intent token；
- 解码过程中实时校验每个 abstract 是否关联**有效广告**：无有效广告的 abstract 立即剪枝；若某 intent 下所有 abstract 均无效，则该 intent 路径终止；
- 有效 int-abs 对被重组成动态约束树继续解码，且**有效集合随用户特征动态变化**（如性别定向的广告对不匹配用户即无效），从而把「定向过滤」前移到生成阶段，保证输出即有效广告，减少下游浪费；
- 生成完所有有效 int-abs 后，由判别头输出 query 与各 int-abs 的相关性分数评估质量。

## 3. 实验设计

- **数据集 / 场景**：

- **对比基线（7 个）**：

  - LLM 生成式检索类：**Qwen-1.8B**、**Hunyuan-2B**、**DSI-1B**（直接生成商业关键词，并用 HNSW 映射到库内最相似关键词以规避无效输出）。

## 6. 主要结论与发现

- **离线结果**：ANGLE-1B 在全部指标上取得 SOTA——HR@10 0.1961、HR@50 0.4834、HR@100 0.5273、MAP 0.4834、ACR 69.17%，显著优于 7 个基线（最强基线 ACR 为 DSI-1B 的 55.49%，但 DSI 的 HR/MAP 极低）。
- **在线结果**：WTS 场景消耗 **+1.81%**、GMV **+2.16%**、点击 **+1.50%**、转化 **+1.44%**、曝光 **+2.49%**；QBS 场景消耗 **+6.57%**、GMV **+5.01%**、点击 **+6.11%**、曝光 **+7.82%**。ANGLE 已作为排序队列的补充在 WTS、QBS 全量应用。
- **消融结论**：移除 Intent、Abstract、DCBS 或 GDR-LLM 任一组件都会造成性能下降，其中 **DCBS 的贡献最大**（去掉后 HR@100 从 0.5273 降至 0.2975，ACR 从 69.17% 降至 55.14%），说明动态约束解码对有效性保障至关重要。
- **总体判断**：分层文本表示可缓解 SID 的泛化与可解释性问题，单 LLM 统一生成–判别–排序能缓解 MCA 的目标不一致与误差传播。

## 7. 优点

- **表示层面**：用自然语言分层文本（intent × abstract）替代离散 SID，充分利用 LLM 预训练知识，无需记忆 SID–广告映射；新广告只需生成 int-abs 即可入索引，**免重训、易维护、可解释**。
- **架构层面**：在单个 LLM 内统一生成、判别、排序三种能力，配合 DPO 直接注入商业价值偏好，跳过相关性/粗排模块，**简化流水线并减少阶段间误差传播**。
- **工程落地**：DCBS 将定向过滤前移至解码阶段，保证生成结果即有效广告，既提升生成效率又避免无效检索；索引按小时更新，支持新广告快速上线。
- **验证扎实度**：同时提供离线多指标对比、在线 A/B 业务指标与组件消融，且在线覆盖两个真实场景，工业说服力较强。
- **延迟控制合理**：通过限制 intent/abstract token 长度（3/4）与束宽、FP8 量化，将端到端延迟控制在 60 ms 内，满足在线广告的严苛时延要求。
