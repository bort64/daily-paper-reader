## 摘要
生成式推荐将物品预测重新表述为语义标识符生成，但剧集内容引入了一种根本不同的设定：目标由叙事演进而非用户偏好决定。该任务要求模型理解多模态故事线推进，同时应对冗余视觉上下文和昂贵的显式推理生成所带来的效率挑战。我们提出 NarraLite，一个高效的多模态生成式推荐框架，联合压缩感知与推理。具体而言，渐进式谱压缩有选择地将长视觉上下文蒸馏为紧凑的叙事相关证据，在保留转场关键信息的同时减少冗余视觉计算。潜在叙事推理引入上下文路由的潜在推理标记，并将其上下文化表示与未来续写语义对齐，从而无需自回归解码文本推理依据即可实现隐式叙事推断。我们进一步建立了一个用户无关的多模态基准，用于跨 UGC、PGC 和 OOD 设定下的短剧续写。大量实验表明，NarraLite 在续写准确率、叙事连贯性和鲁棒性上持续优于现有方法，同时实现了良好的准确率—效率权衡。

## Abstract
Generative recommendation reformulates item prediction as semantic identifier generation, yet episodic content introduces a fundamentally different setting where the target is determined by narrative evolution rather than user preference. This task requires models to understand multimodal storyline progression while addressing the efficiency challenges caused by redundant visual contexts and costly explicit reasoning generation. We propose \textbf{NarraLite}, an efficient multimodal generative recommendation framework that jointly compresses perception and reasoning. Specifically, Progressive Spectral Compression selectively distills long visual contexts into compact narrative-relevant evidence, preserving transition-critical information while reducing redundant visual computation. Latent Narrative Reasoning introduces context-routed latent reasoning tokens and aligns their contextualized representations with future continuation semantics, enabling implicit narrative inference without autoregressively decoding textual rationales. We further establish a user-agnostic multimodal benchmark for short-form drama continuation across UGC, PGC, and OOD settings. Extensive experiments demonstrate that NarraLite consistently improves continuation accuracy, narrative coherence, and robustness over existing approaches, while achieving a favorable accuracy--efficiency trade-off.

## 1. 核心问题与整体含义
- **研究背景**：生成式推荐通常将物品预测转化为语义标识符（SID）生成，但现有方法主要面向用户偏好建模。
- **核心问题**：在短剧等“剧集式/情节式内容”中，推荐目标不是用户兴趣匹配，而是预测“故事线自然延续的下一个片段”，目标由叙事演进决定。
- **关键挑战**：
  - 长视觉上下文高度冗余：连续帧重复场景、人物、背景，但仅有少量事件决定后续转场。
  - 显式思维链（CoT）推理虽可增强结构化推断，但需自回归生成冗长中间理由，增加延迟，且对推荐本身并非必要。
- **整体含义**：论文将多模态生成式推荐拓展到叙事感知场景，提出兼顾“感知压缩”和“隐式推理”的框架 NarraLite，并构建用户无关的多模态短剧续接基准。

## 2. 方法论
### 2.1 核心思想
- NarraLite 联合压缩感知与推理：
  - **渐进式谱压缩（PSC）**：从长视觉上下文中选择紧凑、与文本叙事互补、转场关键的视觉证据。
  - **潜在叙事推理（LNR）**：用上下文路由的潜在推理 token 建模未来叙事倾向，避免显式生成文本推理链。
- 最终将文本 token、压缩视觉 token、潜在叙事 token 组成多模态前缀，输入多模态 LLM 生成目标片段 SID。

### 2.2 渐进式谱压缩 PSC
- **文本条件谱调制**：
  - 对文本 token 做门控池化，得到叙事条件，并投影到视觉空间。
  - 对每帧视觉 patch 做 2D DCT，利用 MLP 生成样本特定的频率门，再经 IDCT 回视觉空间。
  - 作用：让文本叙事信息自适应保留粗粒度场景结构或细粒度视觉细节。
- **叙事感知 token 选择**：
  - 对每个 patch 计算相关性分数。
  - 锚帧直接经 ST Gumbel Top-K 选 `Ka` 个 patch。
  - 后续帧先选候选池 `Kc`，再用“1 − 与已选 patch 的最大余弦相似度”计算多样性分数，最终选 `Kf` 个。
  - 拼接并投影为 `Kv` 个压缩视觉 token，默认 `Kv=30`。
- **效果**：减少冗余视觉计算，同时保留叙事转场关键信息。

### 2.3 潜在叙事推理 LNR
- **上下文路由专家 token 库**：
  - 对文本与压缩视觉 token 做均值池化和归一化，得到上下文表示。
  - 轻量 router 预测各专家相关性。
  - 专家 token 库为可学习连续 token；训练时用 ST Gumbel Top-K 选 `Kr` 个，推理时用确定性 Top-K。
  - 默认 `Kr=2`。
- **目标引导潜在对齐**：
  - 训练时，多模态 LLM 处理“压缩前缀 + 真实续写 SID”，抽取潜在位置的隐状态。
  - 学生表示：对潜在位置隐状态均值池化并归一化。
  - 教师表示：冻结教师模型编码真实续写文本描述，均值池化、归一化并 stop-gradient。
  - 用 InfoNCE 对齐学生潜在表示与教师续写语义，促使潜在 token 编码未来叙事方向。
- **训练目标**：`L = L_SID + λ L_NCE`，即 SID 生成损失 + 潜在对齐损失。

### 2.4 推理流程
- 移除教师分支和对齐目标。
- PSC 与 LNR 使用确定性 Top-K。
- 多模态 LLM 通过 trie 约束解码生成有效 SID，再映射回候选片段。
- 相比全视觉 token，前缀规模从 `Mi + Pi` 降为 `Mi + Kv + Kr`；潜在 token 并行处理，而非自回归生成推理链。
