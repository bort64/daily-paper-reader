## 摘要
基于语义 ID（Semantic ID, SID）的生成式推荐将每个物品表示为一个离散 token 序列，并通过生成用户可能希望交互的物品的 SID 来进行推荐。该领域两种主流范式通常都需要逐个 token 地进行生成：自回归模型从左到右解码 token，而非自回归模型虽并行解码，但仍需多轮细化才能保持竞争力。因此，二者通常对每个物品都要进行多次前向传播，这一开销在延迟敏感的推荐系统中难以承受。我们提出，能否在单次前向传播中生成一个物品，并通过一个我们称为“平均概率速度”的新视角来回答这一问题。我们将 SID 生成视为 token 生成概率的流动，并用其在整个生成过程中的平均速度来刻画。我们证明，该平均速度完全由每个 token 的平均生成概率决定。因此，我们使用双向 Transformer 在单次前向传播中直接参数化并学习所有 token 的概率。由于这些概率在不同位置上是独立生成的，token 之间的连贯性会丢失，我们进一步设计了一种双层流对比目标，以恢复一个物品的 token 之间的连贯性。它在 token 级别和 SID 级别上将目标 SID 与负 SID 进行对比。token 级别将目标 token 的生成概率排在负 SID 的 token 生成概率之上，而 SID 级别则将每个 SID 的 token 作为一个整体物品进行评分，以捕捉每个物品的 token 连贯性。大量实验表明，我们的模型不仅能以高得多的效率生成推荐（相比第二快的 AR/NAR 方法加速 8.39–10.04 倍），而且取得了更优的推荐准确率（相比第二优方法平均提升 7.77%）。

## Abstract
Semantic ID (SID) based generative recommendation represents each item as a sequence of discrete tokens, and recommends by generating the SID of the item a user would like to interact with. Both dominant paradigms in this domain generally pay for generation token by token: autoregressive models decode the tokens left-to-right, while non-autoregressive models decode in parallel yet still need multiple rounds of refinement to stay competitive. Therefore, both generally spend multiple forward passes per item, a cost that is prohibitive in latency-sensitive recommender systems. We ask whether an item can be generated in a single forward pass, and answer it through a new perspective which we call average probability velocity. We view SID generation as a flow of token generation probabilities and characterize it by its average velocity over the whole generation process. We prove that this average velocity is fully determined by the average generation probability of each token. Therefore, we directly parameterize and learn the probabilities of all tokens in a single forward pass with a bidirectional Transformer. As these probabilities are generated independently across positions and the coherence among tokens is lost, we further design a dual-level flow contrastive objective to restore the coherence among an item's tokens. It contrasts the target SID against negative SIDs at both the token and SID levels. The token level ranks the generation probabilities of the target tokens above those of negative SIDs, while the SID level scores the tokens of each SID as a whole item for capturing token coherence of each item. Extensive experiments show that our model not only generates recommendations far more efficiently ($8.39-10.04\times$ speedup over the second-fastest AR/NAR method) but also attains superior recommendation accuracy ($7.77\%$ average improvement over the second-best.

## 2. 方法论

### 2.1 核心思想：平均概率速度（Average Probability Velocity）

- 将 SID 生成视为**token 生成概率的流**：从全掩码源 `x0 = [m,…,m]` 流向目标 SID `x1 = [c¹,…,c^L]`。
- 采用**凸插值路径**（convex interpolant）：逐位置线性混合两端点
  `p_t(x^l | x0, x1) = (1−κ_t)δ_{x0}(x^l) + κ_t δ_{x1}(x^l)`，其中 κ_t 为调度器（κ_0=0, κ_1=1, κ̇_t ≥ 0），衡量"目标 SID 被决定的程度"。
- **瞬时概率速度**（条件形式，denoiser 模式）：
  `v^l_τ(x^l, z | x1) = [κ̇_τ/(1−κ_τ)]·[δ_{x1}(x^l) − δ_z(x^l)]`
  —— 把概率质量推向目标 token、从当前状态抽离；该式在附录 C.1/C.2 中被证明是合法的 CTMC 生成元（列和为 0、非对角非负）。
- **关键洞察**：由于传输方向 `[δ_{x1} − δ_z]` **不随 τ 变化**，对速度在区间 [r,t] 上取平均退化为只对一个**标量速率**取平均，从而可闭式积分：
  `v̄^l_{r,t} = λ_{r,t}·[δ_{x1} − δ_z]`，其中 **`λ_{r,t} = 1/(t−r)·ln[(1−κ_r)/(1−κ_t)]`**。
  这正是不需要连续空间 Jacobian–向量积恒等式的原因。
- **边缘化**（推理时 x1 未知）：用 `κ̇_τ/(1−κ_τ)` 加权的**时间平均后验**替换目标指示函数：
  `v̄^l_{r,t}(x^l,z) = λ_{r,t}·[ p̄_{1|r,t}(x^l|z) − δ_z(x^l) ]`
  其中 `p̄_{1|r,t}(x^l|z)` 是区间加权的平均去噪后验 —— **它本身就是推荐预测器**，单步生成直接从中读出推荐结果。
- 注意：λ_{r,t} 在 t→1 时发散，仅作推导中间量，**不参与优化与生成**。

### 2.2 参数化与训练

- **网络**：轻量双向 Transformer —— **1 层编码器**编码用户历史 H，**4 层解码器**从 L 个 mask query 出发，对每个位置输出对应码本 C_l 上 M 个 token 的分布，即 `p̄_{1|r,t}(x^l | z, H, θ)`。
- **时间采样策略**：固定终端时间 `t = 1`（单步推理总是指向 t=1 的干净 SID）；源时间 r 混合采样：以概率 **ρ 取 r=0**（全掩码，与推理条件完全一致），以 1−ρ 从 U(0,1) 采样（部分已提交的 SID），后者既使平均速度成为 r 的非退化函数，又提供"已知部分位置补全其余位置"的条件监督。
- **从逐 token 似然到对比监督**：基础损失为逐 token 交叉熵（λ_{r,t} 因两项共享而省略）；由于推荐中**未交互物品本身是信息**，将其替换为在采样 SID 集合 S 上的 **flow contrastive loss**（对目标 SID 与 N 个随机负 SID 的整句对数概率做 softmax 归一化）。

### 2.3 双层流对比目标（应对 CH2）

最终损失 `L` = **token 级项** + **SID 级项**：

- **token 级**：`log softmax( Σ_l log p̄_{1|r,t}(c^l | x_r,H,θ) )`，在 S 上归一化，锐化每个位置的边缘预测，使目标 token 概率高于负 SID token。
- **SID 级**：`log softmax( ⟨u, v_{x1}⟩ )`，其中
  - `u = MLP(Cat(h1,…,hL))` 为**用户/序列侧**联合表示（由 L 个解码器隐状态拼接而成，汇总"用户将交互的物品"）；
  - `v_c = MLP(Cat(e_{c1},…,e_{cL}))` 为**物品侧** SID 表示；
  - 以余弦相似度打分，把整条 SID 当作**一个整体物品**评分，从而恢复被独立解码丢弃的 token 组合依赖。
- 二者互补：token 级负责逐位置准确；SID 级负责联合赋值与排序判别力。因 v_c 只依赖物品 SID、与用户无关，全量 `{v_c}` 可离线算一次并复用，SID 级项推理成本仅一次矩阵乘。

### 2.4 推理流程

1. 起点为全掩码序列 `x0 = [m,…,m]`；
2. **单次前向**同时得到 L×M 的平均生成概率表 `p̄_{1|0,1}(·|x0,H,θ)` 与用户表示 u；
3. 在 SID 前缀树的合法轨迹集合 T 上做 **trie 约束生成**，打分函数与训练对齐：
   `score(c) = softmax( Σ_l log p̄_{1|0,1}(c^l|x0,H,θ) ) + softmax( ⟨u, v_c⟩ )`（softmax 在 T 上取）；
4. 返回得分最高的 K 个合法 SID。
- **分词器选择**：采用 **OPQ**（而非 RQ-VAE/RQ-Kmeans），因为单步生成不以前序 token 为条件，与 OPQ 的**相互独立子空间**天然契合；L=4，每码本 M=256。
