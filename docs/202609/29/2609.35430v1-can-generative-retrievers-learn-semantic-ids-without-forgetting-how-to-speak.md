## 摘要
生成式检索（GR）通过生成文档语义标识符（SID）实现端到端检索。然而，仅面向检索的微调可能使预训练语言模型过度特化于SID预测，严重扭曲其自然语言分布，并限制其适用于既需检索文档又需生成自然语言响应的交互式系统。我们提出SpeakGR，一个双目标框架，可在学习SID的同时保持语言生成能力。它将监督式SID学习与保持说话能力的正则化相结合：一种同策略蒸馏目标，在由学生模型生成的前缀上，利用原始文本词表上的前向KL，使当前模型与原始模型的冻结副本对齐。我们进一步提出Adaptive SpeakGR，它根据观测到的语言漂移动态调整保持强度。与仅SFT相比，SpeakGR在MS MARCO上将WikiText-2前向KL降低81.3–93.8%，在Natural Questions（NQ）上降低81.2–85.2%，同时在三种不同LLM上保持有效检索。在大多数设置下，Adaptive SpeakGR相比SpeakGR进一步提升检索效果，同时保持显著低于仅SFT的语言漂移。

## Abstract
Generative retrieval (GR) enables end-to-end retrieval by generating document semantic identifiers (SIDs). However, retrieval-only fine-tuning can over-specialize pretrained language models to SID prediction, substantially distorting their natural-language distribution and limiting their suitability for interactive systems that must both retrieve documents and generate natural-language responses. We introduce SpeakGR, a dual-objective framework that learns SIDs while preserving language generation. It combines supervised SID learning with speak-preserving regularization: an on-policy distillation objective that aligns the current model with a frozen copy of the original model on student-generated prefixes using forward KL over the original text vocabulary. We further propose Adaptive SpeakGR, which dynamically adjusts the preservation strength based on observed language drift. Compared with SFT-only, SpeakGR reduces WikiText-2 forward KL by 81.3-93.8% on MS MARCO and 81.2-85.2% on Natural Questions (NQ) while retaining effective retrieval across three different LLMs. Adaptive SpeakGR further improves retrieval over SpeakGR in most settings while maintaining substantially lower language drift than SFT-only.

# 论文总结：Can Generative Retrievers Learn Semantic IDs Without Forgetting How to Speak?

## 1. 核心问题与整体含义
- **研究动机**：生成式检索（Generative Retrieval, GR）将检索建模为自回归生成文档语义标识符（SID），通常通过扩展预训练语言模型词表并微调实现。
- **核心问题**：仅以检索目标进行 SID 微调，会使模型过度专精于 SID 预测，严重扭曲其预训练自然语言分布，导致“会检索但不会说话”。
- **整体含义**：交互式搜索系统往往需要同一模型既能检索文档，又能回答、总结、引用或进行澄清追问。若检索微调破坏语言生成能力，则模型难以支持端到端交互。
- **论文主张**：SID 学习与语言保持并非不可兼得；通过双目标训练，可让模型在学习检索的同时显著减少语言漂移。

## 2. 方法论
- **问题形式化**：
  - 冻结预训练策略 \(\pi_0\)，学生策略 \(\pi_\theta\) 初始化为 \(\pi_0\)，词表扩展为 \(V_{\text{text}} \cup V_{\text{SID}}\)。
  - 文档由 RQ-VAE 等量化为长度 \(L\) 的 SID：\(z(d)=(z_1,\dots,z_L)\)。
  - 检索目标为层级受限的交叉熵损失 \(L_{\text{ret}}\)，只在有效 SID 词表 \(V_\ell\) 上归一化并预测。
- **语言漂移度量**：
  - 将学生模型在自然语言前缀上的下一词分布限制到原文本词表并重归一化。
  - 以 WikiText-2 前缀分布计算与冻结模型的前向 KL：\(\Delta_{\text{lang}} = \mathbb{E}_{s\sim\mu_{\text{text}}}[D_{\text{KL}}(\pi_0 \| \pi_\theta^{V_{\text{text}}})]\)。
- **SpeakGR 核心思想**：
  - 联合优化检索损失与“保持说话”正则项：\(L_{\text{SpeakGR}} = L_{\text{ret}} + L_{\text{Speak}}\)。
  - \(L_{\text{Speak}}\) 受同策略蒸馏（On-Policy Distillation）启发：当前学生屏蔽 SID logits，仅从文本词表采样续写；冻结原模型与学生在相同前缀上给出下一词分布。
  - 在原始文本词表上使用前向 KL，使学生分布靠近冻结教师分布，且梯度不经过离散采样。
- **Adaptive SpeakGR**：
  - 不固定正则强度，而是根据观测到的保持 KL 动态调整系数 \(\lambda_t\)。
  - 维护保持 KL 的 EMA \(K_t\)，计算归一化偏差 \(e_t=\text{clip}(K_t/\epsilon-1,-c,c)\)，经死区 \(\delta\) 后更新 \(\lambda_{t+1}=\text{clip}_{[\lambda_{\min},\lambda_{\max}]}(\lambda_t \exp(\eta \tilde e_t))\)。
  - 保持强度随语言漂移增大而增强，随漂移减小而放松。
- **推理流程**：SID 生成受层级词表与文档 trie 约束，解码得到有效文档标识符；同一 SID 桶内文档可用额外编码器重排。

## 6. 主要结论与发现
- **SFT-only 会严重遗忘语言能力**：
  - 六个设置中，WikiText 前向 KL 为 5.545–13.005，PPL 急剧上升，Top-1 一致率极低，说明检索微调显著扭曲预训练语言分布。
- **SpeakGR 大幅降低语言漂移**：
  - 相比 SFT-only，SpeakGR 在 MS MARCO 上将 FKL 降低 81.3–93.8%，在 NQ 上降低 81.2–85.2%。
  - PPL 与 Top-1 一致率同样显著改善，同时检索效果总体保持有效。
- **Adaptive SpeakGR 多数设置提升检索**：
  - 在六个设置中的五个提升检索，同时保持远低于 SFT-only 的语言漂移。
  - 例如 MS MARCO + Qwen3-1.7B：Adaptive R@10 为 0.6745，高于 SFT-only 的 0.6696，而 FKL 从 11.222 降至 1.841。
- **与语言保持基线对比**：
  - Offline Replay 保护有限；ORBIT 强依赖阈值，强纠正会显著损害检索。
  - 没有方法在所有操作点全面占优；SpeakGR 提供了目标函数层面的直接替代，Adaptive 提供更偏检索的工作点。
- **机制发现**：
  - 语言退化主要来自文本 token 相对概率变化，而非概率质量大量泄漏到新增 SID token。
  - 保持正则显著降低中后层方向漂移，但仍允许内部表示适应检索任务。
- **敏感性发现**：
  - Adaptive 对 \(\epsilon\) 的响应非单调；过严的 \(\epsilon=0.25\) 反而同时损害检索与保持。
  - 固定 \(\lambda\) 在较宽范围内都能有效降低 FKL，说明保持效果对固定权重较稳健。

- **核心贡献明确**：论文把生成式检索微调中的“语言遗忘”问题显式提出，并通过双目标训练给出可操作方案，问题定义和方法设计具有较强针对性。
