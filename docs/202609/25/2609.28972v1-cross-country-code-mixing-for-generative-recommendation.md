## 摘要
现代电商平台上的跨国推荐通常在不同市场之间采用互不相交的用户和物品ID空间进行部署，这消除了传统跨域方法所依赖的共享锚点。生成式推荐（GR）通过将物品映射到共享的标记空间并训练统一模型来缓解这一问题，但现有方法仍将行为序列严格限定为特定国家，因此知识迁移仅发生在参数层面，在数据层面仍然缺失。受多语言自然语言处理中语码转换语料的启发，我们提出CMRec，一种跨国GR框架，通过双重约束、上下文感知的代码混合在数据层面注入跨国监督。CMRec首先从多模态内容以及跨国家的行为共现中学习共享语义码本。然后，它使用该码本通过满足静态（内容）和动态（如价格、受众、流行度）约束的标记级替换来合成混合国家序列。最后，它引入一种上下文感知损失，根据混合样本在当前序列中的合理性对其进行重新加权。在两个真实世界多国家数据集和一次在线A/B测试上的实验表明，CMRec在数据稀疏国家显著提升了推荐质量，同时保持数据丰富国家的性能，在大型电商平台上实现了+1.77%的广告收入和+2.64%的订单量。

## Abstract
Cross-country recommendation on modern e-commerce platforms is typically deployed with disjoint user and item ID spaces across markets, removing the shared anchors that conventional cross-domain methods rely on. Generative recommendation (GR) mitigates this by mapping items into a shared token space and training a unified model, but existing approaches keep behavior sequences strictly country-specific, so knowledge transfer occurs only at the parameter level and remains absent at the data level. Inspired by code-switching corpora in multilingual natural language processing, we propose CMRec, a cross-country GR framework that injects cross-country supervision at the data level via dual-constrained, context-aware code-mixing. CMRec first learns a shared semantic codebook from multi-modal content and behavioral co-occurrence across countries. It then uses this codebook to synthesize mixed-country sequences via token-level substitutions that satisfy both static (content) and dynamic (e.g., price, audience, popularity) constraints. Finally, it introduces a context-aware loss that reweights mixed samples according to their plausibility in the current sequence. Experiments on two real-world multi-country datasets and an online A/B test show that CMRec substantially improves recommendation quality in data-sparse countries while preserving performance in data-rich countries, achieving +1.77% advertising revenue and +2.64% orders on a large-scale e-commerce platform.

- **研究背景**：现代电商平台通常以国家为单位独立部署，各国用户 ID 与商品 ID 空间完全不相交，行为序列也严格按国家隔离。传统跨域推荐依赖共享用户、共享物品或人工锚点，但在跨国场景中这些锚点天然缺失。
- **现有生成式推荐的局限**：生成式推荐（GR）通过共享语义 token 空间和统一模型，将知识迁移从 ID 级提升到参数级；但训练序列仍按国家划分，跨国家知识迁移在**数据级**仍然缺失，大国丰富信号难以直接惠及小国。
- **核心动机**：受多语言 NLP 中“语码转换”（code-switching）语料启发，作者希望为跨国 GR 构造类似的“混合国家行为序列”，在数据层面注入跨国监督。
- **关键挑战**：
  - 不存在天然的跨国混合序列，必须通过替换合成；
  - 仅靠内容相似度选替代品会忽略行为与市场信号；
  - 即使物品级合理，也可能与用户当前上下文意图冲突。

## 2. 方法论：CMRec

### 2.1 核心思想

CMRec 是一个跨国生成式推荐框架，通过**双约束、上下文感知的代码混合**，在 token 级合成混合国家序列，并让模型根据上下文合理性对混合样本重加权。整体包含三部分：

1. 行为与内容共同驱动的共享语义码本；
2. 双约束跨国代码混合；
3. 上下文感知自适应重加权。

### 2.2 关键技术细节

- **共享语义码本**：
  - 用跨国家共享的多模态编码器（Qwen-VL-32B）将商品标题、图像等编码为内容嵌入 \(m_i\)。
  - 训练一个跨国家联合的行为驱动 i2i 对齐模型，采用两塔 + sampled softmax：用户塔编码行为序列，物品塔编码内容嵌入，负样本池跨国家共享。
  - 目标函数 \(L_{i2i}\) 使内容相似且行为共现模式相似的商品在嵌入空间对齐。
  - 再用残差量化器（如 RQ-VAE）将商品嵌入量化为共享 token 序列 \(q_i\)，既作为 GR tokenizer，也作为跨国替换的共同语义空间。

- **双约束跨国代码混合**：
  - 每个商品附加 side-information 嵌入 \(s_i\)，覆盖价格、折扣、受众、流行度等动态属性；各属性按国家分位数桶离散化，使不同国家数值可比。
  - 对商品 \(i\)，跨国家候选集定义为：
    - token 序列 Hamming 距离 \(d(q_i,q_j) \le \tau\)；
    - side-info 余弦相似度 \(sim(s_i,s_j) \ge \tau_s\)。
  - 即同时满足**静态内容约束**与**动态市场约束**。
  - 给定训练对 \((x,y)\)，算子 \(\Phi_{\tau,\tau_s,k}\) 以比例 \(k\) 随机替换 \(x\) 和目标 \(y\) 中的位置，生成混合对 \((x',y')\)。
  - 对原始数据 \(D\) 以比例 \(p\) 子采样并施加替换，形成混合孪生集 \(D'\)，\(p\) 控制混合强度。

- **上下文感知自适应重加权**：
  - 定义上下文条件可替换性：
    \[
    w(y,y'|x)=sg\left[\frac{P_\theta(y'|x)}{P_\theta(y|x)+P_\theta(y'|x)}\right]\in[0,1]
    \]
  - 在**原始上下文 \(x\)** 下评估替换目标 \(y'\)，避免早期模型对分布外混合序列响应不稳定。
  - 使用 stop-gradient，使 \(w\) 只影响损失权重，不接收梯度。
  - 最终训练目标为原始样本负对数似然 + \(\lambda\) 加权的混合样本负对数似然：
    \[
    L(\theta)=-\sum_{(x,y)\in D}\log P_\theta(y|x)-\lambda\sum_{(x',y')\in D'} w(y,y'|x)\log P_\theta(y'|x')
    \]
  - 早期权重较均匀，后期模型自动降低上下文不合理替换的权重。
