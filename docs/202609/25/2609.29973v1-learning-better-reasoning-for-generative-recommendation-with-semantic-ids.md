## 摘要
生成式推荐将物品检索重构为序列生成，使统一模型能够根据用户交互历史直接生成下一个物品。语义ID通过将每个物品表示为离散编码，进一步使该范式兼具有效性与可扩展性，并支持语义相关物品之间的知识共享。近期研究在语义ID生成之前引入显式推理，帮助模型总结用户兴趣并推断可能的偏好转移。然而，推理本身并非必然有益：不准确或信息量不足的推理可能会误导后续的物品生成，并最终降低推荐性能。这引出一个核心挑战：推荐系统如何选择并学习有效的推理轨迹，并从自身生成结果中逐步演化出更好的推理？在本工作中，我们提出Evo-Rec，一个三阶段框架，用于学习更好的推理，并通过强化学习进一步增强该推理。首先，我们将语义ID与其文本和行为上下文对齐，使模型能够理解并生成物品标识符。其次，我们采样多个候选推理轨迹，并保留那些能够提升对真实目标物品预测的轨迹，通过监督微调提供更强的推理初始化。第三，我们通过强化学习进一步优化推理策略，并结合受目录约束的物品生成与排序感知的推荐反馈。在三个Amazon Review基准上的实验表明，Evo-Rec在所有评估指标上均持续优于判别式、生成式以及推理增强的推荐模型。这些结果证明了我们的框架在为基于SID的生成式推荐学习更好的推理方面的有效性。

## Abstract
Generative recommendation reformulates item retrieval as sequence generation, allowing a unified model to directly generate the next item from a user's interaction history. Semantic IDs further make this paradigm effective and scalable by representing each item as discrete codes, enabling knowledge sharing among semantically related items. Recent studies introduce explicit reasoning before Semantic-ID generation, helping models summarize user interests and infer possible preference transitions. However, reasoning is not inherently beneficial: Inaccurate or uninformative reasoning may mislead subsequent item generation and ultimately degrade recommendation performance. This raises a central challenge: how can a recommender select and learn effective reasoning traces and progressively evolve toward better reasoning from its own generations? In this work, we propose Evo-Rec, a three-stage framework for learning better reasoning and further enhancing it through reinforcement learning. First, we align Semantic IDs with their textual and behavioral contexts, enabling the model to understand and generate item identifiers. Second, we sample multiple candidate reasoning traces and retain those that improve the prediction of the ground-truth item, providing a stronger reasoning initialization through supervised fine-tuning. Third, we further optimize the reasoning policy through reinforcement learning with catalog-constrained item generation and ranking-aware recommendation feedback. Experiments on three Amazon Review benchmarks show that Evo-Rec consistently outperforms discriminative, generative, and reasoning-enhanced recommenders across all evaluation metrics. These results demonstrate the effectiveness of our framework in learning better reasoning for SID-based generative recommendation.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景演进**：序列推荐长期由判别式范式主导（GRU4Rec、Caser、SASRec），将历史压缩为用户向量并与物品嵌入表打分。该范式把物品视为相互独立的索引，嵌入表随目录线性增长、语义相关物品间不共享表示、长尾与冷启动物品难以定位。
- **生成式推荐转向**：以 TIGER 为代表的 SID（Semantic ID）方法用 RQ-VAE 将物品内容量化成短离散码序列，把推荐改写为自回归序列生成，使语义相近物品共享码前缀，泛化不再依赖交互次数。
- **推理增强的兴起**：一旦检索变成语言模型上的序列生成，推荐便继承了 LLM「先推理再作答」的能力。已有工作分为隐空间推理（ReaRec 等）与显式自然语言推理（R²ec、Rec-R1、SIDReasoner）。
- **核心痛点**：现有工作重在「使能推理」，却忽视**推理轨迹的质量**。同一交互历史下，不同推理可能总结不同偏好侧面、推断不同转移、甚至给出冲突决策；看似语言上合理的推理可能对下一物品预测具有误导性。不加区分地训练会引入噪声监督，并进一步污染后续强化学习。
- **RL 阶段的次生问题**：既有方法多用最终结果的精确匹配（exact SID match）作为反馈。在全目录排序问题中，把真实物品从第 100 名提升到第 2 名与使其完全落在检索集外，在 top-1 精确匹配奖励下收益相同——信号过于粗糙；且当推理与物品生成被当作单一轨迹优化时，推理质量与 SID 生成的随机性相互纠缠。
- **核心研究问题**：生成式推荐器如何**识别更优的推理轨迹**，并从自身生成结果中**持续改进推理策略**？
- **论文视角**：有用的推理应当提升真实物品相对于「仅凭历史预测」的似然，并最终把该物品推向目录排序前列。由此衍生两种互补监督：RL 之前按**预测效用**筛选候选推理；RL 期间按推理所诱导的**下游排序**给予排序感知反馈。

## 2. 方法论：Evo-Rec 三阶段框架

### 2.1 问题形式化

- 物品目录 I，交互序列 S=(i₁,…,i_T,i_{T+1})，历史 H=(i₁,…,i_T)，目标为预测 i_{T+1}。
- 分词器 φ: I → C^L，将物品映射为 L 级离散码；历史 h=[φ(i₁);…;φ(i_T)]，目标 y=φ(i_{T+1})。
- 引入中间推理序列 z=(z₁,…,z_M)，建模联合分布 p_θ(z,y|h)=p_θ(z|h)·p_θ(y|h,z)，优化目标为对 z 边缘化后的 p_θ(y|h)。

### 2.2 阶段一：SID 与语言/行为的对齐

- 用 RQ-VAE（L 个码本）将物品文本元数据编码量化得到 SID，SID token 追加进 LLM 词表并随机初始化嵌入，然后在混合任务上微调。
- **八类任务**：① SID历史→SID；② SID历史→标题；③ 标题历史→SID；④ 标题历史→标题；⑤ 标题↔SID 双向翻译；⑥ 含 SID 的物品叙述；⑦ 含 SID 的用户序列叙述；⑧ 通用推理（防止通用能力遗忘）。
- 统一自回归目标 L_align = −E[Σ_t m_t(x)·log p_θ(x_t|x_<t)]，其中 m_t 为损失掩码：预测/翻译/通用推理类只对响应 token 计损失，SID–文本交错数据则做全序列语言建模。
- **定位**：该阶段不优化特定 CoT 轨迹，只建立 SID–语言接地，为后续推理提供表示基础。

### 2.3 阶段二：Best-of-N 拒绝采样监督微调（BoN-RS SFT）

- **预测效用打分**：对每个训练实例 (h_n, y*_n)，用教师 LLM 采样 K 条显式 CoT，用冻结的阶段二模型 p̄_θ（在单样本 CoT 语料上微调）作为打分器：
  Δ_{n,k} = log p̄_θ(y*_n | h_n, z_{n,k}) − log p̄_θ(y*_n | h_n)。
  两项仅在是否包含 z 上不同，因此 Δ 隔离出该候选 CoT 的**增量预测效用**。
- **Best-of-N 选择与拒绝**：k*_n = argmax_k Δ_{n,k}，仅当 Δ_{n,k*} > 0 时保留该轨迹（由于历史项对所有候选共享，该选择等价于最大化「推理条件下的目标 SID 似然」）。
- **微调目标**：在接受集 A 上优化 L_BoN(θ) = −(1/|A|)Σ_{n∈A}[log p_θ(ẑ_n|h_n) + log p_θ(y*_n|h_n, ẑ_n)]，即先学会生成「支持正确结果」的推理，再在推理条件下预测目标 SID。
- **与常规推理 SFT 的关键差别**：直接优化「模型该从哪些推理轨迹学习」，而非把所有生成理由等权对待。

### 2.4 阶段三：约束 SID 排序下的推理优化（RL）

- **受约束束搜索**：用全目录 SID 构建前缀 trie，每一步解码仅在合法子节点上掩码并重归一化，避免把概率质量浪费在非法序列上。推理轨迹 z_{n,g} 条件下的完整 SID 得分为各层对数概率之和，束宽 B 保留最高分前缀，得到有序的、目录合法的候选列表 R_{n,g}=(ŷ^{(1)},…,ŷ^{(B)})。
- **奖励设计**：设 r_{n,g} 为真实 SID 在 R_{n,g} 中的名次（未出现则为 ∞）。
  - 精确匹配奖励：R^EM = I[r_{n,g}=1]（稀疏、可验证，但把第 2 名与未召回等同对待）。
  - 排序感知奖励：R^NDCG = I[r_{n,g} ≤ 10] × 1/log₂(r_{n,g}+1)，即「检索」×「排序」的乘积形式。
- **优化**：采用 NDCG@10 作为标量奖励，对每个历史在 G 条轨迹间做奖励归一化，用 **GRPO** 更新推理策略，使模型偏好能把真实物品排得更高的推理路径。
