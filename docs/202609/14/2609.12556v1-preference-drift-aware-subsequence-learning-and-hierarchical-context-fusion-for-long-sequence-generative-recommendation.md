## 摘要
长序列生成式推荐方法以自回归方式对用户交互序列建模，以生成下一物品表示。现有方法通常分为两类：高效的全序列建模与目标感知的上下文检索。我们的实验表明，随着序列长度增加，前者的计算开销持续增长，而其精度增益很快饱和，甚至因噪声而下降；后者虽然缩短了输入序列，却容易受到语义一致但偏好不一致的噪声以及不完整上下文的影响。这两种范式在处理历史信息时都忽略了用户偏好的动态变化以及跨子序列依赖，从而限制了精度与效率。为解决这些问题，我们提出了一种面向长序列生成式推荐的偏好漂移感知子序列学习与层次化上下文融合方法。具体而言，我们利用多维偏好漂移信息学习可微的软子序列边界，并通过带有软分配权重的线性注意力将每个子序列内的物品聚合为偏好连贯的表示，从而规避全序列注意力的开销。随后采用交叉注意力机制捕捉近期交互与相关子序列上下文之间的依赖关系，减轻学习近期物品表示时的噪声。最后，门控融合机制自适应地结合近期物品表示与全局子序列上下文，使得到的目标表示能够同时编码近期偏好和长期偏好。大量实验表明，我们的方法在推荐精度和计算效率上均持续优于现有基线。

## Abstract
Long-sequence generative recommendation methods autoregressively model the user's interaction sequence to generate the next-item representation. Existing methods generally fall into two categories: efficient full-sequence modeling and target-aware context retrieval. Our experiments reveal that as the sequence length increases, the former incurs steadily growing computational cost while its accuracy gains quickly saturate and even degrade due to noise; the latter, though shortening the input sequence, is susceptible to noise that is semantically consistent yet preference-inconsistent, as well as to incomplete contexts. Both paradigms ignore the dynamic changes of user preferences and the cross-subsequence dependencies when handling historical information, thereby limiting accuracy and efficiency. To address these issues, we propose a preference-drift-aware subsequence learning and hierarchical context fusion for long-sequence generative recommendation. Specifically, we learn differentiable soft subsequence boundaries using multidimensional preference-drift information and aggregate items within each subsequence into preference-coherent representations via linear attention with soft assignment weights, thereby circumventing the expense of full-sequence attention. A cross-attention mechanism is then employed to capture dependencies between recent interactions and relevant subsequence contexts, mitigating noise in learning recent-item representations. Finally, a gated fusion mechanism adaptively combines the recent-item representation with the global subsequence context, allowing the resulting target representation to encode both recent and long-term preferences. Extensive experiments demonstrate that our method consistently outperforms existing baselines in both recommendation accuracy and computational efficiency.

# 论文总结：DRIFT——偏好漂移感知的长序列生成式推荐

## 1. 核心问题与整体含义

- **背景**：推荐系统正从传统多阶段判别式范式转向生成式推荐（GRS）。生成式方法将推荐建模为序列生成，以用户交互历史为条件自回归地生成下一物品表示（如 P5、TIGER、DIGER）。
- **核心矛盾**：长序列建模存在准确率与效率的两难：
  - **高效全序列建模**（HSTU、FuXi-Linear、RankMixer）：计算开销随序列长度持续增长，但精度增益迅速饱和甚至因噪声而下降。实验显示 HSTU 训练时间最多增长 6.9 倍，FuXi-Linear 增长 33.9 倍，而 NDCG@5 几乎无提升甚至波动。
  - **目标感知上下文检索**（GLASS、CAUSE、DualGR）：虽缩短输入序列，但易受"语义一致却偏好不一致"的噪声干扰，且上下文不完整。实验显示 GLASS 在序列长度增至 1000 时 Recall@5 分别下降 7.3% 和 33.7%；检索规模过大也会引入目标错位噪声。
- **共同缺陷**：两类范式均忽略了用户偏好的动态演化与跨子序列依赖，将历史交互同质化处理或依赖单一相似度检索。
- **整体含义**：本文提出 DRIFT（preference-Drift-awaRe subsequence learning and hIerarchical context Fusion meThod），通过自适应划分偏好一致子序列 + 线性复杂度建模局部-全局依赖，兼顾精度与效率。

## 2. 方法论

### 核心思想
双重创新：(1) 利用偏好漂移信息将长历史自适应划分为偏好一致子序列；(2) 以线性复杂度建模局部-全局上下文依赖。

### 2.1 偏好漂移感知子序列学习

- **漂移表征算子 φ**：联合建模三维度漂移——语义（1−cos 相似度、特征变化量）、时间（log(1+Δt)）、类别分布偏移（JSD），共四项。
- **边界打分**：轻量 MLP 将漂移表示映射为边界分数 `b_j = σ(MLP_b(φ_ij))`，b₁=0。
- **自适应子序列数 κ_u**：聚合位置边界分数为用户级统计量（平均边界强度、边界方差、归一化历史长度），通过 sigmoid 映射到 [1, K]，实现个性化子序列数量。
- **软坐标 r_j**：累积边界分数为单调递增软坐标并归一化到 [1, κ_u]。
- **软成员度**：以固定中心 μ_k=k 锚定候选子序列，配合有效性门控 `m_k` 抑制超出 κ_u 的阶段；成员度用带门控高斯核定义 `a_{j,k}`，再经 Gumbel-Softmax 重参数化锐化得到 `y_{j,k}`，缓解过平滑并保持可微。
- **子序列线性注意力**：以 `y_{j,k}` 约束各子序列仅聚合自身成员，避免跨子序列干扰；采用特征映射 `φ(x)=elu(x)+1` 的线性注意力，每子序列配可学习 query，多头输出拼接后 LayerNorm 得子序列表示 s_k。

### 2.2 层次化上下文融合

- **近期偏好上下文融合**：用自回归编码器（T5/HSTU）学习近期物品表示；在编码器块中引入交叉注意力，让近期物品选择性关注偏好一致子序列上下文，抑制语义相似但偏好不一致的噪声，得到隐藏状态 R*。
- **局部-全局上下文融合**：解码器层设计门控交叉注意力，`CA1=CrossAttn(z_dec, R*)` 捕捉局部依赖，`CA2=CrossAttn(z_dec, S)` 捕捉全局依赖；门控 `g=σ(W_g[z_dec;CA2]+b_g)`，输出 `z'_dec = z_dec + (1−g)⊙CA1 + g⊙CA2`，自适应权衡近期与长期偏好。

### 2.3 训练与复杂度

- **总损失**：`L = L_task + λ_sub L_sub`。
- **L_sub（子序列结构约束）**：包含语义一致性（拉近子序列质心）、时间一致性（惩罚同子序列内相邻交互的大时间间隔）、类别一致性（以一级 SID 为代理最小化类别熵），权重自适应于子序列数量。
- **L_task（以 GLASS 为例）**：`L_CE + λ_rec L_rec + λ_sub-rec L_sub-rec`，其中 L_rec 和 L_sub-rec 为 InfoNCE 序列级对齐损失。
- **复杂度**：`O(L_h K d + r² d + rK d) ≃ O(LK d)`，随历史长度线性扩展（K, r ≪ L）。

## 6. 主要结论与发现

- **准确率**：DRIFT 在所有数据集和骨干上持续优于基线。KuaiRec 上 DRIFT-HSTU 的 NDCG@20 和 Recall@20 分别提升 13.1% 和 21.6%；ML-20M 上相对 TIGER 最高提升 74.3%、相对 GLASS 提升 90.4%；Taobao MM 上 DRIFT-GLASS 在 4 项指标中 3 项第一。
- **效率**：DRIFT-GLASS 支持序列长度从 50 扩展到 1000（20 倍），每 epoch 训练快 3.9×（KuaiRec）和 2.7×（Taobao MM）；DRIFT-Tiger 训练最高加速 80.4×、推理加速 22.4×；DRIFT-HSTU 训练时间减少 37.6%–42.1%，显存减少 39.6%–61.1%。
- **假设验证发现**：序列越长精度未必越高；检索规模过小遗漏信息、过大引入偏好不一致噪声；单一相似度度量无法有效过滤此类噪声。
- **兴趣漂移分析**：长行为序列呈现局部连贯、阶段演化、明显近因效应（目标与近期交互相似度 0.275 高于与最早交互的 0.197），验证了显式建模动态兴趣子序列的必要性。
- **消融结论**：均匀分割和 K-means 分割均不如偏好漂移感知分割；移除任一交叉注意力均导致性能下降；朴素拼接子序列表示（Subseq-Prefix、Concat-Fuse）会造成严重性能崩溃（Taobao MM 上 N@5 降至 10⁻³ 量级），证明门控融合对异构表示对齐的必要性。
