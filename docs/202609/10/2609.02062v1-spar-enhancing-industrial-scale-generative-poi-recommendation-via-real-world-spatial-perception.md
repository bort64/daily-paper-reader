## 摘要
生成式兴趣点（POI）推荐通过自回归生成目标POI的语义ID（SID），在基于位置的服务中展现出巨大前景；在这类服务中，只有用户能够到达时，推荐才有实际帮助。然而，现有方法在由行为序列和协同信号定义的兴趣空间中运行，其中地理信息仅作为SID的文本属性进入，缺乏显式机制来学习或保持城市地点在距离、方向和可达性上的关联；因此，它们的预测在行为上看似合理，却远离用户的实时位置。我们认为，这类服务需要将真实的城市空间知识注入兴趣空间，而非仅从行为中推断地理信息。因此，我们提出SPAR，一个统一框架，其三个协同阶段共同构建、培育并保持城市空间知识：（1）在标记化层面，空间固有SID（SI-SID）将经纬度坐标显式编码为正弦地理空间嵌入，并与文本语义嵌入融合，通过RQ-Kmeans生成同时在语义和地理上一致的标识符；（2）在认知层面，多粒度地理空间持续预训练（MG-CPT）在25个精选地理空间数据集上对基础LLM进行持续预训练，这些数据集组织为基本属性、成对关系和城市级导航三个层级，从而让分散的POI凝聚为相互连接的城市空间；（3）在适应层面，任务向量锚定SFT（TV-SFT）将已获得的空间知识锚定为冻结的参数空间任务向量，以防止其在行为微调过程中发生灾难性遗忘，从而融合这两个空间。在两个公开数据集和四个工业规模数据集上的大量定量与可视化实验证明了SPAR的有效性。

## Abstract
Generative Point-of-Interest (POI) recommendation, autoregressively generating a target POI's semantic ID (SID), holds great promise for Location-Based Services, where a recommendation helps only if the user can reach it. Yet, existing methods operate within an interest space defined by behavior sequences and collaborative signals, where geography enters only as a textual attribute of the SID, leaving no explicit mechanism to learn or preserve how urban places are related by distance, direction, and reachability; their predictions are thus behaviorally plausible yet far from the user's real-time location. We argue that such services require injecting real urban spatial knowledge into the interest space, rather than inferring geography from behavior alone. Hence, we propose SPAR, a unified framework whose three synergistic stages jointly construct, cultivate, and preserve urban spatial knowledge: (1) at the tokenization level, Spatially-Intrinsic SID (SI-SID) explicitly encodes longitude--latitude coordinates into a sinusoidal geospatial embedding and fuses it with the textual semantic embedding, producing identifiers via RQ-Kmeans that are simultaneously semantically and geographically consistent; (2) at the cognition level, Multi-Granular Geospatial CPT (MG-CPT) continually pre-trains the base LLM on 25 curated geospatial datasets organized into three tiers of basic attributes, pairwise relations, and city-scale navigation, so that scattered POIs cohere into a connected urban space; and (3) at the adaptation level, Task-Vector Anchored SFT (TV-SFT) anchors the acquired spatial knowledge as a frozen parameter-space task vector to prevent its catastrophic forgetting during behavioral fine-tuning, thereby fusing the two spaces. Extensive quantitative and visualization experiments on two public and four industrial-scale datasets demonstrate the effectiveness of SPAR.

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：下一个兴趣点（Next-POI）推荐是基于位置服务（LBS）的核心能力，地图平台（AMAP、Google、快手等）每天需服务数十亿用户与 POI。近年来，基于 LLM 的生成式推荐模型（GRM）成为主流范式：先将 POI 通过 RQ-VAE/RQ-Kmeans 量化为语义 ID（SID），再在用户行为序列上做监督微调（SFT），自回归地生成目标 POI 的 SID。

- **核心痛点**：现有 GRM 的整个流水线运行在由行为序列与协同信号定义的“兴趣空间”中，地理信息仅在 SID 构建阶段作为文本属性或弱正则项进入，CPT 与 SFT 阶段完全由行为驱动。由此带来两个层面的缺陷：
  - **标记化阶段地理编码不精确**：经纬度或被序列化为普通文本 token（数字 token 不具备度量结构），或仅通过协同/对比信号间接利用。量化结果由高方差语义特征主导，地理退化为弱正则，导致标识符空间缺乏空间连续性——坐标相邻的 POI 未必 SID 相邻，而语义相似但相距数十公里的同品牌连锁店却可能共享近乎相同的 SID。
  - **训练阶段城市空间知识缺失**：通用 LLM 的预训练缺乏特定城市的细粒度地理知识，现有 CPT 规模小且不以城市空间为目标；仅靠 SFT 拟合行为，模型学到的只是“哪些 POI 常被一起访问”，而无法判断候选 POI 是否从用户当前位置可达（例如直线 2 公里外的 POI 可能隔着一条河，需要绕行）。

- **整体含义**：论文主张，LBS 场景下的生成式 POI 推荐应当把**真实城市空间知识显式注入兴趣空间**，而非从行为中反推地理。作者提出 SPAR 统一框架，通过“构建—培育—保持”三个协同阶段实现这一目标，使推荐从单纯的行为拟合转变为在真实城市空间中对用户轨迹进行空间推理。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体框架
SPAR 包含三个协同阶段：**SI-SID**（构建空间标识符空间）→ **MG-CPT**（培育城市空间认知）→ **TV-SFT**（保持空间知识并适配行为）。三者分别对应表示层、认知层、适应层。

### 2.2 SI-SID：空间固有语义 ID

- **显式地理空间编码**：
  - 将经纬度分别归一化到 $[0, 2\pi]$：$\hat{\lambda} = \frac{\lambda+180}{360}\cdot 2\pi$，$\hat{\phi} = \frac{\phi+90}{180}\cdot 2\pi$。
  - 使用 $K$ 个指数间隔频率带 $f_k = 10000^{-k/K}$，生成 Fourier 特征 $\gamma(\hat{\lambda}) = [\sin(f_0\hat{\lambda}), \cos(f_0\hat{\lambda}), \dots, \sin(f_{K-1}\hat{\lambda}), \cos(f_{K-1}\hat{\lambda})]$，纬度同理。
  - 拼接经纬度特征后经两层 MLP（Xavier 初始化）得到 $e_{geo} \in \mathbb{R}^{d_g}$，$d_g = 4K$。
  - **两个理论性质**：(1) 平移不变核——内积 $\langle \gamma(u_1), \gamma(u_2)\rangle = \sum_k \cos(f_k(u_1-u_2))$ 仅依赖位移，且在城市尺度内随距离单调递减；(2) Lipschitz 连续性——$\|\gamma(u_1)-\gamma(u_2)\|_2^2 \le (\sum_k f_k^2)(u_1-u_2)^2$，MLP 作为线性层与 ReLU 的组合保持该连续性。因此坐标相邻的 POI 获得相邻的 $e_{geo}$。

- **RQ-Kmeans 构建 SI-SID**：
  - 将文本语义嵌入 $e_{sem}$（如 Qwen3-embedding-4B）与 $e_{geo}$ 拼接后做 L2 归一化：$x = [e_{sem}; e_{geo}]/\|[\cdot]\|_2$，防止任一信号因尺度差异主导聚类。
  - 采用 $L=4$ 层残差 K-means 量化：前三层为学习到的码本（$N_c=512$ 工业级 / 32 公开数据集），第四层为消歧索引以保证 SID 唯一性。每层对上一层残差做 K-means 聚类，量化时逐层取最近码字并更新残差（含 $\epsilon=10^{-8}$ 防除零）。
  - 最终 SID 形如 $\langle a^*, b^*, c^*, d^*\rangle$。

### 2.3 MG-CPT：多粒度地理空间持续预训练

- **三层次数据分类法**（共 25 个训练数据集，数百万实例）：
  - **Tier 1 基本属性知识（B，13 个数据集）**：12 个 POI 数据集建立 SID、坐标、类别、区县、地址之间的双向映射；1 个道路数据集刻画道路等级、长度、车道、限速。
  - **Tier 2 关系知识（R，9 个数据集）**：POI-POI 与 POI-道路的成对空间关系。8 个距离/方向数据集构成坐标可见性（coord/no_coord）× 推理目标（dis/dir）× 答案格式（choice/open）的 2×2×2 正交设计；另有 POI 邻近关系任务。
  - **Tier 3 系统性知识（S，3 个数据集）**：引入导航数据（路线距离、时长、有序道路序列、逐步导航），让模型内化全城路网连通性而非记忆单条路线。

- **持续预训练**：所有数据序列化为 next-token-prediction 实例，以标准因果语言建模目标联合预训练，将基础 LLM 参数 $W_{Base}$ 扩展为具备城市空间感知的 $W_{MG-CPT}$。

### 2.4 TV-SFT：任务向量锚定的监督微调

- **核心动机**：直接从 $W_{MG-CPT}$ 做大规模行为 SFT 会逐步侵蚀空间知识（灾难性遗忘）；而从 $W_{Base}$ 微调则行为拟合缺乏空间根基。受模型编辑/知识注入中“能力可表示为参数空间方向”的启发，提出双分支方案。

- **任务向量提取**：$\tau_{MG-CPT} = W_{MG-CPT} - W_{Base}$，作为空间知识增量的显式参数化表示。

- **双分支训练**：
  - 分支 A（任务适配）：$W_{Base}$ 全参数 SFT 拟合用户行为，即现有 GRM 的唯一做法。
  - 分支 B（空间知识）：$\tau_{MG-CPT}$ **冻结**作为锚点，仅对线性层施加低秩 LoRA 适配器 $\Delta_{LoRA} = BA$（$B \in \mathbb{R}^{d_{lin}\times r}$，$A \in \mathbb{R}^{r\times d_{lin}}$，$r \ll d_{lin}$），让空间知识获得轻量调整。
  - 组合模型：$W_{TV\text{-}SFT} = W_{Base} + \alpha(\tau_{MG-CPT} + \Delta_{LoRA})$，$\alpha$ 默认 1。$\alpha=1$ 等价于在 MG-CPT LLM 上微调；$\alpha=0$ 退化为对基础模型的全参数 SFT。

- **训练目标**：给定用户历史行为序列与上下文 prompt，最小化目标 POI 的 SI-SID 四元组 $Q_t=\langle a^*,b^*,c^*,d^*\rangle$ 的负对数似然：$\mathcal{L}_{TV\text{-}SFT} = -\sum_{i=1}^{4}\log P(q_i \mid \text{prompt}, q_{<i})$。
