## 摘要
物品分词器将语义嵌入编码为令牌ID，以取代传统推荐模型中随机分配的物品ID，从根本上解决了参数过多和冷启动的问题。然而，最常见的分词器RQ-VAE由于其码本之间的固有依赖关系，导致解码效率低下。与此同时，高效的独立分词器（如优化乘积量化OPQ）仍然难以应对语义嵌入的维度相关性和分布复杂性。在这项工作中，我们提出了一种基于流的物品分词器（Tlow），将原始语义嵌入转换到一个潜在空间，其中嵌入符合统一的标准正态分布，从而实现维度独立和分布简单的双重优势。在这些潜在嵌入上执行的独立分词能够产生语义清晰的令牌ID。此外，我们引入了一种新颖的码本引导机制，将码本空间与令牌嵌入空间对齐，进一步帮助学习更具语义区分性的令牌嵌入。在四个公开数据集上的离线实验表明，Tlow的分词和码本引导显著提升了推荐性能。在跨领域和多模态推荐上的改进也证明了在简化嵌入空间中物品分词的有效性。在中国最大的社交媒体平台微信上进行的多模态检索任务的在线实验验证了Tlow强大的分布转换能力。基于令牌ID的检索模型在全局上使用户点击率提高了10.32%，对新物品提高了11.64%。我们的代码可在https://github.com/wjjln/Tlow获取。

## Abstract
Item tokenizer encodes semantic embeddings into token IDs to replace the randomly assigned item IDs used in traditional recommendation models, fundamentally addressing the problems of excessive parameters and cold starts. However, the most common tokenizer, RQ-VAE, suffers from low decoding efficiency due to the inherent dependencies among its codebooks. Meanwhile, efficient independent tokenizers such as optimized product quantization (OPQ) still struggle with dimensional correlations and distribution complexity of semantic embeddings. In this work, we propose a f\underline{low}-based item \underline{T}okenizer (Tlow) to transform raw semantic embeddings into a latent space where embeddings conform to a unified standard normal distribution, achieving dual advantages of dimensional independence and distributional simplicity. Independent tokenization performed on these latent embeddings yields semantically clear token IDs. Additionally, we introduce a novel codebook guidance to align the codebook space with the token embedding space, further aiding the learning of more semantically distinct token embeddings. Offline experiments on four public datasets demonstrate that Tlow's tokenization and codebook guidance significantly improve recommendation performance. The improvement on cross-domain and multi-modal recommendations also proves the effectiveness of item tokenization in a simplified embedding space. Online experiments for a multi-modal retrieval task on China's largest social media platform WeChat validate Tlow's powerful distribution transformation capability. The retrieval model based on token IDs improves user CTR by 10.32\% globally and by 11.64\% for new items. Our codes are available at https://github.com/wjjln/Tlow.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：传统推荐系统为每个物品随机分配一个唯一 ID 并学习对应的 ID 嵌入，这种方式存在两个根本性问题：
  - **参数规模过大**：物品 ID 嵌入数量随物品总数线性增长，在工业级大规模系统中严重限制模型容量；
  - **冷启动困难**：新物品缺乏交互记录，随机 ID 无法被有效学习，导致系统难以推荐新物品。
- **现有解决方案与不足**：借鉴大语言模型范式，物品分词器（Item Tokenizer）将物品的语义嵌入（如文本/图像经预训练模型提取）编码为离散 Token ID 序列，形成全局共享的词表，从而替代随机物品 ID。其中：
  - **RQ-VAE**：因码本间存在层次依赖，解码时必须逐级串行预测，推理步骤数等于码本数，解码效率低；且存在码本崩溃与冲突问题。
  - **OPQ 等独立分词器**：虽然可实现并行解码，但原始语义嵌入存在**维度相关**（各维度非独立，嵌入分布在一个复杂偏斜流形上）和**分布复杂**（高度各向异性，集中于非均匀锥形区域，尤其在跨域/多模态场景中呈现分离簇状）两大挑战，导致独立量化误差大、语义表达不清晰。
- **核心动机**：设计一种既能实现独立并行分词、又能克服原始嵌入维度相关性和分布复杂性的物品分词器，从而获得语义更清晰的 Token ID 并提升推荐性能。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
**Tlow = Flow-based Item Tokenizer**：利用**基于流的生成模型**（借鉴 Glow 的 multi-scale 架构），将原始语义嵌入 \(\mathbf{x}\in\mathbb{R}^{d_s}\) 可逆地变换为服从**标准正态分布**的潜在嵌入 \(\mathbf{z}\in\mathbb{R}^{d_s}\)。变换后的潜在空间具有：
- **维度独立性**：满足乘积量化（PQ）所需的维度独立假设；
- **分布简单性**：各向同性、均匀覆盖，便于量化码本高效拟合。

在 \(\mathbf{z}\) 上执行**独立乘积量化（PQ）**，将 \(\mathbf{z}\) 分成 \(C\) 段，每段用 K-means 学习码本并量化，得到每个物品的 \(C\) 个 Token ID。相比直接量化原始嵌入，Tlow 的量化误差更小、Token 语义更清晰（见图 1 示例：相同首位 Token ID 下，Tlow 分组的音乐专辑风格更纯净，类别数与熵更低）。

### 2.2 关键技术细节

#### （1）Tlow 流模型结构
- 采用 **multi-scale 架构**：共 \(N\) 个 Block，每个 Block 含 \(M\) 步 Flow。
- 每步 Flow 由三个可逆层组成：
  - **ActNorm（激活归一化）**：\(\mathbf{x}_1 = \mathbf{s}\odot(\mathbf{x}_0 + \mathbf{t})\)，用于稳定训练；
  - **Invertible Linear（可逆线性变换）**：\(\mathbf{x}_2 = \mathbf{W}\mathbf{x}_1\)，将 \(\mathbf{W}\) 分解为 PLU（置换×下三角×上三角）以高效计算行列式，实现维度间信息交互；
  - **Affine Coupling（仿射耦合）**：将输入分为两半，以一半为条件，用 MLP 产生尺度与偏置，对另一半进行仿射变换，保证可逆性。
- 每个 Block 的输出分为两部分：一部分（\(\mathbf{z}^a\)）进入下一个 Block，另一部分（\(\mathbf{z}^b\)）作为该 Block 的最终输出分量；通过对 \(\mathbf{z}^b\) 建模条件高斯分布来估计对数似然，最终得到潜在嵌入 \(\mathbf{z}\)。

训练目标为最大化对数似然（最小化负对数似然）：
\[
\mathcal{L}_f = -\frac{1}{|\mathcal{X}|}\sum_{\mathbf{x}}\log p_{\boldsymbol{\theta}}(\mathbf{x})
\]
其中
\[
\log p_{\boldsymbol{\theta}}(\mathbf{x}) = \sum_{n=1}^N \log p(\mathbf{z}_n^b) + \sum_{n=1}^N\sum_{m=1}^M \Delta_{n,m}
\]
\(\Delta_{n,m}\) 为每步 Flow 的行列式对数。

#### （2）物品分词
- 训练完成后，对任意物品语义嵌入 \(\mathbf{x}\) 前向传播得到 \(\mathbf{z}\)；
- 将 \(\mathbf{z}\) 分为 \(C\) 个互不重叠的子向量；
- 每个子向量独立进行 K-means 量化，得到对应码本 \(\{\mathbf{c}_j^k\}_{j=1}^S\)，Token ID 取最近码字索引：
  \[
  c_k = \arg\min_{j\in\{1,\dots,S\}} \|\mathbf{z}_k - \mathbf{c}_j^k\|_2
  \]
- 从而每个物品被表示为 Token ID 序列 \([c_1,\dots,c_C]\)。

#### （3）基于 Token ID 的推荐模型
- 每个码本对应一组可学习的 Token 嵌入 \(\mathbf{E}\in\mathbb{R}^{C\times S\times d_m}\)；
- 物品的嵌入由各 Token 嵌入均值聚合：\(\mathbf{e} = \frac{1}{C}\sum_{k=1}^C \mathbf{E}_{k,c_k}\)；
- 用户历史序列的嵌入输入 Transformer decoder（如 GPT-2），通过多个独立预测头（project heads）并行解码下一物品的 \(C\) 个 Token ID，并计算交叉熵损失。由于潜在嵌入的各部分独立，解码可在单次前向中并行完成（与 RQ-VAE 的串行解码相比效率更高）。

#### （4）码本引导（Codebook Guidance）
- 动机：使 Token 嵌入空间的结构与码本空间（即语义原子空间）的结构对齐。
- 具体做法：分别计算第 \(k\) 个码本内 Token 嵌入间余弦相似度矩阵 \(\Phi_k\) 和码字间余弦相似度矩阵 \(\Psi_k\)，然后用 MSE 损失拉近两者：
  \[
  \mathcal{L}_{sim} = \mathrm{MSE}(|\Phi - \Psi|)
  \]
- 最终训练损失：\(\mathcal{L} = \mathcal{L}_{rec} + \lambda \mathcal{L}_{sim}\)。

## 6. 论文的主要结论与发现

1. **Tlow 显著优于所有基线**：在四个通用数据集上，Tlow 在 R@5、N@5、R@10、N@10 全部指标上取得最佳，相对 RPG 的提升在 1.97% 至 11.52% 之间（不同数据集/指标不同）。尤其在 Toys 和 CDs 数据集上提升较大（R@10 提升约 9.8%/7.1%）。
2. **流模型变换是关键**：使用随机标准正态分布采样 \(\mathbf{z}\) 代替学习到的 \(\mathbf{z}\) 导致性能大幅下降（例如 CDs 的 R@10 从 0.0801 降至 0.0147），证明 Tlow 保留了语义嵌入的有效信息，并非简单引入高斯分布即可。
3. **码本引导有效**：去除 \(\mathcal{L}_{sim}\) 后各数据集指标都下降，说明对齐码本空间与 Token 嵌入空间有助于提高 Token 嵌入的语义清晰度。
4. **跨域推荐优势突出**：Tlow 在 Cloth-Sports 跨域数据上大幅超越 LLM4CDSR 和 RPG，Overall R@10 达 0.5558（RPG 为 0.4766），说明将不同域的嵌入统一变换为标准正态空间有助于跨域共享语义。
5. **多模态推荐也有提升**：在 Sports 数据集（文本+图像）上 Tlow 优于 HM4SR 和 RPG 的 baseline，但提升幅度中等。
6. **冷启动性能稳健**：Tlow 在不同用户交互深度和物品流行度分组上都一致优于 RPG，尤其在长尾/冷启动物品上表现更好。
7. **在线工业化验证**：微信图片检索场景中，使用 Tlow tokenization 的路径相比随机 ID 路径：单域 CTR 提升 4.79%、UCTR 提升 10.32%；跨域 CTR 提升 6.23%、UCTR 提升 7.20%；新物品提升更明显（单域新物品 UCTR +11.64%）。整体线上核心指标：单域整体 CTR +0.78%、新图片 CTR +1.94%；跨域人均图片 CTR +1.05%，且头部账号曝光占比下降 1.15%，说明长尾图片得到了更多曝光。

## 7. 优点

- **方法创新性强**：将可逆流模型引入物品分词任务，从“分布变换”角度解决语义嵌入维度和分布复杂性问题，思路新颖有依据。
- **解码效率高**：潜在嵌入维度独立且分布标准正态，可并行生成所有 Token ID，避免 RQ-VAE 的串行解码瓶颈。
- **语义清晰度提升**：通过可视化案例和图谱熵对比，直观地展示了 Tlow 生成的 Token ID 在语义聚合上比 OPQ 更纯粹。
- **设计了码本引导机制**：不依赖逐物品或逐序列的对比对齐，而是直接在 Token 嵌入空间与码本空间之间做结构对齐（相似度矩阵 MSE），简单有效，促进 Token 嵌入语义区分。
- **实验体系完整**：覆盖通用、跨域、多模态、冷启动从离线到在线的多层验证，在线实验规模大（每日上亿交互），结果可信度高。
- **实现细节严谨**：统一使用相同的语义编码器（sentence-t5-base），控制模型参数规模与 RPG 大致相同，保证了比较的公平性。
