## 摘要
Transformer因其出色的可扩展性在大语言模型中展现出良好性能，已有若干研究探索了Transformer在工业推荐中的可扩展性。这些研究通常依赖单个排序模型从头优化稀疏参数和稠密参数，导致大量计算资源消耗和收敛缓慢。所幸，预训练模型能够为后续排序提供稀疏参数和稠密参数的良好初始化，从而有效解决上述问题。然而，它们仍面临两个主要局限：（1）由于预训练和排序所使用的输入特征通常不一致，直接将预训练中的稠密参数迁移到排序中可能导致负迁移。（2）排序过程中的多轮训练可能导致稀疏参数过拟合，而冻结稀疏参数又会限制其对于排序目标的适应性。为此，我们提出了一种通过可迁移生成式预训练实现面向工业推荐的扩展Transformer，称为LazFormer。具体而言，我们首先提出一个生成式预训练模块，以自回归方式生成序列特征，为后续排序提供稀疏参数和稠密参数的良好初始化。为了解决稠密参数的负迁移问题，我们提出了一种可迁移残差适配器，以残差方式将额外的排序特定特征注入排序过程。此外，一个请求感知排序模块集成了长序列压缩、混合稀疏注意力和请求感知范式，以高效建模用户的长序列。除此之外，我们进一步提出了一种非对称多轮训练策略，在跨轮次持续累积稠密参数的同时重置稀疏参数，从而缓解稀疏参数的过拟合。

## Abstract
Transformers have shown promising performance in LLMs due to their outstanding scalability, several studies have investigated the scalability of Transformers for industrial recommendation. They typically rely on a single ranking model to optimize both sparse and dense parameters from scratch, resulting in substantial computational resource consumption and slow convergence. Fortunately, the pre-training models offer an effective solution to the above issues by providing favorable initialization of both sparse and dense parameters for the subsequent ranking. However, they still face two major limitations: (1) Since the input features used in pre-training and ranking are usually inconsistent, directly transferring dense parameters from pre-training to ranking may lead to negative transfer. (2) Multi-epoch training during the ranking process may result in the overfitting of sparse parameters, while freezing the sparse parameters limits their adaptability to the ranking objectives. To this end, we propose a Scaling Transformer for Industrial Recommendation via Transferable Generative Pre-training, termed LazFormer. Specifically, we first present a generative pre-training module to autoregressively generate sequential features, providing favorable initialization of both sparse and dense parameters for the subsequent ranking. To solve the negative transfer of dense parameters, we propose a transferable residual adapter that injects additional ranking-specific features into ranking in a residual manner. Moreover, a request-aware ranking module integrates long-sequence compression, hybrid sparse attention, and a request-aware paradigm to efficiently model users' long sequences. Besides, we further propose an asymmetric multi-epoch training strategy that resets sparse parameters while continuously accumulating dense parameters across epochs, alleviating the overfitting of sparse parameters.

- **现有范式的问题**：
  - 现有可扩展排序 Transformer（如 HSTU、OneTrans 等）通常依赖**单个排序模型从头优化稀疏参数和稠密参数**，导致计算资源消耗大、收敛慢。
  - 预训练 + 排序范式虽能提供初始化，但存在两个关键局限：
    1. **稠密参数负迁移**：预训练与排序所用输入特征不一致，直接将排序特定特征注入排序，可能扰动预训练稠密参数的表征空间。
    2. **稀疏参数过拟合**：排序阶段多轮训练可能使海量稀疏参数过拟合；而冻结稀疏参数又会限制其适应排序目标的能力。
- **整体含义**：论文提出 **LazFormer**，通过可迁移生成式预训练，实现工业推荐中稀疏与稠密参数的联合迁移，并协同扩展模型容量与训练数据，兼顾效果、效率与工业部署可行性。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架
LazFormer 由四部分组成：
1. **生成式预训练**：自回归生成序列特征，为稀疏和稠密参数提供初始化。
2. **可迁移残差适配器**：以残差方式注入排序特定特征，缓解稠密参数负迁移。
3. **请求感知排序**：集成粗到细长序列压缩、混合稀疏注意力、请求感知范式。
4. **非对称多轮训练策略**：跨轮累积稠密参数、重置稀疏参数，缓解稀疏过拟合。

### 2.2 生成式预训练
- **Tokenization**：将用户历史交互序列中的每个物品及其 ID 特征与 Side Info 特征（类别、店铺、品牌、时间衰减、停留时间、场景等）拼接，经线性投影和 RMSNorm 映射到统一维度，得到交互 token。
- **Next-Item Prediction**：
  - 使用堆叠 Transformer 块，包含因果自注意力、FFN、归一化、残差连接；注意力层引入 pre-Norm、QKNorm、attention gate 稳定训练。
  - 将隐藏表示投影到物品 ID 嵌入空间，预测下一个交互物品。
  - 正样本为真实下一物品，负样本从同一 mini-batch 内其他序列采样；使用温度缩放余弦相似度计算生成概率。
  - 损失为负对数似然 `L_pre`。
- **作用**：联合学习可迁移的稀疏物品表示与稠密 Transformer 参数，用于初始化后续排序模型；与冻结预训练参数的方法不同，LazFormer 允许预训练参数在排序阶段继续更新。

### 2.3 可迁移残差适配器
- **动机**：排序阶段有额外排序特定特征（加购、下单、加购-点击间隔、下单-点击间隔等），直接拼接会扰动预训练表征，导致负迁移。
- **设计**：
  - 将排序特定特征拼接后，经 `W_down → GELU → W_up` 生成残差表示 `a_j`。
  - 将 `a_j` 以残差方式加到交互 token 上，再经 RMSNorm。
  - **关键初始化**：令 `W_up = 0`，使适配器初始输出为零残差，排序模型从预训练特征出发，再逐步融入排序特定特征。
- **效果**：既保留预训练知识，又允许稀疏和稠密参数向排序目标适配。

### 2.4 请求感知排序
- **粗到细长序列压缩**：
  - 保留最近 `ℓ_i` 个短期细粒度交互 token。
  - 对剩余长期交互按组大小 `g` 做分组求和池化，得到压缩表示。
  - 压缩后序列长度从 `L_i` 降至 `N_i + ℓ_i`。
- **混合稀疏注意力**：
  - 输入由压缩历史序列与同一请求下所有目标物品 token 拼接而成。
  - 设计混合稀疏注意力掩码，包含：
    - 因果滑动窗口注意力（局部历史）；
    - 全局历史 token（最近 `G_i` 个行为，提供长程信息锚点）；
    - 目标物品对全部有效历史 token 的注意力；
    - 目标物品之间仅自注意力，防止候选间信息泄漏。
  - 通过 FlexAttention 将块稀疏模式编译为融合 CUDA kernel。
- **渐进式 token 剪枝**：
  - 随 Transformer 层数增加，线性减少保留的历史 token 数，从 `L̃_i` 降至最小长度 `N_min`。
  - 减少深层计算量。
- **请求感知范式**：
  - 传统排序为每个目标物品构造独立样本，重复序列化、存储、传输和编码同一用户历史。
  - LazFormer 按请求组织样本 `R_i = (u_i, H_i, T_i, Y_i)`，同一请求下所有目标物品共享一次历史序列的存储、传输和编码。
  - 目标物品由稀疏注意力掩码隔离，保持预测独立性。

### 2.5 非对称多轮训练策略
- 将参数分为稀疏参数 `Θ_s` 和稠密参数 `Θ_d`。
- 每轮开始时：
  - **稀疏参数重置**为生成式预训练初始状态 `Θ_s_init`；
  - **稠密参数继承**上一轮优化后的状态（第一轮使用预训练初始状态）。
- 每轮内稀疏和稠密参数仍由排序损失 `L_rank` 联合优化。
- **效果**：稠密参数持续吸收排序监督，稀疏参数避免多轮过拟合，同时保留可迁移稀疏表示。

## 3. 实验设计

- **数据来源**：真实工业电商推荐平台。

- **排序数据集**：11M 用户，370M impressions，过去 25 天训练，后 1 天测试。
- **在线场景**：首页推荐系统排序阶段，生产基线为 3 层 SORT-like 排序模型。
