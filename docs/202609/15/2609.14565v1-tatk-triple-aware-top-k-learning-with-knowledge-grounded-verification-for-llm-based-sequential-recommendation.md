## 摘要
基于LLM的序列推荐器通常将下一项预测转化为文本生成，但该接口与全目录Top-K排序并不匹配。我们提出TATK，一个三重感知框架，将Top-K学习（TKL）与知识锚定验证（KGV）相结合，用于基于LLM的序列推荐。Top-K学习将上下文感知的元数据-KG提示锚定与位置感知的Top-K奖励相结合，使训练与排序效用保持一致；知识锚定验证则在单次LLM前向传播后，对Top-M候选应用结构感知的重排序，并使用相同的由元数据导出的物品图。我们在Amazon Reviews 2023的Musical Instruments、CDs and Vinyl和Video Games数据集上，在匹配的R2ec风格全目录协议下评估TATK。实验使用Gemma-2-2B-It和Qwen2.5-3B-Instruct作为骨干模型，与序列、生成式、KG增强和推理增强基线进行比较，并包含组件、奖励形态、序列扰动、重排序、关系质量和候选池诊断。TATK在全部36个报告指标上均优于匹配的R2ec复现。在NDCG@10上，它在三个数据集上分别将Qwen提升8.05%、4.26%和3.78%，将Gemma提升27.03%、10.52%和10.23%，同时将推理延迟保持在Base RecPO的1.17倍以内。诊断表明，对于具有可靠KG支持且可恢复的Top-M候选，结构证据最为有用，而当元数据关系稀疏或噪声较大时，应对其进行门控。

## Abstract
LLM-based sequential recommenders usually cast next-item prediction as text generation, but this interface is poorly matched to full-catalog top-K ranking. We propose TATK, a Triple-Aware framework that couples Top-K Learning (TKL) with Knowledge-Grounded Verification (KGV) for LLM-based sequential recommendation. Top-K Learning combines context-aware metadata-KG prompt grounding with position-aware top-K rewards, aligning training with ranking utility; Knowledge-Grounded Verification then applies structure-aware reranking over the top-M candidates after a single LLM forward pass, using the same metadata-derived item graph. We evaluate TATK on Musical Instruments, CDs and Vinyl, and Video Games from Amazon Reviews 2023 under a matched R2ec-style full-catalog protocol. Experiments use Gemma-2-2B-It and Qwen2.5-3B-Instruct backbones, compare against sequential, generative, KG-augmented, and reasoning-enhanced baselines, and include component, reward-shape, sequence-perturbation, reranking, relation-quality, and candidate-pool diagnostics. TATK improves over the matched R2ec reproduction on all 36 reported metrics. On NDCG@10, it improves Qwen by 8.05%, 4.26%, and 3.78% on the three datasets, and improves Gemma by 27.03%, 10.52%, and 10.23%, while keeping inference within 1.17x of Base RecPO latency. The diagnostics show that structural evidence is most useful for recoverable top-M candidates with reliable KG support, and should be gated when metadata relations are sparse or noisy.

## 1. 核心问题与研究动机

- **背景**：LLM 序列推荐普遍把"下一项预测"重构成文本生成任务（输入标题/元数据/指令，输出候选物品或推理链），虽与语言理解兼容，却暴露一个根本矛盾——**用文本生成接口去解一个排序问题**。
- **作者识别出三处"接口错位"**（针对全目录 top-K 推荐）：
  - **输入接地弱**：两个标题不同的物品可能同店、同品类、同主类，但纯标题序列无法显式表达这些结构关系。
  - **训练目标与评测指标错位**：token 级似然对目标 token 一视同仁，而 HitRate@K / NDCG@K 高度依赖命中项是否落在排名前列。
  - **推理端候选缺乏验证**：LLM 生成 top-M 候选后，现有方法要么直接信任语言分数，要么依赖更重的推理，而不利用现成的物品结构做校验。
- **核心判断**：全目录推荐很"不宽容"——生成流畅的物品名但正确项排在可见 top-K 之外仍然失败。产品域中有用证据（store / category / main category）常已存在于元数据中，因此关键不是"LLM 能否推理更长"，而是**轻量结构证据能否在 top-K 排序被决定的关键点上去接地、训练与验证生成**。
- **总体含义**：提出 TATK（Triple-Aware Top-K Learning with Knowledge-Grounded Verification），以**同一张元数据导出物品图**贯穿输入构造、训练与推理三个阶段，在不引入外部 KG 对齐、CoT 监督或额外 LLM 前向传播的前提下提升 top-K 排序。

## 2. 方法论

### 2.1 核心思想
- 三重感知（Triple-Aware）= 三种结构意识注入同一流水线：
  - **上下文感知的提示接地**（Context-aware KG grounding）
  - **位置感知的 top-K 奖励**（Position-aware top-K rewards）
  - **结构感知的 KG 验证**（Structure-aware KG verification）
- 组织为两阶段：**TKL（Top-K Learning，训练时）** = 上下文接地 + 位置奖励；**KGV（Knowledge-Grounded Verification，推理时）** = 结构感知重排；TATK = TKL + KGV。
- 消融中用 **TATK-TKL** 表示仅训练期配置（无 KGV），**Full TATK** 表示完整流水线。

### 2.2 上下文感知 KG 接地（§3.3）
- 由商品元数据构建物品图 G = (I, E)，边编码 same-store、same-category、same-main-category，先验强度递减。
- 对用户历史中的**近期锚点物品**检索结构近邻，序列化为紧凑自然语言上下文注入 prompt；无需外部 KG 对齐。
- 支持**动态 KG 门控**：历史长度低于阈值时跳过 KG 注入（短历史锚点过少、KG 证据不可靠）。
- 类别/主类别组上限 350 项，避免高噪声高维组。

### 2.3 位置感知 Top-K 奖励（§3.4）
- 奖励定义（线性、单调，非新排序指标）：
  - 若目标排名 r ≤ K：`r_pos(r) = (K − r + 1) / K`
  - 若 r > K：`r_pos(r) = 0`
- 该奖励在 batch / rollout group 内**中心化**形成相对优势（advantage），再与 token 级学习信号和物品级推荐损失结合。
- 贡献不在线性形式本身，而在于**将 token 级适配与物品级排序效用耦合进 S2R 训练管线**；线性尺度仅为保持相对优势稳定（§4.3 与二值、log 折扣、NDCG 形状做了对照）。

### 2.4 知识锚定验证（§3.5）
- LLM 先以**单次前向**产生 top-M 候选集，KGV 做结构感知重排。
- 对候选 c 与历史 H_u：
  - `m(c, H_u) = max_{h∈H_u} w(c, h)`（与历史锚点的最强关系强度）
  - `n(c, H_u) = max(0, count(c, H_u) − 1)`（重复被支持次数）
  - `raw(c, H_u) = min(γ, m(c, H_u) + β·n(c, H_u))`
- 在 top-M 内归一化并按分数幅度缩放：
  - `b_KG(c, H_u) = [raw / max_{c′∈TopM} raw] × range(TopM)`
- 最终分数：`s′(u, c) = s_gen(u, c) + λ·b_KG(c, H_u)`
- 超参数（主实验）：M = 100，γ = 2.5，β = 0.15，λ = 0.01；M 由精度–延迟扫描选定，γ/β/λ 在 MI/CDs 开发诊断上选定后固定用于 VG。
- **门控条件**：用户历史 ≥ 3 项、至少一个 KG 支持候选，并施加 band 门与不确定度门，避免改动生成分数不可比的候选。
- **可解释性**：每个被提升/压低的候选都可追溯到具体的 store/category/main-category 证据。

### 2.5 复杂度（§3.6）
- 额外开销来自 top-M KG 支持计算，KG 邻居缓存构建后复杂度约 **O(M·|H_u|)**，轻于需要长 CoT 解码或多轮 LLM 调用的方法。
