## 摘要
在电商搜索中融合召回与预排序，要求候选生成在最终排序之前就兼顾相关性、个性化与商业价值。为此，我们提出 VARG，一个面向天猫 App 搜索的生成式检索系统，可将生成的商品候选直接送入现有的最终排序器。VARG-ID 使用 RQ-VAE 构建语义前缀，通过双向查询-商品对比学习增强搜索相关性，并将这些前缀与按价值排序的第三个 token 结合，以提供细粒度商品地址和商业价值先验。三阶段监督微调逐步学习商品到标识符的映射、查询语义检索和个性化检索。个性化模型训练将价值感知和层级对齐的监督与扩展的用户上下文相结合，并使用局部序数监督（LO-SFT）来学习由第三个 token 编码的簇内局部排序。Prefix-GRPO 将基于输出合法性、用户行为、排序器优势和搜索相关性的门控奖励与前缀感知的 token 加权相结合，使候选生成与商业价值和排序目标对齐。协调的每日商品与模型更新在纳入新商品和行为反馈的同时，保留现有商品地址。在数千万商品上的离线实验验证了标识符稳定性，并表明 SFT 策略和 Prefix-GRPO 在检索质量和头部价值召回方面相较各自基线均有提升。在覆盖 20% 搜索流量的 14 天在线 A/B 测试中，VARG 将生成的候选直接送入最终排序器，使 GMV 提升 1.45%，人均 IPV 提升 0.22%，PCTR 提升 0.31%。在线导购查询评估进一步表明，VARG 在更小的候选配额下仍保持有竞争力的相关性。

## Abstract
Integrating recall and pre-ranking in e-commerce search requires candidate generation to account for relevance, personalization, and business value before final ranking. To this end, we present VARG, a generative retrieval system for Tmall App search that directly admits generated item candidates to the existing final ranker. VARG-ID constructs semantic prefixes using RQ-VAE, enhances search relevance through bidirectional query-item contrastive learning, and combines these prefixes with a value-ordered third token to provide fine-grained item addresses and a business-value prior. Three-stage supervised fine-tuning progressively learns item-to-identifier mappings, query-semantic retrieval, and personalized retrieval. Personalized model training combines value-aware and hierarchy-aligned supervision with expanded user context, and uses local ordinal supervision (LO-SFT) to learn the local within-cluster ordering encoded by the third token. Prefix-GRPO combines gated rewards based on output legality, user behavior, ranker advantage, and search relevance with prefix-aware token weighting to align candidate generation with business value and ranking objectives. Coordinated daily product and model updates preserve existing item addresses while incorporating new products and behavioral feedback. Offline experiments on tens of millions of products validate identifier stability and demonstrate gains in retrieval quality and head-level value recall from SFT strategies and Prefix-GRPO over their respective baselines. In a 14-day online A/B test covering 20% of search traffic, VARG directly admits generated candidates to the final ranker and improves GMV by 1.45%, per-user IPV by 0.22%, and PCTR by 0.31%. Online shopping-guide query evaluations further show that VARG maintains competitive relevance with a smaller candidate quota.

- **整体含义**：VARG 试图在工业级动态商品库中，将生成式检索从“生成有效 ID”推进到“生成高价值、可排序、可直接服务最终排序器的候选”。

## 2. 方法论

### 2.1 VARG-ID：语义前缀 + 价值排序第三 token

- **语义前缀构建**：
  - 商品嵌入融合类别、品牌等属性，经商品编码器得到 \(z_i\)。
  - 使用两级 RQ-VAE 残差量化，依次得到 \(s_1\)、\(s_2\)，构成语义前缀 \(c(i)=(s_1,s_2)\)。
  - 查询编码器仅在 tokenizer 训练阶段使用，通过**双向查询—商品对比学习**（InfoNCE）将查询与商品表示拉近，把搜索相关性注入量化前的表示空间。
  - tokenizer 总损失由重建损失、commitment 损失和双向 Q2I 对比损失组成。
- **价值排序第三 token**：
  - 第三 token \(r_i\) 表示商品在同一语义前缀内的价值排序位置，零基且 \(0 \le r_i < K_3\)。
  - 使用经验贝叶斯平滑估计转化率，并结合漏斗行为分数、GMV 和 ID 做字典序排序：转化率降序 → 漏斗价值降序 → GMV 降序 → ID 升序。
  - 初始构建时，VARG-ID 实现**无碰撞商品地址**：每个商品有唯一三元组 \((s_1,s_2,r)\)。
- **标识符稳定性观察**：
  - 实验发现 EB-CVR 排序比点击、销量排序更稳定，第三 token 变化更少、位移更小、Top-20 保留率更高。
  - 固定 SFT 模型参数后重新排序会显著破坏完整 SID 检索性能，因此系统采用**冻结增量更新**，尽量保留已有商品地址。

### 2.2 双循环每日刷新

- **商品循环**：
  - 同一主 SID 版本内冻结 RQ-VAE 和 SID 词表，保留已有商品 SID。
  - 新商品按簇内价值排序复用历史槽位；若排名落在已有商品之间，则共享该槽位，已有商品地址不变。
  - 新前缀从 0 开始分配地址；超出槽位范围时映射到最后一个槽位。
- **模型循环**：
  - 每日用最新点击/购买数据，按行为发生时的 SID 映射打标。
  - 在同一主版本内继续训练上一版个性化生成模型，混合历史回放数据，保留已学地址关系。
  - 验证后，模型、Trie 和 SID-to-item 映射原子化发布为兼容版本组合。
- **月度重建**：引入新主版本，重新编码训练标签、历史 SID 和回放数据，重新训练检索模型后联合部署。

### 2.3 三阶段 SFT

- 基础模型为 Qwen2.5-0.5B-Instruct，扩展 SID 专用 token，自回归生成三元组 \((s_1,s_2,r)\)。
- **阶段 1**：Item → SID，学习商品到标识符的映射，建立商品地址记忆。
- **阶段 2**：Query → SID，学习查询语义检索。
- **阶段 3**：User + Query + History → SID，学习个性化检索。
- **个性化上下文扩展**：
  - 输入包括当前查询、用户画像、相关类目点击历史 SID、最近若干搜索查询、跨域全局兴趣摘要。
- **Q2I 样本加权**：
  - 用查询—商品对的历史购买/点击统计做经验贝叶斯平滑，计算转化率相对全局先验的权重，裁剪归一化后加权训练样本，仅在阶段 3 启用。
- **层级感知 token 加权**：
  - 三级 token 决策角色不同：\(s_1\) 粗粒度区域，\(s_2\) 细粒度前缀，\(r\) 仅在前缀正确后区分商品。
  - 离线发现第二层是主要预测瓶颈，因此设 \( \alpha_2 > \alpha_1 > \alpha_3 > 0 \)，增强前两层监督。
- **LO-SFT 局部序数监督**：
  - 标准交叉熵把 rank token 当离散类别，未利用序数距离。
  - LO-SFT 在真实 rank 附近构造随距离衰减的局部目标分布，保留精确 token 损失，同时引导模型学习 EB-CVR 排序编码的簇内局部顺序。

### 2.4 Prefix-GRPO：门控多源奖励 + 前缀感知加权

- 在 SFT 基础上使用 GRPO 调整候选生成概率。
- **响应契约**：响应必须是合法且占用的 SID；畸形或未占用输出只获得负奖励。
- **门控多源奖励**：
  - **用户行为奖励**：购买 > 点击 > 曝光，最高匹配动作给奖励。
  - **排序器优势奖励**：用生产排序器分数相对同一请求候选均值的标准化优势，经 tanh 有界化，只保留正优势。
  - **相关性奖励**：仅对没有匹配用户行为的占用 SID 使用，避免与行为奖励重复计数。
  - **合法性门控**：畸形输出、未占用输出分别给负惩罚，防止无效输出获得正收益。
- **前缀感知 token 加权**：
  - 根据当前前缀下合法子 token 数量分配策略损失权重，合法分支越多权重越高。
  - 第一层权重固定为 1，后两层按合法子节点数对数映射到 \([d,1]\)；EOS、控制 token 和单分支路径使用下限 \(d\)。
- **优化**：
  - 使用组内相对优势，经标准化、白化和裁剪。
  - 采用 PPO 式裁剪目标，负优势时应用 dual clipping，并加入相对 SFT 参考策略的 KL 正则。
