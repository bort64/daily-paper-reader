## 摘要
生成式推荐已成为一种有前景的个性化推荐端到端范式。然而，用户偏好会随时间不断演化，这使得自演化成为生成式推荐系统的一项必要能力。现有的演化策略，例如持续重训练和基于蒸馏的适配，利用流式交互直接更新共享模型参数。然而，我们发现，将这类策略直接应用于生成式推荐会引入一个关键问题，称为演化冲突。具体而言，来自不同用户的异构偏好漂移在一个完全共享的自回归参数空间中被优化，导致主导行为模式逐渐主导模型演化过程，而代表性不足的模式则日益被忽视。为解决这一问题，我们提出了一种面向生成式推荐的自演化记忆范式，旨在实现跨异构行为模式的有效演化。我们进一步确定了有效自演化推荐系统的三条关键原则，包括隔离记忆、强化演化和可扩展应用。在这些原则指导下，我们开发了 LION，一个以稀疏键值记忆层为中心的简单而有效的框架。具体而言，LION 引入稀疏记忆激活来隔离不同行为模式的演化，同时设计了一种巩固损失，以在持续适应过程中强化对代表性不足的偏好动态的学习。在多种真实世界数据集上的大量实验表明，LION 在各种持续演化设置下（例如分时段评估、用户/物品组评估和演化收敛性分析）均具有有效性。代码已发布于 https://github.com/JazyJiang/Self-Evolving-Memory-for-Generative-Recommendation。

## Abstract
Generative recommendation has emerged as a promising end-to-end paradigm for personalized recommendation. However, user preferences continuously evolve over time, making self-evolving an essential capability for generative recommender systems. Existing evolving strategies, such as continual retraining and distillation-based adaptation, directly update the shared model parameters using streaming interactions. Nevertheless, we find that directly applying such strategies to generative recommendation introduces a critical issue, termed evolution conflict. Specifically, heterogeneous preference shifts from different users are optimized within a fully shared autoregressive parameter space, causing dominant behavioral patterns to progressively dominate the model evolution process while underrepresented patterns become increasingly overlooked. To address this issue, we propose a self-evolving memory paradigm for generative recommendation, aiming to enable effective evolution across heterogeneous behavioral patterns. We further identify three key principles for effective self-evolving recommendation systems, including isolated memorization, reinforced evolution, and scalable application. Guided by these principles, we develop LION, a simple yet effective framework centered on a sparse Key-Value memory layer. Specifically, LION introduces sparse memory activation to isolate the evolution of different behavioral patterns, while a consolidation loss is designed to reinforce the learning of underrepresented preference dynamics during continual adaptation. Extensive experiments on diverse real-world datasets demonstrate the effectiveness of LION under various continual evolution settings (e.g., per-period evaluation, user/item group evaluation, and evolution convergence analysis). The codes are released at https://github.com/JazyJiang/Self-Evolving-Memory-for-Generative-Recommendation.

## 1. 核心问题与整体含义

- **背景**：生成式推荐（Generative Recommendation）以自回归方式直接生成物品标识符（item identifier），将用户历史编码与物品生成统一在单一共享参数空间（如 Transformer 骨干）中，已成为端到端个性化推荐的重要范式（TIGER、HSTU、OneRec 等）。
- **现实挑战**：用户偏好持续演化，模型必须具备**自演化（self-evolving）能力**，需基于流式交互不断更新参数以对齐用户当前意图。
- **现有策略**：
  - 持续重训练 / 持续微调：仅用当前周期数据更新共享参数，易覆盖旧知识。
  - 基于蒸馏 / 正则化的适配：用历史数据或表示变化约束更新，平衡稳定性与可塑性。
- **核心问题——演化冲突（Evolution Conflict）**：
  - 将上述策略直接用于生成式推荐时，不同用户的异构偏好漂移在**完全共享的自回归参数空间**中共同优化。
  - 主导行为模式（活跃用户的高频模式）逐渐主导模型演化方向，欠代表模式（不活跃用户、长尾兴趣）被系统性忽视。
  - 实证：TIGER 在 Toys 数据集从 Period 0 演化到 Period 1 时，活跃用户性能提升，但不活跃用户（G3–G5）性能下降，整体性能反而下滑（图 2）。
- **梯度层面的机理分析**：
  - 目标分解为 `L_rec = L_c + L_unc`，对应梯度 `g_c`、`g_unc`。
  - 冲突性：`g_c^T g_unc < 0`（优化方向相互抵消）。
  - 不对称性：`||g_c|| >> ||g_unc||`（主导模式梯度幅度远大于欠代表模式）。
  - 参数更新 `θ_{τ+1} = θ_τ − η(g_c + g_unc)` 被 `g_c` 逐步主导，造成**双重次优**：主导模式被 `g_unc` 部分抵消，欠代表模式被 `g_c` 持续压制。
- **整体含义**：论文主张以**结构化、可控的自演化记忆范式**取代共享参数的耦合演化，并提出三条设计原则：**隔离记忆（Isolated Memorization）、强化演化（Reinforced Evolution）、可扩展应用（Scalable Application）**。

## 2. 方法论

### 2.1 核心思想
- 用**稀疏 Key-Value 记忆层**替代稠密的用户专属参数，让不同行为模式通过**不同稀疏记忆槽**演化，实现参数层面的模式隔离。
- 以**巩固损失**直接监督记忆增强表示，为欠代表模式提供更强监督信号。
- 记忆参数量固定，不随用户规模增长，天然支持大规模部署。

### 2.2 关键技术细节

- **稀疏 Key-Value 记忆层**：
  - 记忆由 N 个可训练键值对构成：`M = {(k_i, v_i)}_{i=1}^N`，`k_i, v_i ∈ R^d`。
  - **稀疏激活**：给定隐藏表示 `h_u`，计算与所有键的相似度 `s_i = h_u^T k_i`，取 Top-K 得到激活索引集 `A`。
  - **加权聚合**：`m_u = Σ_{i∈A} α_i v_i`，其中 `α_i` 为激活槽内相似度的 min-max 归一化权重。
  - **残差集成**：`h̃_u = h_u + m_u`，回注到后续 Transformer 前向流程。
- **全序列记忆查询（Full-Sequence Memory Query）**：
  - 记忆 query 由用户**完整历史** `S^full_u` 计算，而记忆层前后的 Transformer 层仅使用**近期子序列** `S^rec_u`（recency window `h_rec`）。
  - 这种**非对称设计**在保证路由基于完整行为上下文的同时，维持骨干计算效率。
- **强化演化（双损失训练）**：
  - 推荐损失：`L_rec = −Σ_u Σ_t log P(i_{t+1} | i_{≤t}; θ)`。
  - 巩固损失：`L_con = −Σ_u Σ_t log P(i_{t+1} | h̃_u; θ)`，直接监督记忆增强表示。
  - 总目标：`L = L_rec + λ L_con`，`λ` 控制巩固监督强度。
- **实例化流程**：
  - 记忆层插入 Transformer 中间层（实验默认第 5 层）。
  - 每个演化周期 `P_τ` 到达后，持续微调骨干与记忆参数，得到 `θ_τ`，部署用于下一周期 `P_{τ+1}` 的自回归生成。

### 2.3 理论分析

- **定理 4.1（梯度冲突降低）**：
  - 设共同/非共同模式的激活集为 `A_c`、`A_unc`，重叠集 `O = A_c ∩ A_unc`，重叠比 `ρ = |O|/K`。
  - `Conflict_LION = Σ_{i∈O} max(0, −⟨g^c_i, g^unc_i⟩)`，且 `Conflict_LION / Conflict_Baseline ≤ ρ`。
  - 即冲突被严格限制在重叠区域，非重叠槽最多只接收一个梯度，不产生冲突。
- **推论 4.1（自改进隔离）**：训练推进中路由键趋于专业化，`|O| → 0`，`ρ → 0`。作者明确将其视为**经验观察趋势**而非理论保证。
- **定理 4.2（更快的逐模式收敛）**：
  - 噪声方差建模：`σ²_c = σ²_0 + β²·E[||ḡ_c||²]`；LION 下 `σ²_{c,LION} = σ²_0 + ρ·β²·E[||ḡ_c||²]`。
  - 由 SGD 非凸收敛界可得 LION 达到 ε-稳定所需步数更少，加速比 `T_LION / T_Baseline ≤ 1`。
- **推论 4.2**：欠代表模式受主导模式干扰更小，`|O|` 更小，收敛加速更明显，解释其在实验中收益更大的现象。
- **参数效率（4.2.3）**：
  - LION 仅需 `2Nd` 参数，与用户数 `|U|` 无关；稠密用户个性化需 `|U|·d`。
  - 当 `|U| > 2N` 时 LION 更省，新增用户零额外参数。
  - 组合表达力 `C(N,K)` 远超用户数（如 `C(256,8) ≈ 10^15`），保证唯一表示。
  - 参数比 `Params_LION / Params_Dense = 2N/|U| → 0`（`|U| → ∞`）。
