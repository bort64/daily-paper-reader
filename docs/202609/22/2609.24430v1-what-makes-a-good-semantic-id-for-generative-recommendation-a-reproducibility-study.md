## 摘要
生成式推荐已成为一个活跃的研究方向，其中物品通常由语义ID（SID）表示：逐个 token 生成的离散编码。尽管取得了强有力的实证结果，但 SID 设计在构建策略、码本组织和码长方面差异很大，使其对推荐性能的真实影响尚不清楚。我们开展了一项大规模可复现性研究，在统一的实验框架下系统考察语义 ID 设计对生成式推荐的影响。我们聚焦一个基本问题：什么造就了生成式推荐中的良好语义 ID？为回答这一问题，我们考察四个方面：不同语义 ID 设计的相对有效性、码本利用率与推荐质量之间的联系、语义码长的影响，以及语义 ID 设计对局部物品语义保持的影响。通过统一评估和额外的跨数据集受控分析，我们发现 SID 设计的影响在很大程度上是非单调的：没有哪一种 SID 设计普遍最优，常用的基于 RQ-VAE 和基于 OPQ 的设计在不同数据集上可能表现不一致。具有最均衡第一级码本的方法并不总是最佳推荐器，这表明利用率具有诊断价值但尚不充分。扩大生成式主干或 SID 长度也并非总是有益。最后，语义邻域分析表明，没有任何一种 SID 设计在所有局部语义保持概念上都占优；相反，不同设计展现出互补优势，且这些优势在不同数据集和邻域大小下保持稳定。我们的研究为语义 ID 设计提供了受控且可复现的理解，并为未来生成式推荐系统提供了实用见解。

## Abstract
Generative recommendation has emerged as an active research direction, where items are commonly represented by semantic IDs (SIDs): discrete codes generated token by token. Despite strong empirical results, SID designs vary widely in construction strategy, codebook organization, and code length, making their true impact on recommendation performance unclear.   We conduct a large-scale reproducibility study to systematically investigate the impact of semantic ID design on generative recommendation under a unified experimental framework. We focus on a fundamental question: What makes a good semantic ID for generative recommendation? To answer this question, we examine four aspects: the relative effectiveness of different semantic ID designs, the connection between codebook utilization and recommendation quality, the effect of semantic code length, and the influence of semantic ID design on local item semantic preservation. Through a unified evaluation and additional cross-dataset controlled analyses, we find that the effects of SID design are largely non-monotonic: no single SID design is universally best, and commonly used RQ-VAE- and OPQ-based designs can behave inconsistently across datasets. The method with the most balanced first-level codebook is not consistently the best recommender, showing that utilization is diagnostic but insufficient. Scaling either the generative backbone or the SID length is also not always beneficial. Finally, semantic-neighborhood analysis reveals that no single SID design dominates all notions of local semantic preservation; instead, different designs exhibit complementary strengths that remain stable across datasets and neighborhood sizes. Our study provides a controlled and reproducible understanding of semantic ID design and offers practical insights for future generative recommender systems.

## 1. 核心问题与整体含义

- **研究背景**：生成式推荐将推荐任务建模为序列生成问题，物品由语义ID（Semantic ID, SID）——即从物品语义中派生、逐 token 生成的离散编码——表示。相比随机分配的原子ID，SID 携带更丰富的语义信息，能更好地利用语言模型的预训练知识，已成为生成式推荐的主流设计。
- **核心问题**：SID 设计在构建策略（聚类、量化、层次化、可学习编码等）、码本组织与码长方面差异极大。已有研究在不同数据集、主干网络、训练配方下评估，导致无法隔离 SID 本身的影响，社区缺乏统一的可复现理解。
- **研究目标**：在统一实验框架下开展大规模可复现性研究，回答一个根本问题——**什么造就了生成式推荐中的良好语义ID？** 并将其分解为四个子问题：
  - **RQ1**：在统一数据划分与评估协议下，哪种代表性 SID 生成式推荐系统表现最好？
  - **RQ2**：哪种 SID 设计码本利用率最高？高利用率是否带来更好的推荐性能？
  - **RQ3**：不同 SID 的扩展行为（SID 长度、生成式主干规模）如何？
  - **RQ4**：不同 SID 设计如何影响局部物品语义保持？

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：构建统一实验框架，包含两个层级的比较：
  1. **方法级整体基准**（RQ1）：所有方法共享相同的预处理、数据划分与评估打分器，但保留各自原始的训练与推理设计。
  2. **受控 SID-only 分析**（RQ2–RQ4）：固定生成式主干与训练协议，仅改变 SID 分配，以隔离标识符本身的影响。
- **任务形式化**：
  - 语义ID tokenizer $q: \mathcal{I} \to \mathcal{C}_1 \times \cdots \times \mathcal{C}_L$，将物品 $i$ 映射为 $L$ 个 token 的编码序列 $q(i)=(z_{i,1},\dots,z_{i,L})$，$\mathcal{C}_\ell$ 为第 $\ell$ 级码本。
  - 用户历史序列经 SID 转换后，模型学习自回归生成目标物品的语义ID：
    $$p_\theta(i_{t+1}^u \mid S_u^t) \equiv p_\theta(q(i_{t+1}^u) \mid Z_u^t) = \prod_{\ell=1}^{L} p_\theta(z_{t+1,\ell}^u \mid Z_u^t, z_{t+1,<\ell}^u)$$
  - 推理时生成合法 SID 序列，再通过码到物品字典映射回物品。
- **受控分析设置**：固定 TIGER 框架（简单且被广泛采用的自回归 SID 生成框架），保持训练目标、解码流程与评估管线不变，仅改变 SID 分配。
- **推理与后处理**：采用约束式 trie 前缀解码生成 top-K 预测；候选经统一后处理管线——移除用户训练历史中已出现的物品，并用训练期热门物品填充剩余槽位，保证 K 个有效推荐。
- **码本利用率诊断指标**：used codes、熵、归一化熵、困惑度、有效使用量、Gini 系数、前缀利用率、碰撞率；主文聚焦第一级归一化熵 $H_1^{norm} = -\sum_c p_{1,c}\log p_{1,c} / \log|\mathcal{C}_1|$。
- **局部语义保持度量**：对每个物品检索参考语义空间与各 SID 设计下的 top-K 最近邻，用 **Jaccard@K**（严格邻居集合恢复）与 **RBO@K**（排序偏置重叠，更重视顶部排序一致性）比较。

## 6. 主要结论与发现

- **RQ1（整体基准）**：
  - **没有方法在所有数据集上占优**。RPG 整体最强（Video Games 第一，Microlens 与 Yelp 第二）；SEATER 在 Microlens 最佳，LETTER-TIGER 在 Yelp 最佳。
  - SASRec 作为轻量基线在 Microlens 与 Yelp 上优于多个生成式方法——**生成式推荐并不自动优于传统序列推荐**。
  - 同一构建家族内部表现差异大（如 OPQ 家族中 RPG 与 DiffGRM 差距明显），说明 SID 有效性不取决于高层 tokenizer 类型，而由完整系统设计（tokenizer 目标、码组织、解码策略、与数据兼容性）共同决定。
  - CF 信号注入并非一致有益：Video Games 上多数 CF 增强方法不如 TIGER，而 Microlens 与 Yelp 上有明显增益；LETTER-TIGER 行为最稳定，说明**将 CF 作为 SID 构建的正则化信号**比直接依赖 CF 表示更稳健。
- **RQ2（码本利用率）**：
  - RQ-Kmeans 的第一级码本最均衡（归一化熵接近 1.0，有效使用量高，Gini 低），LETTER-no-div 最不均衡；L2/L3 层所有方法归一化熵均超 0.98，碰撞率低（0.013–0.025）。
  - **利用率与推荐质量近乎零相关**（Pearson $r=-0.02$，Spearman $\rho=-0.08$）；多样性正则化将 L1 归一化熵提升约 0.11，但 NDCG@10 变化至多 0.002。利用率是**诊断性指标但非充分标准**。
- **RQ3（扩展分析）**：
  - **主干扩展非单调**：T5-small → T5-large 并非一致提升，部分方法在 Video Games 上显著退化；在更大的 Microlens-100K 上退化变缓，说明数据稀疏/过拟合是可能原因之一。
  - **码长扩展非单调**：RQ-Kmeans 偏好紧凑码（约 $L=3$）；RQ-VAE 在 top-5 上偏好 $L=3$，top-10 最佳在 $L=12$；OPQ 在 $L=6$ 时最佳，过长则退化。反映**标识符容量与生成难度之间的权衡**。
- **RQ4（局部语义保持）**：
  - **OPQ 在全部四个数据集上 Jaccard@20 最高**（0.1640–0.1741），最能恢复参考邻居集合。
  - **RQ-Kmeans 在全部四个数据集上 RBO@20 最高**（0.1900–0.1974），最能保持最近邻排序。
  - 结论在 $K \in \{10,20,50\}$ 下基本稳健（仅 Yelp 在 $K=10$ 时 OPQ 以 0.0004 微弱反超）。
  - SEATER 两项指标均最低；TIGER、HowToIndex、LETTER 处于中低层。说明**生成合法离散标识符并不必然保持细粒度语义邻域**。
- **总体结论**：SID 设计效应**大规模非单调**；有效 SID 设计应综合推荐质量、利用率、可生成性、扩展行为与语义几何共同评判。
