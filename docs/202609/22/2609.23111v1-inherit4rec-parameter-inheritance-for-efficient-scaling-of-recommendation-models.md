## 摘要
扩展模型容量已成为克服工业推荐系统性能瓶颈的有效方法。然而，反复从头训练更大的稠密模型需要大量数据和时间，而其不断增长的计算量又与工业系统严格的服务预算相冲突。参数继承为稠密模型增长和稀疏化转换提供了一条有前景的途径，但现有方法主要针对静态语料库设计，在动态演变的推荐数据下可能出现性能急剧下降。为应对这些挑战，我们提出 Inherit4Rec，一个支持稠密到稠密（Dense-to-Dense，D2D）增长和稠密到稀疏（Dense-to-Sparse，D2S）转换的参数继承框架。Inherit4Rec-D2D 将混合增长与非对称训练相结合，以在扩展时保持前向函数并维持更新连续性。Inherit4Rec-D2S 通过共激活感知划分和负载均衡损失构建 SMoE 网络，在保持稠密模型能力的同时促进专家激活均衡。在 KuaiRand-1K 和工业短视频推荐数据集上的实验表明，两种转换在所有预测目标上均持续优于所评估的继承基线。这些结果证明了 Inherit4Rec 在工业推荐系统中实现持续容量扩展和计算高效的稀疏转换方面的有效性。

## Abstract
Scaling model capacity has emerged as an effective approach to overcoming performance bottlenecks in industrial recommender systems. However, repeatedly training larger dense models from scratch demands substantial data and time, while their growing computation conflicts with the strict serving budgets of industrial systems. Parameter inheritance provides a promising route for both dense model growth and sparse conversion, yet existing methods are primarily designed for static corpora and can suffer sharp performance drops under dynamically evolving recommendation data. To address these challenges, we propose Inherit4Rec, a parameter-inheritance framework that supports both Dense-to-Dense (D2D) growth and Dense-to-Sparse (D2S) conversion. Inherit4Rec-D2D combines hybrid growth with asymmetric training to preserve the forward function at expansion and maintain update continuity. Inherit4Rec-D2S constructs SMoE networks through co-activation-aware partitioning and a load-balancing loss, preserving dense-model capabilities while promoting balanced expert activation. Experiments on KuaiRand-1K and an industrial short-video recommendation dataset show that both transformations consistently outperform the evaluated inheritance baselines across all prediction objectives. These results demonstrate the effectiveness of Inherit4Rec for continual capacity expansion and computation-efficient sparse conversion in industrial recommender systems.

- **关键切入点**：参数继承（复用已训练参数）在 LLM 中已有两条成熟路线——稠密扩张（Net2Net、bert2BERT、LiGO、MSG、LEMON、SPARKLING）与稠密转 MoE（LLaMA-MoE、G-MoEfication）。

## 2. 方法论

### 2.1 总体思路与建模前提

- 训练被形式化为流式过程：每个时间窗 t 有批次 B_t，检查点 C_t = (θ_t, s_t)（参数 + 优化器统计/学习率计划/训练进度），更新为 C_{t+1} = U(C_t; B_{t+1})。
- 变换只作用于模型的 **per-token FFN**，其余模块在转换点保持不变；从当前检查点构造 C⁺_t 后直接继续训练，不重启。
- **通道级视角**（全方法的基石）：对 SwiGLU FFN
  - h(x) = SiLU(xW_gate) ⊙ (xW_up)，F_Dense(x) = h(x)W_down；
  - 输出可分解为隐藏通道贡献之和 F_Dense(x) = Σ_j h_j(x)·W_down,j:；
  - 因此把 W_gate 第 j 列、W_up 第 j 列、W_down 第 j 行视为**一个通道单元**，D2D 与 D2S 都基于该单元做操作。

### 2.2 四条设计原则（形式化于附录 A.4）

- **D2D**：① *Forward Stability*（扩展瞬间保持原 FFN 输出，误差 E^f）；② *Update Continuity*（扩展后继承通道平滑偏离原优化轨迹，误差 E^u，用归一化 RMS 偏差度量）。
- **D2S**：③ *Capability Preservation*（稀疏路由下保留原稠密 FFN 输出，误差 E^c 为归一化 MSE/NMSE）；④ *Balanced Activation*（路由概率分布均衡，用负载变异系数 CV_load 与归一化熵 H_load 度量）。

### 2.3 Inherit4Rec-D2D：混合增长 + 非对称训练

- **混合增长（Hybrid Growth）**：对源 FFN 的每个通道复制 c 份，隐藏维从 d_hid 扩到 (c+1)d_hid。
  - 新块的 gate/up 投影**直接复制**源参数，因此新块激活与源完全相同：h^(q)(x) = h(x)。
  - 新块的 down 投影从源 W_down 的逐元素经验分布 N(μ_down, σ²_down) 独立采样，并在副本间**中心化**：Ŵ^(q)_down = W^(q)_down − (1/c)Σ_r W^(r)_down，使 Σ_q Ŵ^(q)_down = 0。
  - 由于新块激活相同、down 贡献之和为零，扩展后输出严格等于原输出：F⁺_Dense(x) = F_Dense(x)（精确算术下前向保真）。
- **对称性打破**：中心化后各副本 down 投影互不相同，上游梯度 ∂L/∂h^(q) = δ(Ŵ^(q)_down)ᵀ 不同，使复制的 gate/up 在后续训练中分化出不同表示。零和约束**仅在初始化时施加**。
- **非对称训练（Asymmetric Training）**：继承参数保留一阶/二阶优化器矩与原有学习率计划；新参数从零矩开始并采用**独立的 warmup + 衰减**计划，使新容量贡献逐步释放，保证更新连续性。（工业配置：500 步线性 warmup 到 3×10⁻³ = 1.5× 基础学习率，再 1000 步 cosine 退火回 2×10⁻³。）

### 2.4 Inherit4Rec-D2S：共激活感知划分 + 负载均衡

- **结构**：把 d_hid 个通道重组为 **1 个 always-on 共享专家 + R 个路由专家**，每个专家宽 m = d_hid/(R+1)；每个输入激活共享专家 + top-1 路由专家，即活跃宽度 2m = 2/(R+1) 的原始宽度。
- **通道分配（Calibration）**：冻结稠密检查点，用转换时刻**因果可得**的流式样本做纯前向校准，按通道平均平方输出贡献打分：I_j = (1/N)Σ_n ‖h_j(x_n)W_down,j:‖²。贡献最高的 m 个通道构成共享专家。
- **共激活相似度**：对每个样本保留贡献幅值 top-K_c 且超过阈值 γ 的通道得到指示 b_j(x_n)；统计共激活计数 C_ij 与边际支撑 n_i，定义支撑感知相似度 G_ij = (C_ij/√(n_i n_j)) · (C_ij/(C_ij+τ))，第一项归一化边际频率，第二项抑制低支撑共现。
- **划分目标**：在 |E_r| = m、互不相交的约束下最大化专家内部相似度之和 max Σ_r Σ_{i<j∈E_r} G_ij。
- **求解流程**：① 容量受限贪心播种——以加权度 d_i = Σ_j G_ij 最大的通道为首个种子，后续种子用打分 q_i（兼顾代表性与与已有种子的差异度）选出；② 按度降序贪心分配，分配分数 A(i,r) 由亲和度 + 剩余容量奖励 β 构成；③ 最多两轮**交换精修**（保留正增益交换，容量不变）；④ 4 个随机打破平局的候选划分，按专家内边权占比 ρ 选优。
- **稀疏前向与路由**：路由 W_R ∈ R^{d×R}，选 top-1 专家，门控权重 g(x) = max_r [softmax(xW_R)]_r，输出 F_MoE(x) = E_s(x) + g(x)·E_r(x)。
- **负载均衡训练**：采用 Switch 风格辅助损失 L_bal = R·Σ_r f_r·p̄_r（f_r 为分配比例，p̄_r 为 top-1 前的平均 softmax 概率），总损失 L = L_task + λ_bal·L_bal，λ_bal = 0.01。
- **参数/优化器状态迁移**：专家参数是稠密 FFN 的通道对齐切片（W_gate[:,B]、W_up[:,B]、W_down[B,:]），优化器张量按相同索引切片；唯一新模块 router 用零均值截断正态（σ=0.01）初始化并配全新优化器状态；所有专家与 router 均保持可训练。

## 3. 实验设计

- **数据集/场景**：
  - 公开数据集 **KuaiRand-1K**；
  - **工业短视频推荐单页数据集**（每个样本为用户—视频交互及其反馈）。
  - 每个数据集含 **4 个预测目标**：KuaiRand-1K 为 Effective-view / Long-view / Comment / Like；工业集为 Effective-view / Long-view / Follow / Like。
- **评价指标**：统一使用 **GAUC**（推荐领域常用）。
- **骨干模型（Benchmark 基础）**：**UniFormer**（因其在行为建模、特征交互、任务建模上的均衡协同扩展设计）。
- **D2D 对比方法**：Seed(Base)（保持源结构继续训练）、Train-from-Scratch（目标结构随机初始化，作为 Oracle 上界参考）、**bert2BERT**（函数保持的宽度复制扩展）、**SPARKLING**（信号尺度保持 + 对称性打破的宽度渐进训练）。
- **D2S 对比方法**：Seed(Base)、Train-from-Scratch Dense 与 SMoE（后者为对应 Oracle）、**LLaMA-MoE**、**G-MoEfication**（平衡 K-means 聚类构建专家 + 保留代表性激活值）。所有 MoE 在**匹配的 FFN 激活预算**下评估，所有基于检查点的转换方法从**同一 Dense 检查点**初始化。
