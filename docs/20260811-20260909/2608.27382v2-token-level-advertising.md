## 摘要
生成式人工智能正在改变人们获取信息的方式，对围绕预定义槽构建的传统广告机制提出了挑战。面向生成原生的广告，我们提出了潜在广告商混合拍卖（LAMA），一种令牌级广告机制，将广告商影响力直接嵌入生成过程。广告商报告局部延续价值，这些价值诱导特定于广告商的下一令牌策略，平台通过潜在混合进行解码，同时更新分配后验。我们证明LAMA满足马尔可夫主导策略激励兼容（DSIC）和个体理性（IR），并实现接近最优的KL正则化福利。我们进一步开发了一种基于学习的实现，该实现从学习的局部优势和根值在线重构所需报告。在真实世界商业搜索查询分割上的概念验证实验表明，LAMA在保持面向用户响应质量的同时提高了平台福利和收入，为生成原生广告的可行性提供了初步证据。

## Abstract
Generative AI is transforming how people access information, challenging traditional advertising mechanisms built around predefined slots. Towards generation-native advertising, we propose the Latent Advertiser Mixture Auction (LAMA), a token-level advertising mechanism that embeds advertiser influence directly into the generation process. Advertisers report local continuation values that induce advertiser-specific next-token policies, from which the platform decodes through a latent mixture while updating an allocation posterior. We show that LAMA satisfies Markov DSIC and IR, and achieves near-optimal KL-regularized welfare. We further develop a learning-based implementation that reconstructs the required reports online from learned local advantages and root values. Proof-of-concept experiments on real-world commercial-search query splits show that LAMA improves platform welfare and revenue while maintaining user-facing response quality, providing initial evidence for the feasibility of generation-native advertising.

## 1. 核心问题与整体含义（研究动机与背景）

- **传统广告的“槽位”抽象受到挑战**：传统互联网广告（搜索广告、展示广告、推荐流广告）建立在预定义“槽位”之上，即广告机会可以在拍卖前定义并分配。经典拍卖理论（GSP、VCG 等）主要回答“谁获得已有槽位”的问题，而把“存在哪些机会”当作外生给定。
- **生成式 AI 改变信息访问方式**：生成式界面（LLM 对话/生成式搜索）不再只是检索和排序已有内容，而是围绕用户意图动态合成响应。一个品牌是否相关、是否自然，取决于回答沿着哪个方向展开——广告机会是由生成过程本身内生塑造的，而非预先给定的。因此采用“生成之后插入广告”或“先构造候选再分配”的做法，本质上仍是在已识别的机会上进行分配，没有让生成过程本身参与分配。
- **论文的核心主张**：提出“生成原生广告”（generation-native advertising）范式，将广告主影响直接嵌入 token 级生成过程；在此基础上针对最基本的单赢家（single-winner）场景提出 **LAMA（Latent Advertiser Mixture Auction，潜在广告主混合拍卖）**，让广告主在每个前缀参与生成、共同塑造回答与最终分配。

## 2. 方法论：核心思想、关键技术细节与流程

**核心思想**：将生成过程视为一个贝叶斯序贯决策过程，用于识别“对当前生成机会估值最高的广告主”。广告主按前缀上报“延续价值”，平台据此维持一个分配后验（allocation posterior），并依据该后验做分层采样生成 token。

**关键机制细节**：

- **序贯报告（Sequential reports）**：在非终止状态 \(s\)，广告主 \(i\) 报告子节点价值向量 \(\hat{V}^s_i([s,a])_{a\in V}\)；真实报告对应最优软价值函数 \(V^*_i\)。给定报告，可导出广告主特定的局部策略：
  \[
  \hat{\pi}_i(a|s;\hat{V}^s_i) \propto \pi_{\text{ref}}(a|s)\exp(\hat{V}^s_i([s,a])/\beta)
  \]
- **分配后验与下一 token 规则**：初始化后验 \(\rho_i(q)=Z_i(q)/\sum_j Z_j(q)\)；生成时先按 \(\rho(s)\) 采样潜在广告主 \(I\)，再按其诱导策略采样 token。边缘化后即为混合下一 token 分布 \(x(a|s)=\sum_i\rho_i(s)\hat{\pi}_i(a|s)\)。观察到 token 后用贝叶斯法则更新后验。
- **支付规则**：分两部分——初始根部的入场费 + 路径上的瞬时支付（按后验加权延续价值的增量收取/补贴）。最终终止后按后验 \(\rho(\ell)\) 分配。
- **可行消息空间（Bellman 一致性）**：平台要求新报告满足软 Bellman 递归，只保存标量（当前状态已记录的父值）即可在线校验。

**理论保证**：

- **Theorem 1**：LAMA 在 Bellman 一致性消息空间下是 **Markov DSIC 和 IR**。证明思路是把在线序贯报告在任意可达历史处的可行偏离“修补”（patching）为全局 Bellman 一致直接报告，再借助凸 log-sum-exp 势函数 \(\Phi_q\) 的支撑超平面不等式证明直接机制的诚实占优。
- **Theorem 2**：LAMA 的诚实策略是熵松弛福利最大化的解；相对最优 KL 正则化福利的损失上界为 \(\beta \log|N|\)，且当 \(\beta\to 0^+\) 时收敛到一阶最优福利 \(\max_\ell\max_i r_i(\ell)\)。

**实用化实现（第 4 节，解决广告主无法自行计算复杂报告的困难）**：

- 平台把“报数”作为服务（类似自动出价），把学习拆成两部分：
  1. **局部软优势** \(A^*_i(s,a)=V^*_i([s,a])-V^*_i(s)\)：用 Bradley-Terry 加权逐对比较的二元交叉熵目标训练 token 对数比率策略；
  2. **根值** \(V^*_i(q)\)：用终端奖励减去累计优势的残差期望进行锚定。
- **Theorem 3（精确恢复）**：在比较数据满支持下，上述两阶段学习的总体最优解能精确恢复最优软价值函数与根值，从而在线重构 LAMA 所需的真实报告。
- **共享报告模型**：所有广告主共享一个预训练主干（以 Qwen3-14B 为参考、用 LoRA 头微调），广告主信息通过提示词（\(\kappa_i\)，含身份与广告活动信息）注入，外加一个标量根值头。
- **服务算法（Algorithm 1）**：检索少数候选广告主后，线上逐 token 计算优势、构造 Bellman 一致的子值报告、分层采样 token、更新后验与台账；终止后按后验采样唯一赢家并结算（赢家支付制，保证结果 IR，并维持期望弱预算平衡 WBB）。

## 6. 主要结论与发现

- LAMA 在所有对比方法中取得最强综合表现：平台福利 0.5205、收入 0.8305、广告主价值 0.8568、用户质量 66.5239，均为主结果中最高或并列最高。
- 相比最强的“生成后分配 + Policy”基线，LAMA 在收入上有明显提升（约 0.75→0.83），同时在福利与广告主价值上也略有改善，并保持同等水平的用户侧回答质量。
- 案例研究显示 LAMA 能把广告主自然融入回答生成（如 Workout 中 Bowflex 哑铃自然出现在训练内容中），且出价偏移扫描表明 token 份额与分配概率随出价单调增加、真实效用如实出价处取峰——为机制激励性质提供了定性证据。
- 总体结论：token 级广告主参与可以在不牺牲回答质量的前提下提升变现效率，初步证明“生成原生广告”是可行的广告设计新范式。

- **问题新颖、范式前瞻**：首次明确提出并形式化“生成原生广告”——广告机会由生成过程内生塑造，而非先在外部形成再分配；回应了生成式 AI 对传统“槽位拍卖”的根本性挑战。
- **理论保证强且完整**：给出 Markov DSIC/IR、KL 正则化福利损失上界 \(\beta\log|N|\)、\(\beta\to 0\) 时渐近一阶最优等严格定理；对“在线序贯报告与全局直接报告等价性”的修补式证明清晰巧妙。
- **机制优雅、计算轻量**：贝叶斯后验 + 软 Bellman 一致性的设计使分配后验、混合策略与支付形成简洁的望远镜式结构；线上只需存储标量台账、检查一条约束，服务成本仅为常数倍前向。
- **实用化落地设计用心**：把难以手工计算的报告转为平台“报数服务”，通过“局部优势 + 根值”分解，将学习简化为排序式逐对比较目标与残差回归，且自带精确恢复（Theorem 3）理论支撑。
- **赢家支付结算变体的优化性质**：Prop. 1 证明随机化结算可实现结果（outcome）IR 与期望弱预算平衡，兼顾了实际可部署性。

## 8. 不足与局限

- **稿件状态与理论假设**：论文标注为“工作在进行中的预印本”；机制依赖参考策略在全空间 full support、广告主终端奖励非负、单赢家分配集等假设；Prop. 1 的 IR/WBB 依赖“随服务报告精确”的理想条件。
