## 摘要
基于语义ID的生成式推荐将检索和排序转化为对层级项目标识符的自回归生成。常见做法是先进行SFT再使用GRPO，但原始的GRPO并不适合这种树结构任务。在冻结的SFT检查点下，对于许多提示词，在50束约束排序的前16个候选中并不存在精确目标，而在更困难的情况下，这些候选均未进入目标SID分支。这种提示级诊断引发了一个训练问题：当同策略GRPO组同样缺少目标时，即便某些候选遵循了部分目标路径，项目级奖励也可能产生微弱或退化的奖励变化。我们提出了难度感知的语义ID优化（DASO），一种树感知的后训练方法，将这种失败模式视为在线 rollout 分配问题。DASO 不采用固定难度桶或统一注入真实完成，而是通过前缀匹配深度对每个当前 rollout 组进行画像，定位候选偏离目标路径的瓶颈SID层级，并将组中有限部分重新分配给前缀引导的完成，同时保留原始 rollout 作为对比。SID前缀奖励提供分级信用，而辅助的SFT锚点则缓解SFT检查点已解决示例上的回归。在公开基准上，DASO在12项指标中有11项优于 MiniOneRec 风格的 GRPO，并在12项中取得9项最佳结果；在内部推荐任务上也提升了多数层级召回指标。

## Abstract
Semantic-ID-based generative recommendation casts retrieval and ranking as autoregressive generation over hierarchical item identifiers. A common recipe is SFT followed by GRPO, yet vanilla GRPO is poorly matched to this tree-structured task. Under the frozen SFT checkpoint, the exact target is absent from the first 16 candidates of the 50-beam constrained ranking for many prompts, and in harder cases none of these candidates enters the target SID branch. This prompt-level diagnostic motivates a training concern: when on-policy GRPO groups are similarly target-missing, item-level rewards may produce weak or degenerate reward variation even if some candidates follow part of the target path. We propose Difficulty-Aware Semantic-ID Optimization (DASO), a tree-aware post-training method that addresses this failure mode as an online rollout-allocation problem. Instead of using fixed difficulty buckets or uniformly injecting ground-truth completions, DASO profiles each current rollout group by prefix-match depth, locates the bottleneck SID levels where candidates leave the target path, and reallocates a bounded portion of the group to prefix-guided completions while retaining raw rollouts for contrast. A SID-prefix reward provides graded credit, while an auxiliary SFT anchor mitigates regression on examples already solved by the SFT checkpoint. On the public benchmarks, DASO improves over MiniOneRec-style GRPO on 11 of 12 metrics and achieves the best result on 9 of 12 metrics; it also improves most level-wise recall metrics on the internal recommendation task.

## 1. 核心问题与研究动机

**研究背景：**
- 生成式推荐将传统的"召回 + 排序"pipeline 统一为对物品 ID 的自回归生成。
- 语义ID（Semantic-ID，SID）方案为每个物品构造离散的分层语义 token 序列，使推荐任务转化为受限解码下的自回归生成，代表性系统包括 TIGER、OneRec、MiniOneRec 等。
- 常用后训练流程为：SFT 初始化 + 约束解码 + 基于强化学习（GRPO）的偏好对齐。

**核心问题：**
- 标准 GRPO 在该任务中存在**结构性困难失配**：GRPO 依赖同一提示词的多条 rollout 之间的奖励差异来估计 advantage，但在树状 SID 空间中，大量提示词下的 rollout 组**整体偏离目标路径**（target-missing），导致奖励信号微弱甚至退化。

**关键诊断证据：**
- 在冻结的 SFT 检查点下，公开测试集中有 **52.5%–63.9% 的提示词**，其 50 束约束排序的前 16 个候选中**不包含任何首 token 匹配**的目标路径候选。
- 这类 target-missing 组在 MiniOneRec 奖励函数下会退化为全零或近全零的奖励，即使部分候选已经走了目标 SID 的部分前缀路径。
- 结果：vanilla GRPO 恰恰在最需要后训练介入（目标缺失）的提示词上，可能产生最弱的对比学习信号。

## 2. 方法：DASO

### 2.1 核心思想
DASO（Difficulty-Aware Semantic-ID Optimization）将上述问题建模为一个**在线 rollout 分配问题**：针对当前 rollout 组的实时目标路径覆盖情况，决定"是否干预、在哪些 SID 层级上干预、干预多少条 rollout"。

### 2.2 关键设计

**(1) 在线前缀深度画像（Online Prefix-Depth Profiling）**
- 定义前缀匹配深度 `m(ŝ, s*)`：生成 SID 与目标 SID 最长匹配前缀长度（0~M）。
- 对一组 G 条 rollout 计算累计画像 `p_j(x) = (1/G) Σ 1[d_i ≥ j]`，表示至少有 j 层前缀匹配的占比。
- 相邻层级的下降量 `p_{j-1}(x) − p_j(x)` 即对应层级的"流失率"，用于确定瓶颈所在。

**(2) 瓶颈感知的 rollout 分配**
- **Step 1**：若组内已存在完整目标 SID，则不干预，直接进入标准 GRPO。
- **Step 2**：否则根据组内平均前缀深度决定干预预算 `B(x) = min(B_max, ⌊B_max(1 − 平均深度/M)⌋)`，平均深度越低干预越多。
- **Step 3**：将预算按各层级流失比例分配到对应瓶颈深度（largest-remainder rounding 确保恰好 B(x) 条）。
- **Step 4**：在最弱（按前缀匹配深度排序）的 B(x) 条 rollout 上，固定目标前缀 `s*_{1:j}`，让当前策略 π_t 生成后缀，替换入最终组；保留最强的原始 rollout 作对比。
- 论文强调**guided prefix 只作为条件上下文，不参与 GRPO 似然比与 KL 项**（仅策略生成的后缀 token 计入）。

**(3) 难度感知奖励设计**
- 最终奖励由三部分组成：`R_DASO = R_acc + λ_rank·R_rank + R_sid`
  - `R_acc`：精确命中目标的二元奖励（一项核心目标）；
  - `R_rank`：继承自 MiniOneRec 的排名奖励（λ_rank = 0.3），仅在组内含精确命中时激活；
  - `R_sid = m(ŝ, s*)/M`：SID 前缀进度奖励（单位权重），提供部分正确时的分级信用。
- 仅优化浅层前缀不足以最大化 R_DASO，精确命中仍有独立奖励，保证推荐精度仍是主要目标。

**(4) SFT 锚定稳定化**
- 加一项辅助 SFT 损失（目标 SID 序列的负对数似然）：`L_DASO = L_GRPO + λ_sft·L_SFT`
- 目的：前缀引导的 rollout 会引入分布偏移，SFT 锚点缓解 SFT 检查点已解决示例上的能力回退。
- 超参数选择：G = 16，B_max = 9，λ_sft = 0.1，λ_rank = 0.3（继承 MiniOneRec）。

**算法 1 流程**：采样原始 rollout → 计算前缀深度画像与瓶颈 → 判断是否含精确命中 → 计算预算 → 按画像分配引导槽位 → 替换最弱 rollout → 计算 R_DASO 并归一化 → 用 L_GRPO + λ_sft·L_SFT 更新。

## 6. 主要结论与发现

1. **公开基准上**，DASO 在 12 项指标中 11 项优于 MiniOneRec 风格 GRPO，在 12 项中取得 9 项最佳成绩。HR@5 增益在 Office Products 上尤为显著（1.5B：0.1420 → 0.1639；3B：0.1313 → 0.1683）。
2. **内部工业数据集上**，DASO 显著提升 lv0 Top-20 召回（47.21% → 54.23%），说明能更有效地将生成引导入正确的粗粒度分支；最终层级 lv3 recall 也从 4.23% 提升到 4.67%，表明不局限于浅层前缀。
3. **桶级诊断显示**，最大的改善出现在初始 Medium（部分前缀）和 Hard（无前缀命中）提示词上，正是 vanilla GRPO 容易产生退化奖励信号的区间；SFT 锚点缓解了 Easy 提示词上 SFT 检查点已解决问题的回退。
4. **消融验证**中，在线画像优于静态难度桶；SID 前缀奖励在聚合指标上一致地提供增益；SFT 锚点移除后四个设置上的聚合 HR@5 均退化（降幅 0.003-0.009）；B_max=9 优于 5 和 13，暗示存在"干预不足 vs 保留对比不足"之间的平衡点。

## 7. 优点

1. **问题诊断扎实**：给出具体的量化诊断（>50% 的提示词缺失首 token 匹配），将 GRPO 在树状 SID 空间中的奖励退化问题刻画得清晰、有依据、可复现。
2. **方法设计巧妙且轻量**：仅通过前缀深度画像做动态 rollout 分配（无额外学得的 value 模型或搜索模块），保持了与 GRPO 原生的一体性。
3. **"干预要有节制"的设计原则贯穿方法**：B(x) 有上限、保留原始 rollout、只在瓶颈深度插入前缀 —— 既补充了目标路径信号，又保留了 GRPO 的组内对比性质，未把 RL 退化为纯教师强制。
4. **奖励设计兼顾稀疏与稠密信号**：SID 前缀奖励补充分级学分，精确命中奖励保持主目标，避免只学浅层前缀。
5. **SFT 锚点的稳定性治理**很有针对性——引导分布偏移时的回退风险在这种树状任务中非常现实。
6. **评估与诊断分层清晰**：聚合指标之外增加了 Easy/Medium/Hard 分桶、层级 recall、消融等多个视角，帮助读着理解改进来自哪类难例。

## 8. 不足与局限

1. **单次运行、无显著性检验**：论文明确所有结果为 single-run，缺少多 seed 均值和方差报告，对结论的统计稳健性有一定影响。
2. **内部数据集不可复现**：专有工业数据仅提供聚合统计，无法验证四层 SID 实验的外部效度；Table 3 中 lv2 Top-20 recall 不升反降（5.23% → 5.16%），说明并非所有层级一致受益，论文对此解释较轻。
3. **消融实验的显著性有限**：某些组间差异很小（尤其 NDCG），且为单次运行，难以区分是真实改进还是随机波动。
4. **Easy 桶上存在回退**：在某些配置下（如 1.5B Office、3B Industrial）Easy 桶的 HR@5 相比 SFT-only 和 MiniOneRec 有所下降（如 Table 13/14 中 Easy HR@5 从 0.7199 降至 0.5359），论文虽归因于 SFT 锚点设计尚不完美也承认 Easy-bucket 消融结果不统一。
5. **超参数选择的普适性存疑**：B_max=9、λ_sft=0.1、G=16、前缀奖励单位权重等关键超参数是否随树宽、深度、码本大小而需要调整并未充分讨论；内部实验中没有给出同样的超参数敏感性分析。
6. **计算成本未透明呈现**：未报告各方法的具体训练耗时及 DASO 相比基线的额外计算开销。
7. **与更广泛 RLHF/GRPO 变体对比有限**：未与 PPO、DPO 类方法或更多 guided-search 变体做完整对比，定位更多在 MiniOneRec 框架内的增量优化。
