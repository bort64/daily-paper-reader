## 摘要
在生成式推荐系统中，物品通常被分词为固定长度的语义ID序列，用于自回归的下一个物品预测。然而，对于用户上下文建模，这种细粒度表示会引发物品内注意力过载：过多的注意力被消耗在低层次的物品内依赖关系上，而非高层次的物品间行为转换。为解决此问题，我们提出了语义子词分词（SST），它将历史物品表示为可变长度的语义子词，同时保留固定长度的目标解码。SST首先应用物品级子词分词（IST），将稳定的相邻原子令牌合并为紧凑的语义子词令牌，从而减少编码器中的物品内重组。接着引入行为诱导的共现增强（BCA），注入粗粒度的语义前缀转换信号，引导释放的建模容量转向物品间的行为规律。在三个公开数据集和三个生成式推荐骨干上的大量实验表明，SST相比固定长度和可迁移的可变长度SID基线具有经验性改进。代码可在 https://github.com/mxrcandy/Semantic-Subword-Tokenization 获取。

## Abstract
In generative recommender systems, items are typically tokenized into fixed-length semantic ID sequences for autoregressive next-item prediction. However, for user-context modeling, this fine-grained representation triggers Intra-item Attention Overload: excessive attention is spent on low-level intra-item dependencies rather than high-level inter-item behavioral transitions.   To address this, we propose Semantic Subword Tokenization (SST), which represents historical items as variable-length semantic subwords while preserving fixed-length target decoding. SST first applies Item-level Subword Tokenization (IST) to merge stable adjacent atom tokens into compact semantic subword tokens, thereby reducing intra-item reassembly in the encoder. It then introduces Behavior-induced Co-occurrence Augmentation (BCA) to inject coarse-grained semantic prefix transition signals, guiding the freed modeling capacity toward inter-item behavioral regularities. Extensive experiments on three public datasets and three generative recommender backbones show empirical improvements of SST over fixed-length and transferable variable-length SID baselines. Code is available at https://github.com/mxrcandy/Semantic-Subword-Tokenization.

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：生成式推荐系统近年来成为推荐领域的重要范式，其核心思想是将下一个物品预测建模为自回归序列生成任务。在此类系统中，物品（Item）通常被分词为固定长度的“语义ID序列”（Semantic ID, SID），由 RQ-VAE 或 RQ-KMeans 等残差量化模型产生。
- **核心问题**：论文指出现有固定长度 SID 的设计存在一个关键缺陷——**“物品内注意力过载”（Intra-item Attention Overload）**。固定长度 SID 中的每个码本 token（称为“原子令牌”）被设计用于目标端的解码识别（解码语法）；但当同一表示被扁平化用作历史用户上下文序列时，编码器必须反复消耗大量注意力将同属一个物品的多个原子令牌重新组合（“物品内重组”），才能形成物品级语义。
- **矛盾本质**：固定长度的 SID 作为目标侧（target side）的解码语法是高效稳定的，但作为历史侧（history side）的用户行为上下文建模表示则并不高效。这种“解码导向的标识符”与“用户上下文表示”之间的角色错位，使编码器的建模容量被低层级的物品内 token 依赖消耗，而非投入到高层级的物品间行为转移建模。
- **整体含义**：论文力求解决“固定长度 SID 作为用户历史表示”时的分词瓶颈，通过重新思考生成式推荐系统中的物品分词角色，提出历史侧采用**语义子词**、目标侧保留固定长度 SID 的**非对称分词**新范式。

### 二、方法论：SST（Semantic Subword Tokenization）

SST 由两个互补组件构成，遵循“去除低阶——注入高阶”的设计思路：

**1. 物品级子词分词（Item-level Subword Tokenization, IST）**

- **动机**：从 LLM 子词分词（如 BPE、WordPiece）获得灵感，将频繁相邻共现的原子令牌序列合并为紧凑的“语义子词令牌”，从而把低层级物品内组合的规则直接编码进 token 结构，避免编码器反复“重新学习”。
- **处理流程**：
  - **候选对收集**：只对每个物品内部的相邻 token 对进行统计，跨物品边界一律不构成候选；记录每对的语料频率和物品支持度。
  - **合并规则学习**：迭代挑选分数最高的相邻候选对（需满足频率阈值 f 与物品支持度阈值 s），在全部物品 SID 中执行合并，更新统计，直到达到合并预算或没有合格候选。
  - **重编码**：将学习到的合并规则按序回放到每个物品 SID 上，生成变长的新物品表示（长度 ≤ 原始固定长度 L）。
- **三种候选评分准则**：
  - BPE：仅依据相邻 token 对频率；
  - WordPiece：频率 × 正 PMI，抑制高频泛化对，优先语义耦合强的对；
  - **CondEntropy（论文提出）**：结合频率、双向转移概率与局部上下文纯度（条件熵），要求候选对“频、互预测、局部低熵”，生成更可靠的语义子词。
- **收益**：编码器不再需要反复进行原子级物品重组，历史上下文更短、更紧凑，建模容量被释放用于物品间转移与高阶用户意图建模。

**2. 行为诱导的共现增强（Behavior-induced Co-occurrence Augmentation, BCA）**

- **动机**：IST 做的是“认知卸载”（压缩低阶信息），但没有告诉模型应当关注哪些物品间行为规律，因此需要注入粗粒度行为共现信号。
- **流程**：
  - 对每个物品 SID 提取前 P 个 token 作为“语义前缀”（代表物品粗粒度类别）；
  - 在用户的历史前缀序列上用滑动窗口 W 统计前缀对（p_left, p_right）的共现；按 count / PMI / lift 选择 top-k 前缀对；
  - 回溯这些前缀对在原始序列中的上下文（两前缀之间的历史子序列），将其注入训练集作为额外回放样本：“输入前序历史、预测右前缀对应的物品”。
- **收益**：向训练中提供显式的物品间行为转移信号，让模型更好地利用 IST 释放的注意力。

**3. 非对称分词设计（Asymmetric Tokenization）**

- IST 与 BCA 只修改编码器（历史）侧的 token 表示；解码器（目标）侧始终保留固定长度 SID。
- 理由：目标侧若转成变长子词表示，会破坏稳定的 L-slot 解码语法，并使子词 token 成为低频、长尾的预测目标，导致生成不稳定。

### 六、主要结论与发现

1. 固定长度 SID 在历史侧会大量消耗编码器的注意力在同物品原子令牌重组上，损害物品间行为建模能力。
2. SST 的两个组件交互增益明显：
   - IST 通过语义子词压缩减少了低阶物品内重组负担；
   - BCA 引导释放的建模容量集中于高阶物品间转移信号；
   - 二者构成“去低阶-注高阶”的闭环。
3. SST 在三个骨干（TIGER-KM、TIGER-VAE、LETTER）与三个数据集上均一致优于固定长度与可迁移的变长 SID 基线（比如相对 NDCG@5 提升 3.8%–13.8%）。
4. 非对称分词是必要设计：若把目标侧也改成变长子词，解码崩溃（合并桶样本 HR@10 近 0.0002），而仅改历史侧则有可靠增益。
5. SST 效率可观：由于历史序列缩短，抵消了 BCA 样本增加的训练成本，没有系统性墙钟时间增加。
6. 附件实验还发现：语义子词的收益随历史覆盖率增加而增加；流行度分析表明 SST 不加剧（甚至改善）长尾推荐表现。

### 七、优点

1. **问题洞察独到**：厘清了“目标解码标识符”与“用户上下文表示”两种角色在 SID 中的冲突，提出“物品内注意力过载”这一清晰概念，并用注意力度量进行实证支撑，有理论启发意义。
2. **方法简约且框架兼容**：SST 在任意 SID tokenizer 之上即可使用（对 RQ-VAE / RQ-KMeans 等设计无关），可作为通用插件，不改变目标侧解码范式。
3. **借鉴成熟跨域思想**：将 NLP 的子词分词迁移到推荐物品表示中，并改良适配了 CondEntropy 准则，迁移自然且有新意。
4. **实验严谨且多层次**：不仅有主实验，还有机制验证、超参分析、效率测量、覆盖率效应、非对称设计剖析和流行度分析，验证体系完整。
5. **开源公开**：代码在 GitHub 可获取，有助于复现和后续研究。

### 八、不足与局限

1. **算力与训练资源披露不足**：未给出 GPU 型号/数量/显存等核心算力信息，工业可复现性信息不够完整。
2. **数据规模有限**：实验在 3 个中小规模公开数据集上进行；没有超大规模工业数据集的验证；虽然提到了 OneRec 等工业方向，但并未在真正的工业场景检验语义子词在超大规模候选下的效果。
3. **文本特征依赖**：物品 tokenizer 依赖 Sentence-T5 提取文本语义特征，对无文本描述或弱文本物品（图片为主、冷启动场景）时适用性有限。
4. **IST 超参数与准则选择较繁**：合并预算 k、频率 f、支持度 s、分词准则（BPE/WordPiece/CondEntropy）都需要根据验证集选择；选择成本不低且准则在不同数据集间并不统一（如 Beauty 倾向 WordPiece，Yelp 倾向 CondEntropy），应用时需反复调参。
5. **未深入讨论动态/增量更新**：合并规则为基于静态语料库的离线学习；在线推荐场景中当物品池或语义分布漂移时需要重训 merge 规则，对高频新物品加入的增量适配策略没有说明。
6. **BCA 的简单性会带来一定偏差**：前缀对共现信号仅提供粗粒度行为信息，对复杂、多跳的行为转移不一定能捕捉；回放抽样方式也仍有较多设计空间，论文未做详尽消融（如不同回放策略的选择）。
7. **潜在偏差未完全排除**：虽然 BCA 未加剧头部偏差，但“流行物品天然更容易产生高频子词”仍可能造成子词分布偏斜，可能在更多样数据上造成长尾物品的子词覆盖不足。
