## 摘要
跨域推荐（CDR）在相关域之间传递偏好知识，但联邦部署使得跨域对齐变得困难，因为用于对齐物品空间的行为锚点，如重叠用户和共享交互信号，在客户端之间往往是稀疏的、不可用的或隐私敏感的。为了解决这一矛盾，我们将联邦CDR重新视为在稳定的语义物品语言上的生成过程。通过将物品表示为从公共物品侧元数据派生的离散语义ID（SID）序列，跨域物品对齐由共享词汇表诱导，而不是通过交换私有交互或对齐特定领域的嵌入。然而，直接联邦基于SID的生成器引入了两个设计约束：SID分词器必须保持固定以维护跨客户端令牌一致性，这造成了仅语义瓶颈，因为本地协同过滤（CF）信号无法全局共享或对齐；同时，标准联邦平均在领域异质性下可能导致负迁移。为了克服这些约束，我们提出了FedCGR，一种联邦生成式CDR框架，它保持物品语言稳定并使适应显式化。FedCGR通过可靠性感知的语义接口注入本地CF证据，并训练一个原型个性化的生成器，该生成器根据领域相关性选择性聚合共享参数，同时将领域特定的数量保持本地。在六个亚马逊跨域场景上的实验表明，FedCGR始终优于联邦生成式基线，并且在全排序和采样评估协议下，与强序列和联邦CDR方法相比取得了有竞争力的性能。

## Abstract
Cross-domain recommendation (CDR) transfers preference knowledge across related domains, but federated deployment makes cross-domain alignment difficult because the behavioral anchors that align item spaces, such as overlapping users and shared interaction signals, are often sparse, unavailable, or privacy-sensitive across clients. To address this tension, we revisit federated CDR as generation over a stable semantic item language. By representing items as discrete semantic ID (SID) sequences derived from public item-side metadata, cross-domain item alignment is induced by a shared vocabulary rather than by exchanging private interactions or aligning domain-specific embeddings. Directly federating SID-based generators, however, introduces two design constraints: the SID tokenizer must remain fixed to preserve cross-client token consistency, which creates a semantic-only bottleneck because local collaborative filtering (CF) signals cannot be globally shared or aligned; meanwhile, standard federated averaging can cause negative transfer under domain heterogeneity. To overcome these constraints, we propose FedCGR, a federated generative CDR framework that keeps the item language stable and makes adaptation explicit. FedCGR injects local CF evidence through a reliability-aware semantic interface and trains a prototype-personalized generator that selectively aggregates shared parameters according to domain relatedness while keeping domain-specific quantities local. Experiments on six Amazon cross-domain scenarios show that FedCGR consistently outperforms federated generative baselines and achieves competitive performance against strong sequential and federated CDR methods under both full-ranking and sampled evaluation protocols.

## 1. 核心问题与研究动机

- 跨域推荐（CDR）希望通过迁移多个相关领域的偏好知识来缓解数据稀疏与冷启动问题；但将其部署到联邦学习环境时，面临一个根本性矛盾：传统 CDR 用于对齐不同域物品空间的关键行为锚点——如重叠用户、共现图、共享交互信号——恰恰在联邦隔离下变得稀疏、缺失或受到隐私保护限制。
- 现有联邦 CDR 方法（如 FedSASRec、FedCL4SRec、FedDCSR 等）大多仍属于判别式模型：它们在连续、往往域专属的表示空间中对候选物品打分，跨域迁移因此依赖于让私有空间“可比较”，这使隐私保护与跨域对齐效果相互耦合。
- 作者的核心思路是：将联邦 CDR 重新定义为“在稳定语义物品语言上的生成问题”。利用公开的物品侧元数据（标题、品类、描述等）训练 RQ-VAE 分词器，把每个物品表示成离散的语义 ID（SID）序列。这样，跨域物品对齐不再依赖私有行为数据，而是由共享的离散词汇表天然实现。
- 但“直接联邦化 SID 生成器”会产生两个新约束：
  1. **仅语义瓶颈**：分词器必须冻结以保持跨客户端 token 一致性，但本地协同过滤（CF）信号无法通过 tokenizer 或全局联邦过程获得，且各客户端独立训练的 CF 嵌入坐标系不一致、不能直接融合。
  2. **负迁移风险**：标准 FedAvg 假设各域数据同分布，而 SID 预测是逐 token 自回归分解，早层 token 分布扰动会沿前缀树级联，在域异质性下易发生负迁移。

## 2. 方法论：FedCGR

FedCGR 的组织原则是“**保持物品语言稳定，使域适应显式化**”，整体由两个核心机制构成，而非若干独立模块的简单拼装。

**（1）统一的语义 ID 构造（共享物品语言）**
- 用 BGE-base-en-v1.5 文本编码器将公共物品元数据映射为向量，再用 RQ-VAE（残差量化）层次式离散化为长度 L=3、码本大小 C=256 的 SID 序列。
- 训练目标包含重建、commitment、熵正则与碰撞正则。训练完成后分词器冻结，保证同一 token 在所有域都指向同一语义区域。
- 后续的 SID token embedding 表、Transformer 参数、预测头与专家参数仍可训练并参与联邦聚合。

**（2）可靠性感知的语义接口（注入本地 CF 证据）**
- 每个客户端先用本地私有交互序列独立训练一个轻量 SASRec（也可扩展为 BERT4Rec），提取固定的本地 CF embedding 表。
- 引入物品级可靠性分数：`ρ(v,i)=log(1+n_v,i)/[ε+max log(1+n_v',i)]`，高频交互物品得分高、长尾物品得分低。
- 本地 CF 适配器 `A_i(·)` 把不具坐标可比性的 CF embedding 映射到 SID 生成器隐空间；该适配器只留在本地、不参与聚合。
- 输入表示采用“残差融合”：
  `h_t = Σ_l E_sid(c_l) + E_pos(t) + ρ(v_t,i) · g_i · A_i(e_cf(v_t,i))`
  其中 `g_i=σ(α_i)` 是域级门控。这样模型既能利用可靠的本地 CF 证据，又能通过 ρ 抑制长尾噪声、通过 g_i 校准该域 CF 总体贡献。
