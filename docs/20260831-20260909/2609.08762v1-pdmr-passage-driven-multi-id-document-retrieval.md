## 摘要
生成式检索（GR）模型将查询直接映射到文档标识符，用自回归标识符生成取代对外部稀疏或密集索引的传统检索。然而，大多数生成式检索框架依赖于单一标识假设，即将每个文档映射到一个目标序列。这迫使模型用一个序列表示所有文档内容。由于文档通常是多方面的，这可能导致有损表示并降低对查询变化的鲁棒性，其中多个查询意图必须竞争一个生成访问路径。在这项工作中，我们引入了基于段落驱动的多标识检索（PDMR），这是一种通过多个段落级标识符来表示文档的生成式检索框架。PDMR对每个文档进行分段，并为每个选定的段落分配一个标识符，从而为检索同一文档提供多个语义入口点。这种多入口表示允许模型将查询与特定的语义方面对齐，从而减少对单个文档级目标的依赖。为了解决这种一对多映射的监督模糊性，我们将训练形式化为一个多目标学习问题，并探索一种旨在将概率质量分配到多个有效段落级标识符上的目标函数。我们在NQ320K和MS MARCO Document上评估了PDMR。在NQ320K上，PDMR在Recall@1和MRR@100上优于强生成式和非生成式基线。在MS MARCO Document上，PDMR在所报告的方法中取得了最佳的Recall@1和MRR@10，同时在Recall@10上保持竞争力。受控消融进一步表明，段落级监督、标识符设计、训练查询增强和多目标学习带来了互补的增益。

## Abstract
Generative Retrieval (GR) models map queries directly to document identifiers, replacing conventional retrieval over external sparse or dense indexes with autoregressive identifier generation. However, most generative retrieval frameworks rely on a single-identifier assumption, mapping each document to a single target sequence. This forces the model to represent all document content with one sequence. Since documents are often multi-faceted, this can lead to lossy representations and reduced robustness to query variation, where multiple query intents must compete for a single generative access path.   In this work, we introduce Passage-Driven Multi-ID Retrieval (PDMR), a generative retrieval framework that represents documents through multiple passage-level identifiers. PDMR segments each document and assigns one identifier to each selected passage, which provides multiple semantic entry points for retrieving the same document. This multi-entry representation allows the model to align queries with specific semantic facets, thereby reducing the dependence on a single document-level target. To address the supervision ambiguity of this one-to-many mapping, we formulate training as a multi-target learning problem and explore an objective function designed to distribute probability mass across multiple valid passage-level identifiers.   We evaluate PDMR on NQ320K and MS MARCO Document. On NQ320K, PDMR improves over strong generative and non-generative baselines on Recall@1 and MRR@100. On MS MARCO Document, PDMR achieves the best Recall@1 and MRR@10 among the reported methods, while remaining competitive on Recall@10. Controlled ablations further show that passage-level supervision, identifier design, training-query augmentation, and multi-target learning contribute complementary gains.

# PDMR：基于段落驱动的多标识文档检索

## 1. 核心问题与研究动机

生成式检索将查询直接自回归地生成文档标识符，但现有方法大多遵循“单文档单标识符”假设：

- 一份文档被压缩为一个目标序列，因此难以完整表达多面、长篇幅文档的丰富语义。
- 查询意图多样时，若文档相关片段未反映在全局标识符中，检索容易失败，鲁棒性不足。
- 已有“多视角”类工作（如 MINDER）本质上是对**同一个检索单元**做多种描述，而不是为文档内部不同语义单元设置独立入口。
- PDMR 想解决的问题是：如何让文档级生成式检索拥有多个**粒度更细、语义更局部**的入口，同时仍以文档为单位返回结果。

## 2. 方法论

### 2.1 核心思想

将文档拆分为若干有意义的段落，为每个段落赋予一个标识符，文档因此拥有多个 passage-level identifier。

- 模型可在训练和推理时通过这些段落级标识符访问文档；
- 检索评估仍然在文档级别进行；
- 将监督建模为“多目标学习”，以缓解一对多映射带来的目标歧义。

### 2.2 总体流程

PDMR 包含四个组件：

1. **段落抽取**
   - 第一步：用 LLM（Qwen3-8B）将文档切分为“标题 + 正文”形式的短段落，追求召回；
   - 第二步：让 LLM 去重并筛选信息量高、区分性强的段落，追求精炼。

2. **段落级标识符构造**
   探索三类标识符：
   - RNID：随机数字标识符，纯符号目标；
   - PT-ID：直接用段落标题作为标识符；
   - TC-ID：将文档标题与段落标题组合，形成两种顺序：
     - Doc→Pass：`文档标题/段落标题`；
     - Pass→Doc：`段落标题/文档标题`。

3. **查询-段落对齐**
   - 训练查询来源一：DocT5Query 合成查询，从具体段落生成，并用交叉编码器过滤；
   - 训练查询来源二：原始训练查询，通过两种策略映射到段落：
     - All-passage 分配：相关文档的全部段落都作为目标；
     - Best-passage 分配：用 BM25 选择最匹配的单个段落作为目标。

4. **多目标训练**
   - 标准单目标负对数似然：`ℓ_i = -log pθ(y^(i)|q)`
   - 多目标加权平均损失：`L_avg = Σ w_i ℓ_i`
   - 主段落权重较高（实验中设为 0.6），其余段落平分剩余权重。
   - 该目标既保留“主段落优先”，又让同一文档的其他有效段落仍可被学习。

### 2.3 推理

- 使用一次带约束的 beam search，在统一的段落标识符词表上解码；
- 对同一文档的多个段落标识符，采用最大概率作为文档得分：`Score(d,q) = max_{y∈Z_d} pθ(y|q)`。

## 3. 实验设计

### 3.1 数据集

- **NQ320K**
  - 约 109,739 篇 Wikipedia 文档，7,830 条开发查询；
  - 段落级语料包含 428,412 个段落，每篇文档平均约 3.90 段；
  - 额外报告 seen/unseen 查询划分。

- **MS MARCO Document（MSM Doc）**
  - 323,569 篇网络文档，5,187 条开发查询；
  - 段落级语料包含 1,142,073 个段落，每篇文档平均约 3.53 段。

### 3.2 评价指标与基线

- **NQ320K**：R@1、R@10、MRR@100；
- **MSM Doc**：R@1、R@10、MRR@10。

对比基线覆盖三类方法：

- 稀疏检索：BM25、DocT5Query；
- 稠密检索：DPR、ANCE、SentenceT5；
- 生成式检索：DSI、DSI-QG、NCI、GENRE、SEAL、TOME、Ultron、MINDER 等。

### 3.3 主要实验结果

- **NQ320K**：PDMR 达到 R@1=67.6、R@10=85.8、MRR@100=74.4；
  - 优于 DSI-QG、NCI 等单标识符方法；
  - 相比 MINDER，R@1 与 MRR@100 更高，R@10 略低；
  - unseen 查询上显著优于多类生成式基线。

- **MS MARCO Doc**：PDMR 达到 R@1=37.71、R@10=71.49、MRR@10=48.66；
  - 取得报告方法中最优的 R@1 与 MRR@10；
  - R@10 与最优方法接近但略低。

### 3.4 消融实验

论文围绕四个研究问题做了受控消融：

- **RQ1**：段落级监督 vs 文档级监督。段落级在 NQ 与 MSM 上均显著提升；
- **RQ2**：标识符设计。文本标识符优于随机标识符；Doc→Pass 组合最优；
- **RQ3**：训练查询增强。NQ 上 All-passage 更好；MSM 上 Best-passage 更好；
- **RQ4**：多目标训练。无论随机 ID 还是文本 ID 均带来增益，且与训练查询增强互补。

此外还有数据集层面的“弱对齐段落比例”分析，用来解释不同数据集的分配策略差异。

## 6. 主要结论与发现

- 文档级生成式检索更适合用多个段落级标识符表示，而非单一文档级标识符；
- 段落级监督能稳定带来 Recall 与 MRR 提升；
- 标识符中引入文档上下文并采用 Doc→Pass 顺序，有助于约束解码和查询-标识符对齐；
- 训练查询增强是有效手段，但最优对齐策略取决于文档结构：
  - NQ 类相对均匀的百科文档适合 All-passage；
  - MSM 类长网页文档适合 Best-passage；
- 多目标训练能够将概率质量分配到同一文档的多个有效入口，与前述机制互补；
- 这说明“从单入口到段落化多入口”是生成式检索值得继续探索的方向。

## 7. 优点

- **问题定位清晰**：区分了“多视角标识”与“多语义单元标识”，指出前者不解决文档内部细粒度对齐问题；
- **方法设计合理**：段落抽取、标识符构造、查询对齐、多目标训练四部分形成完整且自洽的体系；
- **标识符设计有比较**：随机 ID、标题 ID、标题组合 ID，以及不同顺序的对比具有可解释性；
- **监督歧义处理有针对性**：多目标加权损失既尊重主段落，又保留其他段落作为有效目标；
- **消融实验设计严谨**：每个 RQ 均被单独验证，结论链条清晰；
- **推理简单高效**：不同于 MINDER 的多类型多路解码，PDMR 只需一次约束解码。

## 8. 不足与局限

- **性能上限**：在 NQ320K 上未超越部分采用学习型标识符、更大骨干模型或集合解码的先进方法；
- **依赖 LLM 抽取**：段落抽取与筛选依赖 LLM，离线和训练成本较高；

- **评估局限**：仅以文档级指标评估，没有直接展示 passage 级召回或命中质量；
