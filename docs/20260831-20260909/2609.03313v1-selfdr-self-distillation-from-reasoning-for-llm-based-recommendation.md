## 摘要
大语言模型（LLMs）近年来已成为推荐系统的强大骨干。为了更好地激发其能力，推理被广泛引入以帮助LLMs解释丰富的文本信号并提高推荐准确性。然而，显式生成中间推理轨迹通常会带来大量计算成本，这限制了在实际推荐系统中的部署。为解决这一挑战，我们提出了SelfDR——一个用于基于大语言模型推荐的推理自蒸馏框架。SelfDR将LLM自身的推理增强预测蒸馏为直接推荐，在提高推荐效果的同时保持推理效率。该框架中的所有组件均基于同一个基础LLM构建，不依赖任何外部模型。具体而言，教师推荐器通过训练一个以下游性能为奖励的推理器构建，使其能够生成有针对性的推理依据，这些推理依据随后被整合到教师模型的输入中。一个用于直接推荐的、具有相同底层模型的学生推荐器，随后通过动态加权策略的自我蒸馏向教师学习。在三个公开数据集上的大量实验验证了SelfDR的有效性、合理性和效率。代码可在 https://github.com/JiangDeccc/SelfDistillation 获取。

## Abstract
Large Language Models (LLMs) have recently emerged as powerful backbones for recommendation. To better elicit their capabilities, reasoning has been widely incorporated to help LLMs interpret rich textual signals and improve recommendation accuracy. However, explicitly generating intermediate reasoning traces often incurs substantial computational costs, which limits practical deployment in real-world recommender systems. To address this challenge, we propose SelfDR, a Self-Distillation from Reasoning framework for LLM-based Recommendation. SelfDR distills an LLM's own reasoning-enhanced predictions to produce recommendations directly, improving recommendation effectiveness while maintaining inference efficiency. All components in the framework are built on the same base LLM, without relying on any external models. Specifically, the teacher recommender is constructed by training a reasoner with downstream performance as the reward, enabling it to generate targeted rationales that are later incorporated into the teacher's input. A student recommender for direct recommendation, with the same underlying model, then learns from the teacher through self-distillation with a dynamic weighting strategy. Extensive experiments on three public datasets validate the effectiveness, rationality, and efficiency of SelfDR. Codes are available at https://github.com/JiangDeccc/SelfDistillation.

## 论文总结

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：大语言模型（LLM）近年来成为推荐系统的强大基础模型。为更好激发其能力，推理（Reasoning）被广泛引入，帮助 LLM 理解丰富的文本信号（如物品元数据、用户评论等）并提升推荐准确性。
- **核心矛盾**：现有基于推理的推荐范式（如多步推理、推理与推荐一体化生成）虽然效果优异，但显式生成中间推理轨迹会造成：
  - **高昂的推理延迟**，难以满足真实推荐系统对响应速度的要求；
  - **计算资源消耗巨大**，限制实际部署。
- **核心研究问题**：如何在**不牺牲推理效率**的前提下，利用 LLM 的推理能力提升推荐效果？

### 2. 方法论：核心思想与关键技术细节

#### 2.1 核心思想

论文提出 **SelfDR**，一种"从推理中进行自蒸馏"的框架，核心理念为：构建一个带有推理能力的"教师"模型（教师通过融入推理过程获得更强的推荐能力），然后让同架构的"学生"模型（执行直接推荐）通过蒸馏学习教师的预测分布，从而将"推理带来的好处"迁移至高效的直接推荐中。整个过程不依赖任何外部大模型，而是利用同一基础 LLM 的"自我提升"。

#### 2.2 整体框架与关键流程

整个流程分为两个阶段，由三个组件构成（Reasoner、Teacher Recommender、Student Recommender），共享同一基础 LLM：

1. **第一阶段：教师推理能力的学习**
   - **Reasoner 训练**：在训练集前半部分，使用 **GRPO（Group Relative Policy Optimization）** 强化学习训练 Reasoner。
   - **奖励信号设计**：用户历史与**真实交互物品**作为输入，提示 Reasoner 生成理由\( r_{u,i} \)，随后将理由与候选集辅助输入给一个冻结的推荐 LLM 做预测，以**下游推荐性能**（如预测正确与否）作为 Reward。该方法避免了推理质量与推荐目标不一致的潜在错配。
   - **防数据泄漏设计**：明确提示 Reasoner 不得复述输入元数据，并对连续与物品标题重叠≥3个词的内容进行掩码。
   - **构建教师**：教师推荐器（Teacher Recommender）将 Reasoner 生成的证据与用户历史/候选池共同作为输入，形成"深思熟虑"式的教师。

2. **第二阶段：学生的自我蒸馏**
   - **学生初始化**：在蒸馏前，基于同一架构、指令微调的学生模型与教师模型共享完全相同参数。
   - **蒸馏学习**：教师输入包含推理信息；学生输入**不包含推理信息**。学生通过损失函数对齐教师对学生候选符元分布。
   - **优化目标（公式 7）**：
     \[
     \min_{\Theta_s} (1-\alpha)\mathcal{L}_{ce}(\Theta_s) + \alpha \mathcal{D}_{kd}(\Theta_t, \Theta_s)
     \]
     - \(\mathcal{L}_{ce}\): 交叉熵损失；
     - \(\mathcal{D}_{kd}\): 蒸馏损失（采用**逆向 KL 散度**，鼓励学生分布集中于教师的高概率区域）。
   - **动态加权机制（公式 9）**：引入自适应权重函数：
     \[
     \alpha(rank_i^t, rank_i^s) = \alpha_{base} f(rank_i^t - k) \sigma\left(\frac{rank_i^s - rank_i^t}{\tau}\right) \beta^{\mathbb{1}(rank_i^t > rank_i^s)}
     \]
     - 若教师排序优于学生，\(\beta\) 惩罚项（\(\beta^{\mathbb{1}(.)}\)）不激活；
     - 若教师排序差于学生，通过 \(\sigma\) 函数和 \(f(x)\) 的调节，大幅降低蒸馏权重，避免噪声；
     - \(k\) 为教师排名阈值（实验中，候选集大小为 20，因此 \(k=5\)）。

#### 2.3 公式与算法流程总结

1. **直接推荐任务**：\( s_{u,i}, R_{u,i} = LLM(H_u, C_{u,i})\)，预测用户下一交互物品；
2. **深思熟虑式推荐**：\( r_{u,i} = LLM_{Reasoner}(H_u, M_i) \)，\(\; s_{u,i}, R_{u,i} = LLM(H_u, C_{u,i}, r_{u,i})\) 为教师输入；
3. **强化学习训练**：用 GRPO + 下游 Acc 作为 Reward 优化 Reasoner；
4. **指令微调 + 自蒸馏**：教师固定，学生采用动态权重（公式 9）训练，最终只保留学生模型直接推理。

### 6. 主要结论与发现

1. **SelfDR 效果显著**：在所有三个数据集上，SelfDR 在所有指标（HitRate@1/3/5、NDCG@3/5)上均显著优于传统和 LLM 基础方法；
2. **Reasoner 更优**：仅利用小型骨干本地训练的 Reasoner，优于 GPT-4o-mini、Claude-3-Haiku 等大型外部大模型；且**更强/更大的通用 LLM 并不一定产出更好的下游推荐**；
3. **自蒸馏是核心**：若仅用监督训练（Sup-Only），易过拟合；仅用蒸馏（Dist-Only）缺乏对正确标签的锚定；动态加权能有效平衡两类信号，避免过度信任教师错误信号；
4. **输出置信度上升**：自蒸馏后模型当正确项排名靠前时，对其 Token 置信度显著增加；
5. **效率兼顾**：SelfDR 推理速度与最快速率方法持平，总训练成本优于若干推理增强基线，且不依赖昂贵外部 LLM。

### 7. 优点

- **方法设计巧妙**：统一模型架构（教师、学生、Reasoner 同骨干），不依赖任何外部模型，完全实现"自我进化"；
- **奖励对齐**：训练理由生成器时用"下游推荐精度"而非规则化的推理质量指标，确保模型生成内容与最终任务目标一致；
- **教师差异化信号**：采用 logits 级别的软标签蒸馏（逆向 KL 散度），避免退化为银标签监督；动态权重机制（用教师/学生相对排序、教师绝对排序和惩罚项共同调节）避免"噪声传递"并大幅提升鲁棒性；
- **实验充分且考量全面**：涵盖多个 LLM 推理范式（multi-step 和 reason-and-recom）、不同候选生成器下的泛化、以及跨域评估；
- **推理效率高**：输入输出极简（仅一个字符 ID），最大化效率。

### 8. 不足与局限

- **模型规模的限制**：实验仅针对 LLaMA-3.1-8B 一个骨干，未对多个不同架构（如 Qwen、Mistral）或不同参数规模（如 3B、70B 等）进行验证，框架适配性未能全面展示；
- **数据领域的限制**：实验仅涵盖三个数据集（亚马逊两个领域与电影数据），尚无游戏、新闻、短视频等交互模式差异较大的场景验证；
- **API 调用与能耗不可忽略**：虽然方法自监督，但训练阶段仍需 Reasoner 在大量采样与训练集分发上进行生成；但文中未报告 Reasoner 强化学习（GRPO）阶段的 Token 总数与总能耗，也未考量评估阶段数据传递成本；
- **基础排序器训练成本未列出**：对比基准实现（如 LightGCN、ComiRec）的经济成本没有在效率表格中体现，若算上候选生成器，整体训练成本会更高；
- **跨域迁移实验仍属于同质化数据迁移**，两个 Amazon 类别在文本主题存在较强相似性，真正的完全异源迁移（如从购物迁移至电影）未纳入评测。
