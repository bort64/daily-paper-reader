## 摘要
扩展Transformer已在语言建模中带来巨大提升，但将其移植到生产环境排序中的行为序列建模面临挑战：推荐在信号质量上有所不同，行为序列嘈杂、时间上不规则且监督稀疏；同时存在计算不对称性，每个请求需要在严格的延迟预算内，针对共享的用户历史对众多候选进行打分。我们提出ReST，一个推荐原生的Transformer扩展框架。针对信号质量，它引入了带有双门控注意力、旋转位置与时间嵌入、稳定残差归一化以及仅训练时辅助目标的序列编码器。针对计算不对称性，它将排序分解为一个重型可复用编码器和一个轻量级交叉解码器，后者采用无投影KV注意力与令牌特定参数化，将用户级共享前缀训练与共享前缀推理相结合，实现一次计算、多次解码的排序。在工业与公开基准上，ReST实现了更高的准确率，并在序列长度、深度和宽度上扩展更为一致，而LLM风格Transformer块在此类扩展下会饱和。在某个生产广告平台上进行的一周在线A/B测试中，在线AUC提升了1.31%，在50毫秒P99预算内核心收入指标提升了11.93%；ReST此后已全面部署到生产中，表明行为序列扩展仍是生产排序中一个充满潜力且尚未充分利用的维度。

## Abstract
Scaling Transformers has driven large gains in language modeling, but transplanting this to behavior-sequence modeling in production ranking is challenging: recommendation differs in signal quality, where behavior sequences are noisy, temporally irregular, and sparsely supervised, and in computation asymmetry, where each request scores many candidates against one shared user history under tight latency budgets. We propose ReST, a recommendation-native Transformer scaling framework. For signal quality, it introduces a sequence encoder with dual-gated attention, rotary positional and temporal embedding, stabilized residual normalization, and training-only auxiliary objectives. For computation asymmetry, it factorizes ranking into a heavy reusable encoder and a lightweight cross decoder with projection-free KV attention and token-specific parameterization, coupling user-level shared-prefix training with shared-prefix serving for compute-once, decode-many-times ranking. Across industrial and public benchmarks, ReST achieves higher accuracy and scales more consistently along sequence length, depth, and width, where LLM-style Transformer blocks saturate. A one-week online A/B test on a production advertising platform improves online AUC by 1.31% and lifts a core revenue metric by 11.93% within a 50 ms P99 budget; ReST has since been fully deployed in production, showing that behavior-sequence scaling remains a promising, under-exploited axis for production ranking.

# 论文总结

## 1. 核心问题与研究动机

- **背景**：Transformer 在语言建模中通过扩展模型规模、数据量和算力取得了显著收益，推荐排序领域希望将这一“缩放红利”迁移到用户行为序列建模中，从而捕捉超越静态特征的动态用户意图。
- **问题核心**：直接将 LLM 式 Transformer 移植到工业推荐排序面临两大根本性挑战：
  1. **信号质量差异**：行为序列是隐式反馈，存在噪声大、时序不规则（行为间隔从秒到天不等）、监督稀疏（仅有点击/转化等延迟的判别标签）等问题；此外混合排序系统中，非序列 DLRM 分支可能“短路”主损失，造成**序列饥饿**（sequence starvation），使序列模块梯度信号弱、难以有效扩展。
  2. **计算不对称**：排序场景中一次请求对应“一个用户历史 + N 个候选”，序列侧计算可跨候选复用，而候选侧交互需要按每个候选重复计算，成为延迟瓶颈；LLM 式 decoder-only 结构将两者耦合，难以满足生产级延迟预算下分别扩展的需求。
- **意义**：论文试图证明，通过“推荐原生”（rec-native）设计，行为序列缩放仍是工业排序中值得挖掘、且尚未充分利用的性能增长维度。

## 2. 方法论

论文提出 **ReST**（Recommendation-native Scalable Transformer），核心思想是**非对称编码器-解码器架构 + 系统协同设计**：将排序过程分解为“重型可复用行为序列编码器 T”和“轻量级交叉解码器 C”，实现“一次计算、多次解码”（compute-once, decode-many-times）。

### 2.1 推荐原生序列编码器 T

针对行为数据噪声、时序不规则与深度扩展不稳定，设计了三个关键模块：

- **双门控注意力（Dual-Gated Attention, DGA）**
  - 在注意力前加**值门控**（value gate）过滤不可靠行为特征；在注意力聚合后加**输出门控**（output gate）调制上下文更新。
  - 核心公式示意：
    - `H = Attention(XW_Q, XW_K, σ(XW_gv) ⊙ (XW_V))`
    - `DualGatedAttn(X) = (H ⊙ σ(XW_go)) W_o`
  - 相比 HSTU 的 SiLU 无界输出门，本项目观察到大规模下输出可能发散，因此使用更稳定的 **sigmoid 有界门控**。

- **旋转位置 + 旋转时间嵌入（RoPE + RoTE）**
  - 保留 RoPE 的旋转编码形式，处理相对序列位置；
  - 新增 **RoTE（Rotary Temporal Embedding）**：将物理时间戳按头特定粒度 `τ_h` 离散成桶索引，并旋转 query/key，使注意力分数依赖**相对时间间隔**而非绝对时间。
  - 注意力头分为两组：`H_pos` 使用 RoPE 编码序数位置，`H_time` 使用 RoTE 编码多粒度时间间隔（如秒/分钟/小时/天/周等），兼容 FlashAttention 等高效注意力核。

- **稳定残差归一化（Stabilized Residual Normalization, SRN）**
  - 采用 Mix-LN 风格：前约 25% 层用 Post-LN（整体归一化路径），后 75% 层用 Pre-LN（残差分支归一化）；
  - 残差分支加入可学习缩放系数 `α_l`（初始化为 0.01），使深层编码器从近似恒等映射开始逐步引入更新，缓解稀疏监督下的优化不稳定与深度扩展饱和。
  - 公式示意：
    - 前 25% 层：`x_{l+1} = LN(x_l + α_l · SubLayer(x_l))`
    - 其余层：`x_{l+1} = x_l + α_l · SubLayer(LN(x_l))`

### 2.2 轻量级交叉解码器 C

为在“每候选重复计算”的场景中保持低延迟：

- **无投影 KV（Projection-Free KV）**：直接复用编码器输出 H = T(S_u) 作为键和值，去掉候选侧 W_K、W_V 和值门控 W_gv 的重复计算。
- **令牌特定参数化（Token-Specific Parameterization, TSP）**：query token 包括 `[CLS]、context、user、ad` 等类型，每种 token 使用自己独立的 W_Q、输出门控和 FFN 参数，增加容量而不显著提高激活 FLOPs。

### 2.3 训练专用辅助目标

缓解“序列饥饿”：

- **辅助序列 CVR 监督（L_seq）**：直接在序列侧输出上附加 BCE 损失，输入只用序列相关特征与候选特征，不能用非序列 DLRM 特征，使序列编码器获得更强的梯度信号（实验显示平均梯度范数提升 3 倍以上）。
- **序列/非序列对齐损失（L_align）**：将行为序列表示与非序列用户表示视为同一用户的两种模态，使用 **sigmoid 对比学习**（对 batch size 不敏感）拉近同用户表示。
- 总损失：`L_total = L_ce + λ_seq·L_seq + λ_align·L_align`（辅助目标仅训练时使用，推理阶段移除）。

### 2.4 系统协同设计

- **用户级共享前缀训练（ULT）**：同一用户多条样本共享行为前缀，合并为一条序列做一次编码，用前缀有效因果掩码保持训练语义，端到端训练吞吐提升 5.8×。
- **共享前缀推理（Shared-Prefix Serving）**：一次请求只运行一次 T，得到记忆 H 后，所有候选的 query token 批量通过 C 解码；将每请求开销从 `N·FLOPs(T) + N·FLOPs(C)` 降为 `FLOPs(T) + N·FLOPs(C)`，推理成本最高减少约 20×。

## 6. 主要结论与发现

1. **ReST 优于既有方法**：在相同/相近 FLOPs 下，ReST 在工业数据集与三个公共数据集上均取得最高 AUC（或最低 log loss）。
2. **ReST 扩展性更好**：随着序列长度（最高 16k token）、深度（层数）和宽度（d=128→512）扩展，ReST 持续获得增益；而 LLaMA 与 HSTU 在深度约 8~16 层、宽度约 256 后趋于饱和。
3. **LLM 式缩放配方不能直接迁移到判别式排序**：HSTU 在判别式 CVR 场景弱于 LLaMA；“生成式推荐缩放配方并不自然适用于判别式排序”。
4. **组件设计有效**：
   - 给编码器加 MoE 容量无效（+0.00%），说明瓶颈不在编码器容量；
   - 轻量交叉解码器 C 只用 +0.2% FLOPs 即可带来 +0.05% AUC 提升，且 TSP 与无投影 KV 在保持更低执行开销前提下更有收益；
   - DGA 在噪声注入实验中鲁棒性最好；SRN 是深度扩展的关键（+0.08%）；多粒度 RoTE 优于单粒度与纯 RoPE（合计 +0.12%）。
   - 辅助序列 CVR 损失与对齐损失普遍提升多种序列模型的精度，缓解序列饥饿。
5. **系统效率与业务价值可兼得**：ULT 训练吞吐提升 5.8×；共享前缀推理使序列组件逐请求推理成本降低至约 1/20；在线 A/B 中，在 50ms P99 预算内，AUC 提升 1.31%，Advv 提升 11.93%，且已全量部署。

- **可复现性有限**：工业核心数据与绝对指标未公开；部分对比基线配置（如 HSTU、LLaMA 在 CVR 任务中的超参调节细节）并不完全透明，可能会引入对自身方法有利的偏差（尽管作者声称做了公平对齐）。
- **公共基准覆盖范围偏小**：仅用 MovieLens 两个版本和 Amazon-Books，缺少更多公开 CTR/CVR 数据集（如 Avazu、Criteo）或新兴大规模行为数据集，通用性论证不够全面。
- **“缩放但不真正到极限”**：在线部署配置只达到 50ms 延迟预算下的“可部署配置”，并未给出与离线实验最大规模同级的在线验证；同时公共基准序列长度仅 200，工业基准上 16k 长度的效果是否完全来自序列信息本身、还是额外的数据覆盖差异，仍需更多分析。
- **辅助目标的应用一致性**：ReST 对辅助序列 CVR 损失的边际增益小于其他基线（+0.07% vs LLaMA +0.16%），说明 ReST 的编码器已较好缓解序列饥饿，但这也意味着其最终精度增益有一部分来自训练目标，而非纯结构；对“损失函数短期可被简化/复用”可能构成一定解释风险。
- **系统设计依赖特定业务结构**：共享前缀复用依赖“多候选共享同一历史”的广告/推荐请求模式，对不同候选来源异构或需要个性化长序列检索的业务场景，可迁移性需进一步验证。
