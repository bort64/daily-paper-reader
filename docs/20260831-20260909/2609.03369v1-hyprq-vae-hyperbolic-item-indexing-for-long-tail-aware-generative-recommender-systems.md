## 摘要
序列推荐系统将用户行为建模为项目ID序列，而最近的生成式方法则利用大型语言模型（LLMs）将推荐视为语言建模任务。虽然这种范式融入了丰富的文本语义，但它引入了一个根本性的不匹配：LLMs处理文本令牌，而推荐系统依赖于离散的项目索引。这种错位常常导致生成式推荐中的幻觉。现有方法试图通过在欧几里得空间中学习项目词汇来弥合这一差距，但它们难以建模现实世界目录中固有的长尾分布，其中少数头部项目占主导地位，而大量尾部项目反映了用户的利基偏好。为解决这一问题，我们引入了双曲残差量化变分自编码器（HypRQ-VAE），这是第一个在双曲空间中学习项目索引的框架。HypRQ-VAE利用双曲几何的独特性质，其指数级的体积扩展自然适应了用户-项目交互的幂律结构。这使得模型能够编码丰富的文本语义，同时保留稀疏长尾项目的表示保真度。在三个基准数据集上的实验表明，HypRQ-VAE显著提高了推荐性能，特别是在推荐尾部项目方面。我们的分析将这些收益归因于双曲空间在生成式推荐中建模项目层次结构和稀疏性的卓越能力。我们的代码和数据可在以下网址获取：https://github.com/wulongfeng/HypRQ-VAE。

## Abstract
Sequential recommender systems model user behavior as item ID sequences, while recent generative methods cast recommendation as a language modeling task using large language models (LLMs). While this paradigm incorporates rich textual semantics, it introduces a fundamental mismatch: LLMs operate on text tokens, whereas recommender systems depend on discrete item indices. This misalignment often leads to hallucinations in generative recommendations. Existing methods attempt to bridge this gap by learning item vocabularies in Euclidean space, but they struggle to model the inherent long-tail distribution of real-world catalogs, where a small number of head items dominate, and a vast number of tail items reflect users' niche preferences. To address this issue, we introduce Hyperbolic Residual-Quantized Variational AutoEncoder (HypRQ-VAE), the first framework to learn item indexing in hyperbolic space. HypRQ-VAE leverages the unique properties of hyperbolic geometry, whose exponential volume expansion naturally accommodates the power law structure of user-item interactions. This allows the model to encode rich textual semantics while preserving the representational fidelity of sparse, long-tail items. Experiments on three benchmark datasets show that HypRQ-VAE significantly improves the performance of recommendation, particularly in recommending tail items. Our analysis attributes these gains to the superior capacity of hyperbolic space to model item hierarchies and sparsity in generative recommendation. Our code and data are available at: https://github.com/wulongfeng/HypRQ-VAE.

推荐系统领域近年面临一个核心的结构性矛盾：**LLM 的强大语言能力与推荐系统依赖的离散项目 ID 之间存在语义鸿沟**。具体而言：

- **范式背景**：传统序列推荐模型（如 SASRec、Caser）将用户行为建模为离散 item-ID 序列；而生成式推荐方法（P5、TIGER 等）将推荐重构为语言建模任务，利用 LLM 的文本理解与生成能力。
- **核心痛点**：LLM 基于文本 token 运作，真实商品标题/描述往往包含数十至数千 token，直接让 LLM 生成冗长文本极易引发**幻觉**；而直接采用原始 item ID（如"01234"）又会构造出语义空洞、体量庞大的无意义词表。
- **已有 Solution 的不足**：RQ-VAE 及其衍生方法（TIGER、LC-Rec、LETTER 等）在**欧几里得空间**中学习项目索引，但**欧氏空间的体积随维度多项式增长**，表征容量有限，难以刻画推荐数据中根深蒂固的**长尾分布** —— 少量头部项目主导交互，海量尾部项目承载用户利基偏好。
- **直觉洞察**：用户-项目交互天然呈现**幂律（power-law）结构**，而**双曲空间的体积沿远离原点的方向呈指数级扩展**，其几何形态与树状/层级化的长尾数据完美匹配。

作者由此提出两个关键研究问题：① 双曲模型在**生成 item ID** 方面是否有效？② 双曲模型是否在**长尾推荐**上系统性优于欧氏方法？HypRQ-VAE 即为回答上述问题所提出的首个将物品索引构建在双曲空间中的框架。

## 2. 方法论

### 2.1 核心思想

HypRQ-VAE 将 RQ-VAE（残差量化变分自编码器）的量化过程从欧氏空间**迁移到 Poincaré 球模型**（常负曲率双曲空间），利用双曲几何的两大特性：

1. **指数体积扩展** → 天然适配长尾项目中"稀疏+多样"的表征需求；
2. **层级树状结构** → 编码头部项目靠近原点（树之主干）、尾部项目延伸至边界（树之枝梢）的自然排列。

> 整体为两阶段流水线：**阶段一**用 HypRQ-VAE 将商品文本转为层次化离散语义 ID；**阶段二**将语义 ID 序列化为 token 序列。用 LoRA 微调 LLaMA2-7B，获得生成式推荐模型。

### 2.2 关键技术细节

**阶段一：双曲语义 ID 生成**

- **编码流程**：
  1. 商品原始文本嵌入 \(x\) 经 DNN 编码器得到欧氏隐向量 \(z_e \in \mathbb{R}^d\)；
  2. 通过指数映射 \(\exp_0^\kappa(v) = \tanh(\sqrt{-\kappa}\|v\|) \frac{v}{\sqrt{-\kappa}\|v\|}\) 将 \(z_e\) 投影到 Poincaré 球 \(\mathbb{P}_\kappa^d\)，得到初始残差 \(r_0 = z_h\)；
  3. 在每一量化层级 \(l\)，从含 \(K\) 个码的码本 \(\mathcal{C}_l = \{e_l^k\}_{k=1}^K\) 中选择与该层残差最近的码向量，并更新残差：
     - 最近码索引：\(c_i = \arg\min_k \| r_i \ominus_\kappa e_i^k \|_2^2\)
     - 下一层残差：\(r_{i+1} = r_i \ominus_\kappa e_{c_i}^i\)，其中 \(\ominus_\kappa\) 为 Möbius 减法，即 \(p \ominus_\kappa q = p \oplus_\kappa (-q)\)
  4. 最终重构表征为选中码的 Möbius 加法聚合：\(\hat{z}_h = e_{c_1}^1 \oplus_\kappa \cdots \oplus_\kappa e_{c_L}^L\)；
  5. 再经对数映射 \(\log_0^\kappa\) 拉回欧氏空间，供解码器重建原始嵌入 \(\hat{x}\)。

- **损失函数**（与 RQ-VAE 同构，但距离度量在双曲几何下进行）：
  \[
  \mathcal{L}_{HypRQ\text{-}VAE}=\underbrace{\|x-\hat{x}\|_2^2}_{\text{重建损失}}+\gamma\underbrace{\sum_{i=1}^L\left(\|\text{sg}[r_i]-e_{c_i}^i\|_2^2+\beta\|r_i-\text{sg}[e_{c_i}^i]\|_2^2\right)}_{\text{量化损失}}
  \]
  其中 \(\text{sg}[\cdot]\) 为 stop-gradient 算子。

- **语义 ID 格式**：每层选出一个索引，L 层共产生索引序列 \((c_1, \ldots, c_L)\)，格式化后形如 `<a_1><b_3><c_2><d_9>`。

- **碰撞处理策略**：针对多个商品被映射到相同 token 集合的碰撞问题，**不使用**额外辅助标识符，而是提出一种**基于距离张量的级联 token 再分配算法**：构造距离张量 \(D \in \mathbb{R}^{M\times L\times K}\)（M 为碰撞项目数），从最后一层开始，每个项目分配当前最近的可用 token；发生竞争时距离最小者优先，剩余项目回退至次近可用 token；若最后一层无法唯一分配则逐层向上递推，直止每个项目取得唯一 ID。

**阶段二：生成式推荐（SFT 微调）**

- 用户历史中每个项目替换为语义 ID token 流，序列展平后置于以任务提示模板包装的 prompt 中；
- 因果注意力掩码保障自回归训练；
- 优化目标为下一个项目 ID 序列的负对数似然：
  \[
  \mathcal{L}_\theta = -\sum_{j=1}^{|Y|} \log P_\theta(Y_j \mid Y_{<j}, X)
  \]
- 推理阶段使用 Trie 约束解码 + beam size 为 20，保证只沿有效 token 路径扩展。

## 6. 主要结论与发现

1. **主实验结论**：HypRQ-VAE 在 3 个数据集上的 Hit@K 和 NDCG@K 全部优于所有欧氏 baseline，相对最强基线 LETTER / LC-Rec 的提升最高达 Hit@10 +4.8%（MovieLens）和 +6.4%（Instruments）。
2. **长尾效应显著**：
   - 在 MovieLens 上尾部商品（T80）Hit@10 相对 TIGER 提升高达 **+52.71%**（头部仅 +14.09%）；
   - 双曲模型在推荐列表中给出了更高比例的尾部项目（无论 ground-truth 是头部还是尾部），说明其改善了推荐的**多样性**而非仅提升头部命中。
3. **量化误差机制解释**：欧氏空间中头部项目的 AQE（平均量化误差）系统性低于尾部（头尾差异 -3.3% ~ -4.5%），而双曲空间中头尾 AQE 差距显著缩减（甚至 MovieLens 上尾部 RQE 优于头部），为"双曲空间更均衡地表征头部和尾部项目"提供了直接实证。
4. **码本利用充分性**：不少欧氏方法需要 Sinkhorn-Knopp（LC-Rec）或正则约束（LETTER）来提高码本均匀度，而从码路径可视化结果看，**HypRQ-VAE 仅靠双曲几何的天然空间分配能力，就达到了比这些额外正则方法更均匀的码分布**。
5. **最优配置**：语义 ID 长度为 6、码本维度 256~512 时效果最优；过长 ID 因自回归误差累积而回落，过小码本则区分能力不足。

## 7. 优点

- **问题选取锐利**：准确识别了生成式推荐中"语义 ID 量化所在空间与数据分布几何形态不匹配"这一此前被忽略的关键维度。
- **方法论完整且自洽**：从"长尾结构 ↔ 双曲指数扩张"的理论直觉出发，延伸到 RQ-VAE 的几何改造，有清晰的可解释链条；碰撞再分配策略提供了超越简单增补 token 的工程方案。
- **分析视角深入、证据线索扎实**：不止汇报总体指标，而是从 head/tail 子群性能、AQE 量化误差、推荐列表成分、码本可视化多角度验证"双曲空间为何有效"，说服力强。
- **实验跨度合理**：数据集从稠密（MovieLens）到高度稀疏（Arts 仅 0.041% 密度）覆盖广；baseline 兼顾经典与前沿生成式方法。

## 8. 不足与局限

- **实验安全性与统计严谨性缺失**：未报告标准差的多次运行；头部/尾部切分是基于流行度的简单二分类，缺少更细分段（如按 10 分位）的粒度分析；主结果提升的显著性无从判定。
- **归因论证存在灰区**：HypRQ-VAE 的增益可能不单纯来自双曲几何——其还包含了更优的碰撞处理模块、部分初始化差异等。双曲空间+欧氏 RQ-VAE 中仅替换几何、保留碰撞策略的严格对照缺失。
- **对下游 LLM 生成质量缺乏直接量化**：长尾推荐性能的提升是否伴随生成幻觉率上升或输出不稳定（泛化风险）？论文并未从 text-to-item 的生成质量维度给出验证。
- **可扩展性未回答**：当品牌目录扩展至数亿商品、双层码本或更长 ID 必须扩展时，双曲空间中码本学习的收敛速度、数值稳定性及索引漂移问题（catalog shift）有待探讨。
- **算力/资源披露欠缺**：缺少 GPU 数量与训练时间，且 LLaMA2-7B 的 LoRA 微调显然需要远高于非 LLM 方法的计算资源，实际部署成本不明。
- **实验与真实场景差距**：评测限于静态的 next-item prediction 与离线命中率，没有揭示在用户冷启动、商品冷启动和动态目录更新等实际推荐系统运行条件上的表现。
