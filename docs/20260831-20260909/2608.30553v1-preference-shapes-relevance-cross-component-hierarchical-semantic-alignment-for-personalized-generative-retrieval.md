## 摘要
生成式检索（Generative Retrieval, GR）通过将查询直接映射到具有强大候选项目表示能力的语义ID（Semantic IDs, SIDs），已成为一种有前景的范式。然而，现有仅从项目内容派生的SIDs存在语义鸿沟，无法将动态查询意图与静态项目表示对齐。此外，当前的生成范式很少对用户行为序列进行建模，并且总是受到束搜索自回归解码高推理延迟的瓶颈制约。为解决这些挑战，我们提出了面向个性化生成式检索的跨组件分层语义对齐（Cross-component Hierarchical semantic Alignment for Personalized generative retrieval, CHAP），一种从分层视角出发的新型个性化GR框架。首先，我们设计了一个分层语义对齐模块，将查询的潜在空间与项目的量化路径对齐，并同步多粒度语义。其次，我们构建了一个个性化GR框架，通过协同离散SIDs进行结构指导和连续表示进行细粒度语义细化来建模用户行为。值得注意的是，我们引入了一种残差级联生成机制，将昂贵的多步Transformer解码器限制为单次推理，从而在提升推理吞吐量的同时减轻信息损失。在三个公开数据集、一个专有工业数据集以及在线A/B测试上进行的大量实验证明了CHAP的优越性，验证了我们方法的有效性和实用价值。代码公开于https://github.com/zzzgm/CHAP。

## Abstract
Generative Retrieval (GR) has emerged as a promising paradigm by mapping queries directly to Semantic IDs (SIDs) with powerful representation capabilities for candidate items. However, existing SIDs derived solely from item content create a semantic gap, failing to align dynamic query intents with static item representations. Furthermore, current generative paradigms rarely model user behavior sequences and are always bottlenecked by the high inference latency of beam-search autoregressive decoding. To address these challenges, we propose $\textbf{C}$ross-component $\textbf{H}$ierarchical semantic $\textbf{A}$lignment for $\textbf{P}$ersonalized generative retrieval ($\textbf{CHAP}$), a novel personalized GR framework from a hierarchical perspective. First, we design a Hierarchical Semantic Alignment module to align query's latent space with item's quantization path and synchronize multi-granular semantics. Second, we construct a personalized GR framework that models user behavior by synergizing discrete SIDs for structural guidance and continuous representations for fine-grained semantic refinement. Notably, we introduce a Residual Cascading Generation mechanism to restrict the costly multi-step Transformer Decoder to a single-pass inference, boosting inference throughput while mitigating information loss. Extensive experiments on three public datasets, one proprietary industrial dataset, and online A/B tests demonstrate CHAP's superiority, validating the effectiveness and practical value of our approach. The code is publicly available at https://github.com/zzzgm/CHAP.

## 1. 核心问题与整体含义

本文聚焦于**生成式检索（Generative Retrieval, GR）** 这一新兴检索范式，该范式通过将查询直接映射为物品的语义ID（SIDs），省去了外部索引、缩小了端到端检索的复杂度。其核心动机和背景如下：

- **语义鸿沟（Semantic Gap）**：现有GR方法（如TIGER、HierGR）所构造的SIDs**仅基于物品内容**通过RQ-VAE等模型预训练得到，未能显式感知查询语义。这导致模型难以对齐“动态查询意图”与“静态物品描述”，在处理复杂、个性化查询时泛化性差。
- **缺失个性化建模**：当前GR范式很少利用用户行为历史序列，无法充分刻画多变、因人而异的检索意图。
- **推理效率瓶颈**：GR通常依赖束搜索（beam search）自回归解码，每一步都需要经过重型Transformer解码器，在层级化SID生成中尤为耗时，难以满足线上工业系统低延迟的要求。

针对上述问题，论文提出**CHAP**（Cross-component Hierarchical semantic Alignment for Personalized generative retrieval）框架，核心思想是：**“偏好塑造相关性”**——通过将个性化偏好与语义进行精细对齐，使生成式检索在结构正确性与语义匹配能力上都获得突破。

## 2. 方法论

CHAP 的整体框架由三大部分构成：

### 2.1 层次语义对齐（Hierarchical Semantic Alignment, HSA）

目的：将查询的潜在空间与物品的量化路径对齐，弥合查询-物品语义鸿沟，并防止 codebook 崩塌。具体由三个模块协作：

- **跨样本对齐（CSA）**：基于RQ-VAE损失函数，在查询和物品间互换角色，优化两项损失：
  - **Cross-Commitment Loss**：强制查询的第l层残差向量向目标物品选中的码字对齐。
  - **Cross-Reconstruction Loss**：利用查询的量化表示重建目标物品的原始稠密表征。
- **层次感知对比学习（HCL）**：在每一个层级深度上显式执行对比学习，将查询与目标物品在该层累计的量化表示拉近、与批次内负样本推远，保留“从粗到细”的结构信息。
- **软概率蒸馏（Soft Probability Distillation）**：将冻结的物品侧编码器输出的软码字分布作为教师信号，用 KL 散度约束可训练查询侧编码器的量化分布，防止硬量化导致的表征漂移。

### 2.2 个性化序列建模（Personalized Sequence Modeling）

- **双视图序列建模**：每条用户历史交互由“稀疏 SID”（结构指导）和“稠密向量”（细粒度语义）共同表示，组合为输入序列。模型**仅用查询的双视图表征作为解码器初始输入**，强迫解码器通过交叉注意力向用户历史“回望”来获取个性化上下文，避免曝光偏差。
- **混合训练目标**：
  - 稀疏生成损失（Sparse Generation Loss）：对各个层次的SID token做分类。
  - 稠密对比损失（Dense Contrastive Loss）：以预测出的稠密向量为锚，用InfoNCE目标监督。
  - 两者协同形成“先学粗结构、再精炼语义”的课程式学习效果。

### 2.3 残差级联生成与检索（Residual Cascading Generation and Retrieval）

- 将物品生成概率分解为两阶段：层次化SID的稀疏生成 + 稠密向量的条件生成。
- 提出**单次推理残差生成机制**，令Transformer解码器只运行一次，得到全局结构上下文后，后续各层的SID token通过轻量级残差块按递推式（h^(l+1) = ResBlock(Concat[h_dec_sparse, e_l^c_l]) + h^(l)）逐步生成，无需重复调用解码器。
- 稠密向量预测头接收解码器输出和量化重建向量，融合离散结构与连续语义。
- 推理时并行采样M个候选SID，稀疏信号按生成路径累计对数概率计算，稠密信号用预测向量与物品原始向量的余弦相似度计算，二者经带温度的Softmax归一化后相乘得出最终融合分数。

论文在附录B中还给出一个**熵增定理**：证明CHAP的级联分解相对于独立的双视图分解不会增加建模不确定性（即级联能降低条件熵）。

## 6. 主要结论与发现

- 基于物品内容训练的SIDs存在严重语义错位，必须引入**查询-物品的跨组件对齐**。
- HSA模块是提升SID质量的核心：它能相关物品收敛到查询周围，不相关物品被推开，大幅改善生成式检索命中率。
- 稀疏SID与稠密向量需**协同使用**：稀疏ID负责结构骨架，稠密向量负责精细排序（单独使用会显著下降）。
- 双视图序列建模对歧义查询的帮助最大，HSA对冷启动和长尾查询增益最强，而残差生成机制在所有意图段上提供稳定基础增益。
- **残差级联生成机制**是有效的解码加速方案：Local-Life上CHAP取得78.9 QPS，显著高于COBRA（32.4）、TIGER（39.2）等模型，精度还更高，实现了“更快+更准”。
- 在实际业务中，CHAP带来UV-CTR +0.77%、UV-CXR +2.09%、支付订单量 +2.98%的显著业务提升，验证了其商业落地价值。

## 8. 不足与局限

- **冻结码本限制了协同信号反馈**：论文自身承认，冻结物品侧码本虽能防止语义漂移，但物品表示无法随协同过滤信号或查询侧反馈动态更新，可能限制高度动态环境下的个性化上限。
